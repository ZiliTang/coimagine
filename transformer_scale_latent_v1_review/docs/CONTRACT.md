# CONTRACT — 本轮接口冻结

## 1. 数据与未来信息

- 输入是**同一前缀窗口**（33×57，左补齐，padding 恒为零且 `token_valid=0`）。
- 监督是该窗口之后的**连续真实帧**：第 k 步标签取自同一序列的 `end + k`，仅当
  `end + k < steps` 有效。**不从互相独立的状态转移拼伪序列，不复制终态填充 padding。**
- 覆盖 `t=0` 与 `t>0`；平衡采样默认保留 25% 的 `t=0` 配额，比例随面板一起保存。
- 未来跨度：训练 8 步（0.40 s）。评价 1/4/8 步为训练范围内，**16 步标注为跨度外推**。
- 同一 root 下的窗口高度相关。所有样本量同时给出**窗口数 / 序列数 / root 数**。

## 2. 可用与不可用字段

允许进入模型：真实前缀观测、双方候选命令（alpha、速度、active）、公开 option 最大超时、
已执行时间（历史帧的时间列与当前时钟）。

禁止作为自由预测输入：未来真实控制器阶段、未来实际低层控制、未来接触结果、未来真实位姿、
物体真值、实际剩余时长、真实结束时间。真实 `T_exit` 只出现在 terminal token 中，terminal token
只用于监督。

## 3. 残差与坐标

- 保持每次 option 的既有 `R_i0`，时间展开中**不隐式重锚定**。
- 残差锚点固定为**预测起点的可见中点**；起点不可见时回退到 `R_i0` 固定原点（数值零），
  该子集单独评估。**第 k 步解码不得使用 t+k 时刻的真实中点作为参考。**
- 几何 8 列：`0,1` r0 中点 x/y、`2,3` r0 法向 sin/cos、`4,5` r1 中点 x/y、
  `6,7` r1 法向 sin/cos。四列中点用残差参数化，四列法向保持绝对（按组单标量标准化）。
- 标签统计只从训练集拟合，随检查点保存（`transformer-scale-latent-v1/stats-1`）。

## 4. 多步目标与损失

- 第 k 步只在真实帧存在时进入损失；**先在窗口内对有效步与有效列平均，再跨窗口平均**，
  长窗口不会因为标签多而获得额外权重。
- 过程任务 = geometry / pose / velocity / validity 四组等权平均；直接终态辅助头为另一组；
  两组各占 **0.5 / 0.5**。下一步（k=1）已包含在多步损失中，不重复加权。
- 几何按真实标签可见性评估；**不按模型预测的可见性筛选几何样本**。
- latent 递推从真实前缀初始化一次，随后自由展开并沿展开链反传；训练与评估的递推路径一致。
  teacher forcing 只能作为明确命名的辅助诊断。

## 5. 两类模型的同规模定义

- 总可训练参数差 ≤5%；同时报告 encoder / transition / decoder / heads 分模块参数。
- 本轮配对：两侧 encoder 完全相同（1,246,880），差异只在
  **latent 多一个 transition（105,440）而 decoder 更窄（76,824 vs 168,984）**。
  这意味着配对比较的是"同样的历史编码器下，把参数花在递推还是花在读出头"。
- 同参数量**不等于**同训练计算量，也不等于同预测能力；训练成本单独报告。

## 6. 报告口径

- 机器人 0/1、`t=0`/`t>0`、四类场景、运动程度、可见性变化、历史长度**分开报告**。
- 分组样本过少时只给描述值与数量，不声称优势。
- 配对比较用 **root 级 bootstrap**（保留同 root 内全部窗口）；三个种子分别报告，
  跨 seed 汇总不把 seed 当独立 root。
- 同时给出**"各模型误差中位数之差"**与**"逐样本误差差值的中位数"**；两者可以对同一基线
  给出相反方向，不得互相替代。
- 真实 `T` 只作**评估坐标**；**不得**用它决定部署停止时刻。
- 未接规划器，因此报告明确写"尚未评估闭环决策收益"。
