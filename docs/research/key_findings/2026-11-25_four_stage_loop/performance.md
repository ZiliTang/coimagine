# 四段式前端提速：开发记录，未完成研究闭环

用户要求允许牺牲几何精度，优先将计算开销拉回接近原整局耗时。此次保留unknown语义，采用新的C++增量网格profile；不将粗化版本声称为旧多边形算法的逐位等价替代。

原80边界剖析中，历史静态点被查询约458万次。平面区域合并、逐个包装多边形以及重复复制公开记录也占主要开销。空间索引与GEOS向量化保留了逐项语义一致性，但前端重算仍约20.2秒。跳过冗余区域合并会改变后续收缩与个别放行，已撤回。

新kernel从公开自由射线的闭合三角形、四边形建立小面积证据。整个1cm格被覆盖才标记FREE，不完整或过复杂的格保持UNKNOWN。只处理当前运动附近的新证据；射线区域按16tick间隔增量更新，静态命中逐边界加入保守占据格。运动区域按外包络检查，保留原身体运动界。当前策略仅引用126项语义，原准备器有524项；其他候选的几何报告在运行时需要时才计算。当前历史与未来预测共享同一份已抽取策略。

不能把前端计时与整局计时相混，也不能将不同行为版本的耗时比解释为纯kernel加速比。本次尚未达到“一秒一局”。在线整局分项约为前端3.20秒、选择检查0.71秒、物理仿真5.37秒；单机时序抖动及计时范围不同会造成回放耗时差异。

该整局的独立审计：公开前缀逐项一致，所有记录动作按当时规则放行；箱体静态接触、机器人静态接触、机器人互碰、箱体与其他物体接触、宿主运动界越界均为0，停止达标。**箱体目标推进为0，最终任务失败。** 不将停滞或单开发房零接触写成策略安全与任务完成的研究成功。

51项针对性检查通过，包含原抽取/预测/载体测试，以及C++隐藏障碍输入不变、整格覆盖、独立障碍几何、原身体包络复用、完整与精简语义的候选/评分/选择一致性、过期延迟几何拒绝。未运行全仓库测试。安全仍以公开传感器、静态几何、最小连通障碍面积、已知目标CAD、初始分离及运动/经验预测范围为条件。
