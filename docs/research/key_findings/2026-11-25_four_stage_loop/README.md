## 正在修补的缺口

1. 运动包络必须只校准真正向外越界的方向，不能把包络内较短运动当作漏覆盖。已修正，并保留旧模型及反例。
2. 两台机器人速度、控制器参考速度和公开执行阶段必须影响支持域，不能被大量雷达通道稀释。已增加相应检查，正在补采短动作切换的数据。
3. 当前动作已认证的制动尾段需要带着模型版本与条件传给停止执行，不能在下一边界无候选时丢失。已实现有来源的停止依据；实际停止速度和预测越界另行审计。
4. 在线模拟仅从公开历史构造候选场景，并核对雷达。未经误差校准的有限名义成功不放行；当前在线误差适配器尚未完成，不能把接口可运行当作在线复核已有效。
