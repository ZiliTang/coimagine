# 离线 GA-Q 提高了七 CAP 成功并集上的闭环保留率

2026-11-19 · 随机房间 · 无 trace · 冻结模型配对评估

## 可用于论文的结果表述

在 200 个已查看的诊断初态上，离线 GA-Q 与单教师 GA 均从七个 CAP 给出的合法候选动作中贪心选择。在至少一个 CAP 成功的 146 个初态中，离线 GA-Q 的平均任务成功率为 **67.81%**，单教师 GA 为 **57.53%**，配对差为 **+10.27 个百分点**（95% 区间 **[+3.06, +17.35]**）。在全部 200 个初态上，两者的成功率分别为 **53.00%** 和 **43.75%**。百分比与配对差均从原始计数独立四舍五入。[逐场景数据](per_scene.csv) · [统计汇总](summary.json)

## 对研究路线的启示

- **离线 GA-Q 值得作为后续 CAP 整合实验的无 trace 基线。** 两个种子在成功并集上都有净收益，同时仍有能力丢失。以单教师为参照，seed17 新增 37 例、失去 28 例，seed29 新增 31 例、失去 10 例。在十个单 CAP 中，本面板成功数最高的 CAP-003 为 81/200，两个离线 Q 模型分别为 100/200 和 112/200。[逐场景成败](per_scene.csv) · [单 CAP 参照数据](reference_per_scene.csv)
- **少数 CAP 独有的能力仍是缺口。** 在恰一个 CAP 成功的 28 例中，两个 Q 模型各成功 12 例，仍各有 16 例失败。该子组的配对区间跨零。论文可以报告总体保留率的改善，对稀有能力的判断需更多场景。
- **收益的机制有待拆分。** Q 使用 608 个训练初态中七个 CAP 的成功与失败决策，先做 16,000 次 V 更新，再用真实执行动作和后继状态的预测价值做 8,000 次 Q 更新。单教师 actor 从其中 449 个有成功教师的初态抽取优先教师动作，做 24,000 次模仿更新。目标、样本范围与抽样权重同时变化，单独归因于 Q 自举仍需控制这些因素。两组均未使用在线微调。

## 证据与复核

两个训练种子共享同一面板，新增 400 次离线 Q 执行，配对复用 400 次归档 actor 执行。两组均在最多 1,800 ticks、300 个决策的预算下运行。按可移动物体数量分层，对场景配对重抽 10,000 次，每次保留两个种子的全部结果。区间条件于这两个种子。该面板已用于诊断，独立确认需另行冻结场景。[场景原件](panel.json) · [Q 评估协议与权重哈希](q_protocol.json) · [actor 评估协议与权重哈希](actor_protocol.json)
