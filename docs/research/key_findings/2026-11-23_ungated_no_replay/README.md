# 无门控路由中的成功回放消融

关闭成功回放后，200 间诊断面板的成功率变化为 -1.33 [-3.17, +0.50] 个百分点。旧成功保留率变化 -0.29 [-2.42, +1.69] 个百分点，旧失败救回率变化 -2.70 [-6.06, +0.42] 个百分点。

本面板中，成功回放合计多成功 8 次，其中 7 次净差来自救回父 actor 的失败，旧成功的净保留只多 1 次。三个种子的成功数差（加回放减去回放）分别为 +9、+1、−2。回放明显减少了固定训练前缀的改选，闭环差值的区间仍跨零。当前证据适合将其列作可选的训练项，未确立其为整局成功所必需。

两种更新直接比较，去掉回放独赢 12 次，加回放独赢 20 次。三个种子共用同一批 200 间。95% 区间按房间配对自助抽样 10,000 次，每次把三个种子一起抽取，条件指标同步重算分母。该面板此前已查看，区间只覆盖这三份模型的房间抽样不确定性。

## 训练数据上的效果

固定父 actor 的成功前缀，加回放后改选 7/542 个边界，去掉后改选 40/542 个。两组在有实测胜者的训练分叉分别选对 37/37 和 37/37 个。50 间开发闭环中，父 actor、加回放和去回放的逐种子成功数分别为 [20, 22, 21]、[24, 26, 26]、[23, 24, 24]。

## 实验条件

每个种子从原已训练四轮的同一父权重接续一轮。全程开放路由，共用此前在 50 间上采到的 419 个分叉，其中 37 个同前缀分叉具有唯一胜者。每步 64 个分叉偏好、128 个全局软保持，均取相同小批和固定父模型概率。加回放臂额外使用 64 个成功前缀的余量损失，权重 0.25、logit 余量 0.2。去掉该项后直接对其余两项求和，保留其原权重。每种子均为 300 次 Adam 更新，学习率 0.0003。带回放组重新拟合的权重与原锁定模型全部逐值一致，复用其既有闭环结果。去回放组三份模型锁定后，重新执行 600 次诊断面板闭环与 150 次开发闭环。
