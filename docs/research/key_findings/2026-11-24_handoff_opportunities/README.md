# 提前接管与改变交还时机

母策略 P 与恢复程序 R 冻结。每个分叉从相同的可见观测、物理前缀和程序记忆出发，只改变一次当前决定，再用原规则跑到终局。本轮比较基准是作者的 P＋R 完整程序。

每间计一次。从事后知道终局的视角，任取一条已测分叉可以多救回哪些房间。救回与丢失两列相对于同一条原路线，实际选择需要只看当时的公开输入。

自然抽样的新房间用来判断总体收益空间。定向组从独立候选池取最可能触发旧接管的五分之一。已知失败组来自旧开发集，仅用于寻找漏触发。验证两组与开发房间按布局内容去重。

提前接管将停滞证据窗口从 140 ticks 缩到 60 ticks，要求最近至少两个观测，物体向目标前进不超过 6 cm。原有几何、可行动作和剩余时间条件继续生效。提前交还要求 P 已经提出不同的合法动作。稍晚交还允许 R 在达到位移目标、超出不超过 10 cm 时再选一次动作，保留超时与避障限制。所有条件仅在原有 option 边界、单推手连续接触 3 ticks 或接触中推手机器人沿推动轴每前进 0.2 m 的复核点检查。复核点只纳入能实际切换控制的替代提议。

在原轨迹上，每类取首末两个合格时刻，稍晚交还只取第一个。另在首次提前接管实际生成的计划内取同样的交还分叉。后一类成败均与已经提前接管的配对路线比较，不能和原路线增益相加。提前接管指此刻早于原规则，房间更早时可能已有其他恢复计划。

## 公开信息能否判断何时改动

分时机拟合线性回归。输入为当时可见的几何、接触、进展与计划信息；目标为改动后的终局成功减去默认终局成功，轨迹内按房间等权。开发两种胜负方向都出现才拟合。验证前固定阈值为零。以下整局策略只在该类**第一次**合格时按预测决定是否干预，后续完全沿用原规则。两条结局均已实跑，可从配对记录精确还原该策略的逐房间终局。

| 改动 | 验证面板 | 原程序 → 单次选择 | 执行改动 | 救回 / 丢失 | 首次一律改动的成功数 | 全部分叉条件 AUC |
|---|---|---:|---:|---:|---:|---:|
|提前接管|验证 · 自然（160 间）|103 → 104|5|2 / 1|104|1.000|
|提前接管|验证 · 定向（80 间）|42 → 43|7|3 / 2|43|0.800|
|提前交还|验证 · 自然（160 间）|103 → 103|2|0 / 0|103|—|
|提前交还|验证 · 定向（80 间）|42 → 43|3|1 / 0|42|0.800|
|稍晚交还|验证 · 自然（160 间）|103 → 103|1|0 / 0|103|—|
|稍晚交还|验证 · 定向（80 间）|42 → 42|0|0 / 0|43|—|

AUC 仅比较终局翻转的正负分叉，缺少任一方向时未定义。单次选择的房间增益与这个条件排序指标分母不同。

- 开发 · 定向中，104 间在整条原路线均无恢复提议，其中 45 间失败。提前接管在 6 间可执行，救回 0 间、丢失 1 间。
- 开发 · 已知无接管提议的失败中，79 间在整条原路线均无恢复提议，其中 79 间失败。提前接管在 5 间可执行，救回 4 间、丢失 0 间。

另外从头运行母策略 P。80 间已知失败中，P 单独成功 0 间。
