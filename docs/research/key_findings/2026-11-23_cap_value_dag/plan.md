# 假设与验证顺序

| 假设 | 如何检验 | 本轮位置 |
|---|---|---|
| 不同 CAP 有可互补的整局和局部能力 | 固定 A、B、AA、AB、BA、BB 在同房间配对，报告收益与损失 | 已有证据，本轮复用真实后缀 |
| 几何前置条件有助于解释和辨认局面 | 真实八种关系形成六簇，和从公开短历史预测的簇比较 | 节点和读出器沿用已冻结版本 |
| 同簇回访可以是持续推进；部分回访是在卡滞 | 用同簇分支的真实终局、物体推进和公开近期进展检验；对成功回访计数 | 本轮检验。不将真实回访改标成失败 |
| 时间向前展开后，图可回传终端均值和风险 | 两个 120 tick 窗口，再由最后一位专家执行到底。分别回传成功率、终距一阶及二阶矩 | 本轮主检验 |
| 同一个节点可能因来路、进展和剩余预算而需要细分 | 在同一数据上对预算＋局面与附加最近专家、三命令公开进展的表示做配对比较 | 本轮主消融 |
| 误差可能来自转移估计，也可能来自共享终端后缀估计 | 依次代入真实第一后继、真实第二后继；独立评价终距、成功率、风险和路线排序 | 本轮离线解释，真实后继不用于部署 |
| 图的价值能监督真实交接，优于保持原专家 | 从相同前缀按预测选四条路线，或在 A 造成的实际接手点比较 A/B；用完整实测对应分支评价 | 本轮限定到单次/两段路由。长期反复路由另验 |
| 图指导作者能产生更大的单专家成功并集；新成员能从别人的失败状态接手并交还 | 同母本、同困难池、同开发预算，常规作者对图指导作者；冻结新成员，独立测单成员并集和 A→恢复 CAP→A 相对 A | 后续独立作者对照。当前 A/B 的数据无法验证新成员的贡献 |

## 冻结的设计

开发集使用已有 200 个房间。原 200 房间复作诊断；再用内容去重的全新 200 房间（生成种子 662315973）作主确认，不按其结果调整节点或阈值。每房间预定在第 4、24 条命令之后分叉。两种原专家前缀在房间间均衡分配。复用优化后执行器和真实总预算。旧文件缺少边界决策计数，重放前缀核对历史哈希，补记真实计数。两种终端指标分开报告，不更改物理奖励。

冻结 120 tick 的两个层次。模型预测每段终止或到达下一层的联合结果；层次严格递增。实际剩余 tick 和决策数随样本保存，在估计表内分别以 300 tick、50 个决策为宽度共享样本。末层由第二专家保持执行到底，估计真实后缀的成功概率、终距均值及平方均值。各层以 8 个父层伪样本平滑稀疏格。基础对照为按路线的常数、同起点直接估值、仅预算、物理簇、物理簇加来路与近期公开进展、公开预测簇的基础和加细版本。来路取至多最近两位执行专家；进展按最近三条命令的公开余距变化分为接近/无明显变化/远离/不可见，阈值 2 cm。平滑后再分别估计终距小于等于 20 cm、超过 1 m 的概率，以后者为预先指定的尾部风险。方差评价用实际平方残差和预测方差校准，报告方差分解；成功本身仍用环境标签。

主要评价可达起点上四路线的终距 MAE、成功 Brier、尾部 Brier，以及同前缀、真实终距相差超过 2 cm 的两两排序（预测持平算半分）。路由按预测成功率最高选，完全相同按 AA、AB、BA、BB 顺序。另按预测终距最低选并独立报告。以开发集固定最佳路线以及 AA 作基准；保留未到分叉的真实终局，区间按房间配对重抽。补充分析 A 已走一段后继续 A 或交给 B，以及有无自环的局部样本。由此检验预测改善能否转为路线选择改善。诊断和独立确认均保留正负结果。

## 针对新 CAP 开发池的独立筛查

在只检查开发集后，冻结早期筛查：从规定原专家实际执行四条命令的边界出发，该点物理簇为 3，随后 A、B 各执行一窗后也均未终止且仍在簇 3，标为候选故障房间。以初态开始、自然运行的七个冻结专家是否全败为独立标签。新 200 房间另执行 1,400 局单专家，比较标记与未标记房间的全败率、差值区间和所有全败房间中能找出的比例。允许在任一采样边界命中的宽松规则仅作次要分析。这验证能否找到旧库的薄弱处；新 CAP 本身是否能解决它们必须留给随机对照的作者实验。
