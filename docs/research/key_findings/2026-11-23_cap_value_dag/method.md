# 价值回传的统计口径

## 路线与信息边界

用 A 或 B 生成真实前缀，从同一个边界分别执行 AA、AB、BA、BB。第一个字母执行一个 120 tick 窗口，第二个字母先执行另一个 120 tick 窗口，此后继续到底。两个窗口的末条命令均按预算截短。提前发生任务成功、失败或预算耗尽按真实终局结算。第 4、24 条命令后的分叉各占一个预定时点；任务先于分叉结束时，各方案取得同一结果。四条路线是四种真实执行条件，每房间仍只算一个独立房间。图上一步的专家选择指一段闭环 CAP，而非单条底层动作。

每个非终止边界记录完整公开历史哈希、物理 tick 与实际决策计数。旧 400 房间在复用既有终局时重放缺失预算的前缀；新 200 房间从头执行。每个窗口后的预算严格减少；相同物理簇可出现在下一层。用于共享估计的预算分箱可在相邻窗口相同，层号始终不同。模型拟合与选路只用开发房间；旧诊断与新确认面板分别报告。

## 经验估计

以终距 D（米）为正数，奖励可等价取 −D，折扣为 1。成功率另取环境成功标签。每个实际终局产生五个目标：D、D²、成功、D>1 m、D≤0.2 m。

- 末端后缀表只用实际上到达第二个窗口末的分支。取对应末位专家继续执行的完整终局，按该专家和末层节点估计目标的条件均值。
- 在中间层，若该窗口内已终止，用实测终局；否则读取后继处的对应专家后缀估计。按中间层起点和接手专家求条件均值。
- 在分歧起点，同理取第一段真实发展到的中间层估计或窗口内终局，再按起点和候选两段路线求均值。这样得到的是对开发样本转移分布的经验积分。用于每条路线的第一个窗口转移样本与未来第二个专家身份无关。以同样的规则回传 D² 和事件指示量。方差为 E[D²]−E[D]²，可拆为末层剩余方差、第二段后继均值的分化、第一段后继均值的分化。
- 样本稀少时，按同路线或同继续专家的均值逐级平滑，再按预算、节点、来路、近期进展加细。每一级父表相当于 8 个样本。这是受限的数据驱动近似；同簇、同预算仍可能隐藏关键差异。图中的概率和方差来自房间及历史的混合，无法单独解释为物理随机噪声。

“直接估值”在相同起点、同一路线、相同分箱和平滑方式下直接拟合真实终局。“一次回传”使用实际第一后继的整段后缀估计，并在起点对其积分。“观察真实后继”则在测试时读取对应分支真实到达的一个或两个节点，作为诊断对照；窗口内已经终止的分支结局已知，另行报告两窗都未终止的共同子集。在 A 已真实执行第一段后，可以用它的实际后继选择继续 A 或交 B；在根节点选路时不能读取这些未来信息。

## 误差与收益

多种路线的全局距离误差与成功/尾部 Brier 各有独立口径。距离排序只在同前缀的真实终距差超过 2 cm 时计分，预测持平计半分。终局方差和均值预测的实际平方残差在测试集上比较，并按预测方差四分位给出分组结果。房间配对 95% 区间取 2,500 次重抽；它描述测试房间抽样差异，不衡量重新训练一套模型的方差。选择策略同时报告胜率、实际终距、相对固定 AA 救回和丢失数。新任务成功和距离最短可能偏好不同的路线。
