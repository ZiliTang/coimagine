原有 200 个开发房间的纯专家成功数为 A 108、B 117、C 122。示范覆盖并集 152，有效分歧边界 3,687。两组共用全部样本与优化预算。首轮基础组与语义组的平均动作熵分别为 0.205 和 0.181 nats。

四个冻结语义量为保持有效接触推动、保持有效接触准备、改动反复停滞的动作意图、双机器人推动方向对抗。这些量由相同公开输入与任一候选命令计算，critic 在两组均采用基础信息。四个量在成功示范的候选之间分别有 200, 915, 152, 9 / 3687 个边界出现差异。较早的 A/B 或 A/B/C 面板未用于给本轮选择 PPO 权重。
