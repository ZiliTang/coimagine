# 从空库逐个解决单中心故障的三轮结果

原计划五轮，按用户指示在第三轮的 160 场全开发池扫描后截止。三位入库成员各完成 160 个原始开发房间，480 次完整闭环，均无执行异常。每轮作者调试一个实际未覆盖中心及其四个固定机器人初位微扰，半径为 1、2、3、5 厘米。第一轮只给公共指南，后两轮可复用之前的源码。

| 轮 | 中心 | 成员 | 可见中心族 | 单成员全池成功 | 新增 | 累计并集 |
|---|---|---|---:|---:|---:|---:|
| 1 | dev_5_36 | s020 | 3/5 | 2/160 | 2 | 2/160 |
| 2 | dev_2_03 | s028 | 0/5 | 0/160 | 0 | 2/160 |
| 3 | dev_2_31 | s048 | 0/5 | 0/160 | 0 | 2/160 |

第一轮在原始开发池解出 dev_5_36 和 dev_4_23。后两轮所选成员均未增加覆盖，也未解决各自中心。第二轮触及单轮 token 限额，由宿主从已完成的同轮试跑中选定版本。首轮的两例微扰成功来自同一父房间；这两例不纳入 160 个原始房间的分母。

这次单作者开发在已执行三轮内没有积累可测的跨房间终局成功。结果适用于选定的中心、预算和提交成员。第四、五轮已取消，隐藏扰动和自然留出面板未评测。原始协议、各次试跑、源码与公开轨迹保留于实验目录。
