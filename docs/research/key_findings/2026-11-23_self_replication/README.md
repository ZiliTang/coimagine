# 无教师路由的自采自续能否跨种子复现

新面板 A 成功 101/200，B 成功 106/200。seed17、29、43 的最终成功数分别为 107、111、105。三个种子中有 2 个超过自身起点，2 个超过同面板最佳单 CAP。

主评估按种子等权，最终平均成功 107.7/200。相对先验比较对象 B 的成功率差为 +0.8 [-4.0, +5.5] 个百分点，相对各自起点为 +1.7 [-1.8, +5.0] 个百分点。区间按房间配对重采样，条件于这三个已训练模型。

## 冻结方案

沿用首轮协议和 200 个开发房间的顺序，四轮各使用 50 间。seed17 复用已锁定的初始和末轮权重；seed29、43 各自从头采样和拟合。每个种子控制 PyTorch 随机初始化和每轮小批抽样，选取分叉的时间分层与哈希规则相同。每个边界先由 A、B 各提一个动作，在共享停滞门控开放且提案不同时由 actor 选择。每间至多抽三个分叉，在同一前缀比较两条首步，均由该轮冻结的 actor 续跑。四轮各 300 次 Adam 更新。训练和部署均屏蔽九个显式教师语义特征，保留几何、动作和短历史。

拟合前冻结新的 200 个自然房间，按去除 scene_id 的内容哈希核对与开发房间、上一轮面板和历史登记集无重合。各种子共享房间。原先得到 114/200 的面板作为诊断，与新面板分开报告。仅评估起点和预先指定的第四轮，未根据评测选种子或轮次。

## 结果解读

在两位专家分别执行都失败的 72 间中，三个模型分别救回 7、13、7 间。在两位专家都成功的 79 间中，三个模型也分别丢失 6、4、5 间。能力组合可以跨种子观察到，稳定的整局净收益在新面板上仍缺乏证据。

相对 B，每个种子平均救回 20.0 间，同时丢掉 18.3 间。保留原有成功与发现新解对最终收益都很重要。
