# 每个 CAP 的终局价值何时可预测？

## 目标与执行

对两套冻结库去重后的 7 个 CAP 分别拟合。共同母本 basis、常规 s002/s003/s004、语义专精 s002/s003/s004 互相独立。每个程序在相同的 400 个开发房间和另一批新生成、按可动物体数均衡的 200 个房间执行到底，沿用拆分接触＋末段调速、最多 1,800 ticks / 300 个实际决策边界。开发逐局与原实验核对完整历史哈希、成败、tick 与边界数。留出集由随机房间 seed 662315879 生成，并按去顶层 scene_id 的内容哈希与所列面板交叉排重。每个房间共享给全部专家，推断时用房间作配对单位。

连续终端收益取目标物中心到目标点的负欧氏距离，单位为米，γ=1。报告预测余距，越小越好。物理真值仅在最后生成监督或在扰动对照中审计。另用独立网络回归环境定义的二元任务成功概率。进入目标圈但未满足终止条件的轨迹可取得小余距及失败标签。成功、预算截断按原任务记账。沿每个真实前缀监督其本条轨迹的同一终局标签；没有下一步自举、逐步 shaping、额外控制成本或跨专家 max V。距离目标只用于新预测任务。将距离直接用于选 CAP 与按预测任务成功率选择的结果分别报告。

## 学习与时间切片

评分点取每条完整 CAP 命令实际开始前的可见边界，含初态。内部接触拆分仍按原执行器运行。输入包括公开几何、可见性和最近一次可见目标余距、距上次可见的时间、历史最佳/初始余距、1/3/10 条命令的变化、耗时、接触准备/超时/调速计数、两机姿态速度触觉与本 CAP 当前的合法动作参数。误差评估使用终止前最后一条命令的输入；终止反馈不会进入输入。每个 CAP 独立标准化、独立训练两个 64×64 tanh MLP，分别用米制距离的 MSE 和二元交叉熵。3 个训练种子各 2,000 次 AdamW 更新，学习率 .0005，batch 128，均匀抽房间再均匀抽房内命令边界。可部署分数是三种子预测平均，距离物理下限截在 0。各 CAP 及两种目标均不共享网络权重。

主曲线在实际终止时间的 0/25/50/75/90/100% 处取最近一个不晚于该时刻的预测；100% 指最后一次终止前预测。实际终止时间只用于事后汇总，未提供给网络。另报告固定真实 tick 的存活房间指标，并将同一批真正活到第 1,200 tick 的轨迹固定下来，重复比较较早时点。基准包括该 CAP 的开发平均、按已用 tick 分箱的基准，以及把最近一次公开目标余距直接当作终局余距。后者无历史可见目标时用开发平均。报告距离 MAE、失败子集误差、Brier、AUC 和逐轨迹预测跳变。阶段误差差及扰动翻转率的区间按父房间重抽，保留同房间内 CAP 相关性。

## 同前缀动作扰动

预先按房间 ID 哈希和可动物体数选 56 个新房间，7 个 CAP 共 392 个机会。各局在 300 tick 起寻找第一条命令上限至少 12 ticks 的目标物单机平推。仅将该命令时长上限减少 1 tick（名义上 0.05 s），重算后续每条闭环动作直至真实终止。同一前缀校验完整历史哈希、目标与机器人姿态、此前输入。未触发者校验完整终局历史相同。分别记录原/改后实际段末 tick、物体与两机的位姿变化、原/改后终局距离及真实任务成败。时长上限变化有时被早停或调速吸收，仍可能改变程序读取的执行记录；特别列出有可测位移的样本和即时三体位置差均不超过 2 cm、物体角差不超过 .05 rad 的子集。一次动作扰动代表一种具体运行敏感性，不直接估计一般物理噪声分布。示例按实际成功变失败中的最大终距差选取。

## 预测量的选路检验

在每个新房间的共同初态用七位专家各自的预测值选择一位执行到底；完整逐专家实测矩阵给出该选择的闭环结局。基线由开发集分别按真实成败和终距固定，事后真值选择只描述可达范围。

针对此前的常规 s003（A）和专精 s002（B），另冻结两个可在线识别的换手时点：先让 A 到达第 600 或 1,200 tick 后第一个命令边界，仍有合法 B 提案时可改走 B 到底。到时已结束或 B 不可用均保留 A。两位 CAP 的程序记忆和两个预测器都用同一条实际公开历史；未见过该状态的 B 预测器承受换手分布变化。各房间实际重跑这种接手续跑，并和相同初态的 A 自然轨迹配对。分别用预测终距最低与任务成功概率最高来选，用真实成败和终距评价。
