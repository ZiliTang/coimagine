# 专家和混合 actor 的优势在多大邻域、哪个决策时刻可以预测？

两种监督 actor 的相对胜负在 1 厘米上已会改变。到了首次实际动作分歧，公开信息比开局更能区分赢家。按这一信号选后续策略仍少于一直使用动作 actor 的成功数。首次物体接触没有给两组策略提供一致可靠的切换时机。

## 面板与比较对象

在种子 6820420 的自然房间中，按可动物体数 2–5 分层各取 24 个父房间。按固定顺序给每个父房间分配一个世界方向（东、西、北、南），只移动机器人 0 的初始中心 0、1、2、5 厘米，其他初始量相同。要求四个位移都符合原房间的几何合法性。选房间时不读取成败。384 个初态对应 96 个独立父房间，每族只测一个方向。开发池与本实验分开；本批为机制诊断面板。

- actor 对照使用区域十 CAP 库、同一批最快教师示范和 24,000 次更新后的两个 seed17 监督模型。编号 actor 输出十个 CAP 分数，动作 actor 给每个不同的合法提案评分。
- 单专家对照只依据原 160 个开发房间选定。n_s002 的开发成功数最多，n_s009 在 n_s002 失败的房间里新增成功最多。由此得到一对实际有互补性的专家。
- 两组分别执行 928 和 1,022 次闭环（含零位移重复）。每组预选 8 个原始房间，两个策略独立重跑的终局历史哈希均复现。专家程序另在 8 个已有原生轨迹上核对终局哈希。原作者目录后续生成过 Python 字节码，冻结验收使用只含原清单文件的临时视图，对所有受封存文件执行原 verify_frozen。额外的首步交叉实验有 174 次闭环。物理回放另行记录并逐条核对成功、结束 tick 和公开历史哈希。

“保留、翻转、同结局”只看原点一胜一负的父房间。“自身成败翻转”看全部 96 个父房间。有 4/21 个 actor 分歧父房间在沿同一方向的三个实测距离上始终保留原独胜者，单专家为 8/25。

0 cm 原始房间上编号与动作 actor 成功 50、59 次，配对差 +9.38 个百分点，95% 区间 [0.00, 18.75]。按四个半径等权合计为 207、236 次，配对差 +7.55 个百分点，按父房间聚类的区间 [2.08, 13.02]。动作 actor 的闭环成功数在这一局部扰动面板领先。两种 actor 自身的翻转率差在三个半径的配对区间均跨零。此前另一个 200 个自然房间的同预算结果为编号 113、动作 110。一个训练种子、两种打分和监督结构一起改变，跨面板证据还不足以把差异归因于固定编号输出层。

## 哪个时刻有可利用的信息

在开局、两者首次提出不同物理动作、参考策略轨迹首次在公开边界报告机器人接触物体时，比较由两者分别接手直至终局的成败差。actor 的参考轨迹由编号 actor 生成，单专家的参考为 n_s002。如果接触发生在两条原生轨迹已经分开之后，从参考前缀实际重放到该点再切换。首次分歧之前整段前缀相同，因此分歧处的两种续跑与两条原生执行等价。未到达某个时刻的房间不计入该行。

固定的线性岭回归用六折父房间分组预测，四个半径总在同一折。输入为当时的公开几何、机器人速度与接触、两边的实际动作参数；actor 对照还输入原始分数、候选支持者和目标可见性。每折在训练部分估计缺失值均值和尺度，回归目标为另一策略成功减参考策略成功，预测值大于零就切换。为检验时间信息，每行另训练一个只看开局的预测器，使用完全相同的房间、折和后续收益标签。“常选”在每个训练折选平均成功率较高的一方。所有预测均为折外值。

| 策略对 / 判断时刻 | 到达 / 有胜负 | 中位 tick | 只看开局 / 当时信息 AUC | 开局预测 / 当时预测 / 常选 成功数 | 始终选参考 / 另一方 |
|---|---:|---:|---:|---:|---:|
| actor 开局 | 384 / 87 | 0 | .386 / .386 | 214 / 214 / 236 | 207 / 236 |
| actor 首次分歧 | 353 / 87 | 120 | .386 / .595 | 187 / 206 / 211 | 182 / 211 |
| actor 首次接触 | 361 / 65 | 160 | .432 / .444 | 219 / 222 / 230 | 207 / 230 |
| 专家开局 | 384 / 112 | 0 | .451 / .451 | 234 / 234 / 219 | 224 / 236 |
| 专家首次分歧 | 346 / 112 | 0 | .429 / .473 | 206 / 200 / 191 | 196 / 208 |
| 专家首次接触 | 346 / 77 | 130 | .211 / .477 | 207 / 226 / 214 | 224 / 229 |

AUC 只看一胜一负的样本，比较哪一方会赢。当时预测的成功数使用该前缀下实际执行的两条后续，表示在该时刻只选一次。actor 首次分歧的 AUC 配对提升为 .209，按父房间重抽的 95% 区间 [.056, .361]，绝对 AUC 的区间 [.462, .733]。比只看开局多解 19/353，比常选动作 actor 少解 5/353。专家接触时 AUC 也相对开局提升，但绝对值 .477，区间 [.302, .653]。这些数据只定位到三个候选时刻和一种预设读出方法。预测为相关父房间产生的折外结果，区间固定了已经学到的各折读出，不含重训波动；三个时刻的探索性比较未做多重校正。

## 首个不同动作的价值取决于谁接手

96 个原始房间中有 87 个出现实际动作分歧。在同一分歧前缀，各自执行编号或动作 actor 的一个提案，然后固定为同一个后续 actor。这样能把选首步与以后一直由谁控制拆开。

| 固定的后续策略 | 只用编号首步成功 | 只用动作首步成功 | 两首步都成功 | 两首步都失败 |
|---|---:|---:|---:|---:|
| 编号 actor | 7 | 10 | 36 | 34 |
| 动作 actor | 13 | 13 | 39 | 22 |

在 87 例中，更换后续 actor 后有 1 例首步的严格胜负反转，23 例在“一个首步更好”和“两者同结局”之间切换。动作 actor 在本面板原生闭环领先，固定后续后，其提案并未显示稳定的单步优势。[逐父房间四种组合](first_action.csv)

### 同步回放

五组回放有意选取成败不同的分叉，用于查看机理。第 3、4 组为同一父房间的四种组合。两边共享物理时钟，可拖动滑条、逐决策前后跳转、定位干预或直接看终局。场景、物体真值和距离折线只用于离线显示，策略始终使用当时公开的输入。

1. dev_2_23。tick 210 将 R0 从让行改为向西推，两边后续都交给编号 actor。40 ticks 后，最终失败的一侧反而离终点更近（2.353 对 2.571 米）。之后另一侧在 tick 1284 成功。
2. dev_2_07。tick 942 两边目标都距终点 0.371 米。R0 向北推的一侧在总预算前 9 ticks 成功；让行的一侧耗尽预算。
3. 与 4. dev_5_11。tick 71，两侧都还没有物体接触。只改变 R1 从东北移动还是向北移动，指令均为 25 ticks。编号 actor 接手时东北成功、向北失败；动作 actor 接手时结果正好相反。
5. dev_2_14。机器人 0 初始向东移动 1 厘米，两边均用编号 actor。第一条指令已不同，原初态 tick 895 成功，扰动后耗尽预算。

## 对 actor 设计的含义

决策分歧处值得建模“执行某个动作，并按指定方式接手以后会怎样”。结果也提示两项构造监督的要求：同一前缀下比较动作、固定后续控制器。当前结果没有测量提案之外的动作。局部修正能否把轨迹拉回专家可恢复的状态，可以用一个更窄的因果问题检验：保持前缀、后续专家和任务预算相同，只改变一次合法的方向、速度或持续时间，再看能否在未见父房间稳定救回失败并保住原成功。单步距终点缩短在第一个回放中给出了相反的排序，因此应以完整后续成功验收。
