# 区域十 CAP 的剩余时间软标签 actor

沿用最快成功教师的 161 条示范和 6,150 个训练边界。同一初态内，逐步比对实际动作、结束 tick、公开特征和有序候选。一个成功专家与教师有相同历史时，其当前动作获得 1 / 剩余实际 ticks 的权重；从首次不同动作之后停止使用该专家的后缀。相同动作的权重相加，再在合法候选内归一化。失败轨迹贡献零。训练和部署均使用无 trace 的 GA 输入，部署逐步贪心选动作。

983 条成功运行参与构造。3,344 个教师边界有多个成功专家共享前缀，其中 272 个边界有多种成功动作，占全部边界的 4.4%，按训练采样分布为 5.7%。它们涉及 139 个房间，包括 68 个初始边界；其中 71 处另一动作的权重严格高于最快教师动作。16 个独胜训练房间的动作目标都与硬标签一致。

在 272 个有多种成功动作的边界上，若每个成功专家投等权票，48 处会出现最高票并列。按时间加权后的第一动作在 7 处票数严格低于等权最高票。这是对目标分布的核对，未另训等权投票模型。

主比较的自然留出净变化为 -2.0 个百分点，该区间包含零。 同一面板上，开发选定单 CAP 成功 117/200，原 directQ 成功 112/200。

在 272 个具有多个成功动作的训练边界上，24,000 步硬标签与软标签模型选中最高软权重动作分别为 202 与 256 次。沿最快教师输入逐步全对的房间分别为 157/161、82/161。软标签允许多条成功后缀，任务最终通过实际闭环判断。

在 161 个可解训练房间的实际闭环中，固定预算软标签 actor 有 82 个完整跟随最快示范。首次偏离选择了另一条已知成功后缀首动作的有 76 个，其中最终成功 63 个。模型只在原教师边界接受监督，从该分歧点往后的另一条完整示范没有加入训练样本。

两个软标签检查点各执行 215 个训练初态、200 个自然留出初态与 90 个困难族扰动，共 1,010 次。硬标签结果复用同房间已归档闭环。自然面板按房间配对，扰动面板按 45 个父房间配对重抽，每个父房间有两个扰动。区间按物体数分层 bootstrap 10,000 次，条件于本次库和 seed 17。留出面板此前已查看。
