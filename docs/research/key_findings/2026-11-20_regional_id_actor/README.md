# 十维 CAP 身份 actor 与合并动作 actor

同一 seed 17、同一批 161 条最快成功示范，共 6,150 个边界。目标为该条轨迹的教师 CAP 编号，每次决策输出十个独立编号的 logits。训练对合法编号做交叉熵，闭环取最大的合法编号，执行该 CAP 当步提出的动作。每次执行后重新选择。不同编号可提出完全相同的动作。

网络输入沿用归一化后的公开几何历史、十 CAP 固定顺序的提案及预算。隐藏层为 64×64，身份网络 1,562,122 个参数，动作网络 1,573,057 个参数。十维输出层同时改变了监督类别和打分结构，原 actor 对每个不同候选显式输入其动作与来源。

主对照为两模型均训练 24,000 步；次对照均追加 4,500 步，身份模型的续训长度在评估前确定。两者均用 batch 64、先均匀抽房间再抽边界、Adam 初始学习率 0.0003、续训重置 Adam 至 0.00003。

## 开局选择与后续切换

用身份 actor 实际首选编号，在同一房间已有的完整单 CAP 执行中读出一直跟随它的成败，作为开局选一次的参照。另计有过至少一次编号改变且所选动作与前一 CAP 当前提案不同（或前一 CAP 已失效）的房间。

| 更新 | 面板 | 开局选一次 | 每步重选 | 至少一次换编号 / 其中有动作差异的房间 | 相对开局固定救回 / 丢失 |
|---|---|---:|---:|---:|---:|
| 24,000 | 自然留出 | 112/200 | 113/200 | 180 / 122 | 15 / 14 |
| 24,000 | 困难族扰动 | 26/90 | 30/90 | 76 / 48 | 7 / 3 |
| 28,500 | 自然留出 | 114/200 | 109/200 | 179 / 123 | 8 / 13 |
| 28,500 | 困难族扰动 | 27/90 | 30/90 | 77 / 51 | 8 / 5 |

两套身份检查点各完成 505 个场景的独立闭环，另做 215 条共用教师重放。留出面板此前已查看。配对 bootstrap 按物体数分层重抽 10,000 次；困难扰动以 45 个父房间为单位成对重抽。区间仅反映该种子与该程序库下的场景差异。
