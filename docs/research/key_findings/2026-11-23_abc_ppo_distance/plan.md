# A/B/C PPO 的终端距离奖励对照

沿用上一轮基础输入 seed 17。两组从同一个累计 200 局的 actor、critic 和 Adam 状态续训，按同一顺序使用 1,800 个训练房间、36 个 50 局批次，绝对轮次、采样及 minibatch 随机数相同。末轮固定在累计 2,000 局。动作评分器、公开观测、限时、控制器、温度 1、GAE、PPO 超参数和任务成功条件与二元基线一致。

唯一处理变量是训练末端奖励。基线成功为 1、失败为 0。距离组成功为 1，失败为 0.25 × exp(−d / 1 m)，d 为终止时目标物体中心到目标点的真实欧氏距离。距 0.5、1、2 m 的失败奖励约 0.152、0.092、0.034。中间步骤奖励为零，超时和决策耗尽仍按完整失败终止。真实距离在环境终止后读取，只用于训练回报和诊断。它不能出现在部署输入、动作掩码和切换条件中。

复用上一轮的 64 间曲线和 200 间确认面板。此处两者均为此前已查看的诊断数据。阶段化对照前 200 局完全相同，之后每 200 局在同样的 64 间测贪心成功。固定末轮在同样的 200 间估计配对成功差及救回与丢失。重跑二元末轮来提取真实终距，核对成功、ticks 和完整历史哈希一致。另报告两组均失败房间的成对终距差，以检查优化后是否牺牲成功换取更近落点。两组学习速度用各自的二元训练成功和固定房间贪心曲线衡量。
