# 72 束局部中心估计与仅在静止时融合

200 个既有自然房间中，固定 72 束改用局部中心后，冻结专家 A 成功从 93 增至 99，逐例救回 10 个、丢失 4 个。单帧错相为 97，救回 20 个、丢失 16 个。局部中心更有针对性，跨新面板的收益幅度仍待确认。静止融合改善了部分中心估计，但在做过六条件比较的每个房间，相对同一中心估计的单帧错相均未改变终局成败。

相对原版，固定局部中心在原房间及镜像救回 1 个、丢失 3 个，镜像成败不一致由 13/32 降至 9/32。自然首批救回 5 个、丢失 1 个，追加部分救回 5 个、丢失 3 个。两种中心估计下，门控融合相对单帧错相在开发组合计分别改变 26、27 份历史哈希，在自然首批分别改变 17、18 份，终局成功标签逐例持平。这些诊断不足以支持将融合设为默认。

## 两个因素如何隔离

使用专家 A 和同一 split_precision 执行器。中心估计在 CAP 的记忆更新和动作提案中同时生效。局部版把可见目标点、面截距和既有中心统一换到点云质心坐标系，运行原函数后再换回世界坐标。32 个原始初态的编译版结果与上一轮独立几何诊断一致。身体坐标系下每帧 72 束，错相组的奇数 tick 加 2.5°。扫描改动只进入控制器使用的目标面；CAP 仍接收既有 72 束公开观测和候选动作。保持严格兼容要求在错相 tick 另外取得公开扫描，因此这组实验不能解释为传感吞吐优化。

原房间和镜像共 64 例，保留 32 个母房间的配对。另从已用过的 200 个自然确认房间预选 64 个，六个条件在完全相同房间上比较。观察首批结果后，在剩余 136 个自然房间复跑基线、固定局部中心与原估计单帧错相。全 200 面板用于配对诊断。基线全部自然房间复现原专家成败；原始与镜像的固定基线和原估计单帧错相均与上一轮成功数、逐房间 ticks 一致。

## 静止判断和估计质量

任一机器人执行平移 PUSH 或旋转 PUSH，两台控制器均只取当前帧。额外融合仅限同一目标、连续三 tick 均满足无 PUSH 和本机无目标接触的窗口，每步本机平移不超过 2.5 mm，转角不超过 0.2°。首尾两帧同相位，必须命中同一组至少 3 条目标射线，每条量距变化最多 3 mm。通过后只融合当前及前一帧。门控只读可见量；真值用于事后核对。

以局部中心组为例，开发原房间及镜像中，门控接纳 14,786 个机器人时刻，14,783 个满足目标在 50 ms 内平移不超过 1 mm、转动不超过 0.5° 的审计标准。自然首批接纳 8,372 个，8,370 个满足标准。只看通过且经审计低运动的时刻，开发组合格面的数量由单帧 13,894 增至 14,550；自然组由 8,140 变为 8,122。合格要求法向偏差不超过 5°，点到对应真实支持线的平均距离不超过 1 cm。同一条轨迹内多帧相关。

在局部中心加门控的 32 条原始房间轨迹上，每 11 tick 检查一次，至少一台机器人通过门控且目标可见时，用同一份 72 束公开点集分别配合单帧面和门控面，重算局部中心。初始先验均置空，连续调用两次估计器；这个读数用于隔离面片信息，并非替换实际 CAP 的历史。重放历史哈希与原实验逐例相同。27 个房间产生 716 个配对快照，均满足低运动标准。中位误差从 1.38 降至 0.97 cm，均值从 9.68 降至 9.35 cm，P90 均为 38.01 cm。以 0.001 cm 为数值容差，82 个快照改善，7 个变差，627 个持平。

一个长尾例子来自 0_dev_b_dev_4_04 的 tick 462。融合后可见 10 个目标点，拟出 1 个面。程序沿两根轴估的宽度分别是 0.24 m、1.00 m，真值投影为 1.00 m、0.25 m，中心误差 38.05 cm。单个可见面留下了长短轴歧义；本例补点后歧义仍在。此项只定位了一个具体快照。
