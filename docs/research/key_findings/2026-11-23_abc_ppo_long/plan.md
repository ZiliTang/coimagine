# A/B/C 基础输入 PPO 长程续训

以已有的基础输入 seed 17 第 4 轮为父模型，恢复 actor、critic 和 Adam 状态。固定该种子用于首轮长程筛查，末轮预先定为第 40 轮。每轮从相同生成器取 50 个未使用的新自然房间，共追加 36 轮、1,800 局，累计 2,000 局。房间按内容哈希排重。前三份冻结专家、72 束局部中心、split_precision、公开输入、候选合并规则、温度 1、训练目标和超参数与父模型一致。继续使用上一轮的绝对轮次编号确定采样和更新随机数。

固定 64 个此前已查看房间作曲线诊断。按内容哈希排序选固定子集，不用成功标签选房间。每 200 个累计采样局运行一次固定子集闭环，0 与 200 的结果复用当前相同权重的既有结果。实时曲线还显示每 50 局训练成功率、五批滚动均值、动作熵和 PPO 损失。诊断曲线不决定权重选择或训练停止点。

开始续训前冻结另一个含 200 间的自然面板。只在锁定末轮权重后评估纯 A/B/C、监督起点、200 局父模型和 2,000 局末轮。主比较为末轮相对 200 局，按配对房间汇总救回和丢失，记录专家独胜和全败分层。首轮筛查以固定模型种子为条件。增加在线预算的同时也让训练接触更多独立房间，这次衡量两者合计的收益。
