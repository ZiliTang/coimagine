# 进度事件下的专家示范与初始路由

## 训练数据和策略

在 200 个开发房间中，A、B、C 各自独立运行。每个专家在单推稳定接触 3 ticks 和沿指令法向每累计有效推进 0.20 m 时重新提出命令。若自己的合法新提案改变了控制，就立即采用。若该路线失败而同一专家按原命令边界运行成功，则重放原路线，在事件点继续当前命令。50 条这样的重放全部复现了原成功记录的公开历史哈希与执行 ticks。其他专家沿同一条实际历史提出备选动作，输入和掩码与部署一致，重复提案合并。仅有一种合法选择的边界不计入分类损失。

| 开发示范 | 成功轨迹 | 涉及房间 | 可选择边界 | 其中选择继续 |
|---|---:|---:|---:|---:|
| 自动采用新提案 | 366 | 152 | 5,473 | 311 |
| 原边界成功、自动改选失败 | 50 | 40 | 1,011 | 331 |
| 合计 | 416 | 164（去重） | 6,484 | 642 |

416 条中有 3 条全程无可选择边界。原保持示范中的“继续”取自确实成功的完整路线，其标签并不估计单个事件改选的因果损失。训练按房间、该房间含有效监督的成功轨迹、轨迹内的可选择边界依次等概率抽样。基础输入评分器从随机权重拟合，种子为 17、29、43，Adam 学习率 0.001，每批 128，固定更新 4,000 次，无 PPO 更新。按各自最终权重进行贪心评估。

评估面板复用此前进度 PPO 的 200 个终点房间，逐房间内容与开发集互斥。旧监督起点取同种子的无额外语义基础评分器，使用相同的进度事件运行时，按历史接入协议将新增“继续”特征的输入权重置零。旧模型只学习了原始命令边界的成功示范。新旧差异涵盖示范路线、决策状态、样本及标签，不能从该对照单独估计 50 条保持示范的增量。
