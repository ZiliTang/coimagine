# 扩大交接机会的补充验证

在看到开发结果、尚未检查新面板任何终局之前固定本补充方案。主实验在 200 个开发房间仅有一个条件组合达到支持数，且没有正式切换规则。保留主结果，用冻结的探索条件「从公开簇 4 以外进入簇 4」检验时机限制。

沿全 A 的真实轨迹，从每个房间原先分配的第 0、8 或 24 条命令起，在每个边界检查。如果 A、B 提案合法且不同，A 执行该条自然提案后首次进入指定 Y（前一边界满足 X 且不在 Y），到达时两位专家仍有不同合法提案，就在同一历史分别执行 B、A 各一次，其后统一回到 A。每房间最多切一次。以所有 200 个独立确认房间为分母比较成败；在实际触发房间上比较相同接手点的单步物体推进（实际终距减少至少 2 cm）。用基线历史哈希复核全 A；没有触发计入原有结局。这里特意按 A 实际到达选取接手点，不能从该子样本推断 A 比 B 更擅长创造 Y。该问题由主实验的同前缀准备对照回答。补充检验使用和主实验相同的新房间，两项检验共享场景。

另沿 B 自己从初态产生的自然轨迹做同条件检查，读取 B 在自己送达的 Y 上的一条提案推进。分别报告所有触发房间和双方来路均触发的相同房间；不将未配对或不同边界的差异解释为因果效应。
