# 预测优势门槛能否保护最佳单 CAP 的能力

仅在既有专精库中做开局固定选择。对 400 个开发房间按物体数分五折，得到每房间的折外专家成功概率。基础方案为该折训练集选定的最佳单 CAP。只有预测最优相比它的概率优势超过门槛才切换。比较 0 至 0.30 的多个门槛与始终用单 CAP 的规则，按折外成功数选定，同分选换得少的规则。一体化和拆分调速的开发集均选中了始终用单 CAP。之后又冻结 400 个新房间，先决定两种路由的专家分派，再运行各方案选择的专家。

| 执行器 | 开发选定最佳单 CAP | 无门槛的完整语义选择 | 折外选出的门槛 |
|---|---:|---:|---:|
| 原一体化 | 179/400 | 174/400 | 179/400 |
| 拆分调速 | 188/400 | 191/400 | 188/400 |

无门槛语义选择相对最佳单专家，一体化为 −1.25 个百分点 [−3.5, +0.75]；拆分调速为 +0.75 [−1.5, +3.0]。两组都保留实测逐案决策。折外开发数据没有支持一个稳定的概率优势门槛，独立房间的变动尺度仍小。
