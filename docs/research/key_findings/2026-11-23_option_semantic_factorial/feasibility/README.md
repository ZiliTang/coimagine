# 公开局部几何能否预测单次 PUSH 的物理效果

重放三个真实前缀面板的 580 个合法单机分支，共 247 开发、116 第一留出、217 第二留出。按房间等权拟合三个正则逻辑读出。动作参数只有命令时长和速度。紧凑几何增加 target 回波、距离、横向错位、净空和触觉。完整几何进一步检查方向相容的有限面段、法向与机体朝向、站位路径最近返回、终段净空、场地距离、队友间隙、最近移动和公开的接触确认。所有输入都取动作之前。

| 控制器与读出 | 第一留出 AUC／Brier | 第二留出 AUC／Brier |
|---|---:|---:|
| 原 PUSH，动作参数 | .500／.249 | .532／.245 |
| 原 PUSH，紧凑几何 | .538／.291 | .682／.225 |
| 原 PUSH，完整局部几何 | .562／.299 | **.751／.207** |
| 换点 PUSH，动作参数 | .500／.223 | .547／.235 |
| 换点 PUSH，紧凑几何 | .368／.290 | .565／.248 |
| 换点 PUSH，完整局部几何 | .514／.264 | **.660／.218** |

完整几何在第二留出能区分不少前缀的整体可行性，第一留出的校准较差。就同房间内的异结局扰动而言，原 PUSH 的第二留出 8 个房间中，完整几何等权排序约 45%。换点 PUSH 的第二留出只有 5 个这种房间，约 50%。因此现有数据支持观测几何有一些跨前缀信息，尚无证据表明可以从初始几何读出同一前缀的厘米级成败分歧。
