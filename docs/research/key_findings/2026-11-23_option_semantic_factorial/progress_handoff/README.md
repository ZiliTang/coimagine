# 长时低进展时回到最佳单 CAP

沿用置信门槛实验的 400 个新房间和拆分调速执行器，保留开局完整通道语义所选专家。它若与开发集最佳单 CAP 不同，则观察目标物是否连续低进展。过去 55–140 ticks 至少有两次 PUSH 接触超时或估计沿途位移不足 2.5 cm，且这一窗口的目标净移不超过 7 cm 时，允许一次交给开发集最强单 CAP。目标位置来自公开点拟合，程序状态按实际上行公共历史更新。选择器和场景均早于本对照结果冻结。

固定最佳单 CAP 成功 188/400，固定开局语义指派为 191/400，允许一次低进展交接为 189/400。实际触发 7 个房间，救回 0、丢失 2。相对固定开局指派的增量 −0.5 个百分点，配对 95% 区间 [−1.25, 0.0]。未触发情形的执行时长、决策数、完整公开历史与冻结开局指派一致。有限触发下没有净改善，说明这条低进展判据给出的交接时机尚不足，特别是开发优选 CAP 主要在初态分布上验证。
