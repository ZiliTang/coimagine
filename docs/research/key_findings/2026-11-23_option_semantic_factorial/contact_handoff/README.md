# 只在重复接触超时后交接专家

同一批复验房间与冻结的开局完整语义读出。使用拆分调速执行器，开局提交给预测成功率最高的 CAP。只有同一机器人、目标和推向在过去 120 ticks 至少两次发生接触超时，且每次执行不短于 12 ticks、机器人位移不到 5 cm，才询问其余 CAP。一位专家当前提出方向不同或换推手的同目标合法动作，且具备公开接触证据或估计可到达准备位时，允许整局一次交接。各程序按实际已执行的公共动作历史更新。无交接局在 ticks、公开哈希、决策数和成败上逐项等于原开局指派。

| 专家库 | 开局指派，全程固定 | 允许一次接触超时交接 | 发生交接的房间 | 救回／丢失 |
|---|---:|---:|---:|---:|
| 常规 | 186/400 | 187/400 | 3 | 1／0 |
| 专精 | 182/400 | 182/400 | 0 | 0／0 |

这组严格的接触条件和备选提案门槛很少同时出现。专精库结果完全重合，主要说明这套具体触发与筛选规则的可用覆盖小。另一个实验从公开观测衡量实际物体长时间不动，允许回到开发集最强通用成员。
