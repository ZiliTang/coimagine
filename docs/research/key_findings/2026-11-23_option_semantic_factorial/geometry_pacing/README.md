# 按推向计算剩余行程能否改善末段调速

原调速规则在接触确认后按目标距离限速并缩短命令。增加两种候选，一种将触发距离收窄，另一种用公开目标物拟合中心、目标区域和候选推向计算沿射线进入内圈所需的行程，再据此调整推速和时长。两个 CAP 都在相同 64 个开发房间试跑，三种规则的成功数分别为 70、70、71 次（128 次策略执行）。选择最后一种，在另一张 200 房间面板与冻结规则配对。面板与先前的首次调速发现无内容重合，先冻结候选代码，再使用本面板的既有固定调速记录作为参照。

| CAP | 固定调速 | 按推向和余程调速 | 救回／丢失 |
|---|---:|---:|---:|
| s025 | 82 | 78 | 4／8 |
| s027 | 82 | 80 | 4／6 |

两 CAP 平均净差 −1.5 个百分点，按房间配对 95% 区间 [−4.25, +1.25]。开发数据上的一点增益未迁移。固定调速仍用于专家库交叉对照。基于目标物拟合中心计算推向余程，受遮挡、实际接触后的旋转和松手后惯性影响，这轮数据无法分别量化三者。
