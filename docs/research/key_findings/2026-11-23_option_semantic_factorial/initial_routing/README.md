# 通道语义能否在开局选到合适专家

用 400 个开发房间逐专家成败拟合容量相同形式的正则线性预测器，每位专家一条独立概率输出。输入从九维原公开几何逐步加上原作者的三条亚型判据，再加对应的阻挡、目标可见性、通道覆盖度和离墙连续特征。对每个房间仅采用预测成功率最高的专家，整局由该专家完成。测试直接查同一执行器下逐专家的实测整局结果，完全等价于从初态提交这位策略。适用于开局固定指派。

| 执行器与库 | 开发选定最佳单 CAP | 专家成功并集 | 基础读出 | 加三个类型判据 | 加完整通道证据 |
|---|---:|---:|---:|---:|---:|
| 原一体化，常规库 | 188 | 259 | 190 | 182 | 180 |
| 原一体化，专精库 | 170 | 199 | 159 | 166 | 173 |
| 拆分调速，常规库 | 192 | 274 | 187 | 185 | 182 |
| 拆分调速，专精库 | 189 | 225 | 177 | 186 | 194 |

第一组自然留出是 400 个房间。完整证据相对基础输入在专精库内改善 +3.50 及 +4.25 个百分点，按房间分层配对区间分别 [1.25, 5.75] 和 [1.75, 6.75]。在常规库同样加证据为 −2.50 及 −1.25。两库增量相减，一体化为 +6.0 [2.5, 9.75]，拆分调速为 +5.5 [1.25, 9.75]。两个固定专家库的响应不同，两种执行器均有这一信号。专精库的完整证据版本只比各自最佳单 CAP 净增 3、5 个房间，影响尚小。

这项读出沿用已经冻结的作者类别和公开几何。开局窄输入能暴露专家选择之间的差异；逐边界评分器在经历自身动作后还会面对各自的状态分布，不能用此结果代替。
