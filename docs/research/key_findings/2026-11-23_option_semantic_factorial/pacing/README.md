# 末段调速需要在接触确认之后执行吗

在又一批 200 个新房间上，将接触拆分与调速时机分别控制。两 CAP 共 2,000 局，独立房间仍只有 200 个。调速沿用初轮冻结的公开距离、方向、速度与时长规则。未复用末段改选或停滞换手策略。

| 执行方式 | s025 成功 | s027 成功 | 两 CAP 等权成功率 |
|---|---:|---:|---:|
| 原一体化 PUSH | 78 | 78 | 39.0% |
| 一体化，在发 PUSH 前按目标距离调速 | 85 | 79 | 41.0% |
| 一体化，仅在事先已有确认接触时调速 | 83 | 79 | 40.5% |
| 显式拆分，按原速度自动续推 | 75 | 77 | 38.0% |
| 显式拆分，在接触后调速 | 82 | 82 | 41.0% |

在拆分条件中加入调速，平均成功率增加 3.0 个百分点，配对 95% 区间为 [+0.25, +6.0]。拆分后调速与一体化发令前调速的平均差为 0.0 个百分点，区间 [−3.25, +3.25]。拆分不调速相对原版为 −1.0 个百分点，区间 [−4.0, +2.0]。此前同一对 CAP 在首批新房间中，自动拆分比原版高 3.0 个百分点。两张面板共同支持调速是重要因素，拆分本身的净效应不稳定。接触证据仍为更细的诊断与高层控制提供了独立入口。
