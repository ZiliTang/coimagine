# 开局通道证据在独立房间上的复验

沿用第一次开局路由的 400 开发房间、模型、特征和标签。另冻结 400 个新自然房间，预先保存基础读出、完整通道证据读出和开发集最佳单程序对每个房间的专家安排。然后只运行这些预定专家，合并重复安排后实际执行 2,493 局。各案由选出的 CAP 整局执行。

| 执行器与专家库 | 最佳开发单 CAP | 基础读出 | 完整通道证据 | 语义相对基础的净增 |
|---|---:|---:|---:|---:|
| 一体化，常规库 | 203 | 183 | 178 | −5 |
| 一体化，专精库 | 177 | 161 | 173 | +12 |
| 拆分调速，常规库 | 211 | 195 | 186 | −9 |
| 拆分调速，专精库 | 191 | 175 | 182 | +7 |

先按房间平均两种执行器的成败差，专精库加入语义改善 +2.375 个百分点，配对 95% 区间为 [+0.625, +4.125]。常规库为 −1.75 [−4.125, +0.625]。两库的增量差为 **+4.125** 个百分点，区间 [+1.0, +7.375]。两张 200 房间面板的库间交互方向一致。两库仍是原先冻结的作者产物，统计区间描述房间变化和这组固定专家之间的区别。未重采样作者。

独立复验中，语义读出均低于同库开发集选出的最佳单 CAP。专精库中的语义信息仍能帮助较弱的基础读出纠正选择，改善幅度和绝对策略水平需同时报告。
