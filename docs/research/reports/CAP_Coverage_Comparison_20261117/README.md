# 覆盖报告使用说明

打开[index.html](index.html)。可离线运行；每个矩阵单元格可点击查看对应场景ID。GD尚未完成时灰色表示缺失，完成后刷新页面即可看到完整结果。

| 记号 | 本报告中的含义 |
|---|---|
| G | 公开几何与历史编码 |
| D | 冻结CAP库输出的描述性语义数值通道 |
| A | 冻结CAP库输出的动作推荐、候选匹配及程序计划阶段等执行意图通道 |
| CAP-RR-001…010 | 十个冻结的独立程序策略 |
| R0 | 初态快照最近邻检索，选一个CAP执行到结束 |
| Rt | 每个决策边界按快照检索并选择CAP，所有程序记忆均使用真实执行历史 |

四个监督模型共享270条示范、9292个决策边界、相同网络、28000更新/seed17；GD是本次新增。其他模型复用此前expanded版本，不混入repaired版本或新扩数据模型。D和A严格使用原冻结分组，不是另行人工挑选的新语义。

以行方法i、列方法j表示：共同成功=两者均成功数；Jaccard=共同成功/任一成功；补救覆盖=j成功但i失败数；包含率=共同成功/i成功数。共同失败不参与Jaccard；分母为零记未定义。独有成功仅相对于报告中全部已完成方法。

按物体数和覆盖模式排序仅影响显示，不改变比较样本。两种方法覆盖相近不代表动作选择一致；较大事后并集也不意味着已有一个能实现该并集的路由器。此100例已被查看，只作固定诊断，不称新独立盲测；本次为单训练种子比较。

全部图提供PNG/SVG、三页PDF及CSV/JSON。JSON包含来源文件哈希；完整任务协议见[任务书](../../../agent_exchange/tasks/GD_Coverage_Comparison_20261117.md)。

分类细节：A不仅是“候选是否等于推荐”的二值标记，还包括原冻结分类中的phase、planned_direction、导航目标距离等程序内部意图。D包含目标距离/方向、接触与阻塞、观测年龄、进度及候选几何关系。因此GD与GDA比较的是冻结的整组程序意图信息，不能把差异全部解释为单个推荐匹配bit的作用。
