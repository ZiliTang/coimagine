# 用最近 H 个决策边界的程序 trace 为当前动作评分

2026-11-19 讨论 · 开发侧试跑与最高剂量闭环对照均已完成

**假设。** 当几个 CAP 当前的建议难以区分时，近期程序阶段、提案、实际执行和公开反馈之间的关系可能提示哪条路线正在停滞。如果增益主要来自时序 trace，中途重选比开局选择更容易观察到差异。原 GA 几何编码已保留初始观测和最近 8 个边界，各 CAP 也沿真实执行前缀更新自身记忆。[现有运行入口](../../../experiments/planar_tasks/semantic_rl/program_trace_value_v1/runtime.py) · [几何历史编码](../../../experiments/planar_tasks/semantic_rl/relational_transfer_features.py)

**输入和输出。** 每步只保存一次共享几何及预算，分别编码七个 CAP 的身份、有效性、程序 trace、动作建议和可选的冻结 Q 估计。程序的 trace 槽位布局各异，可按 CAP 投影到同宽表示。历史转移记录当时真正执行的动作、来源集合、实际时长和随后已到达的公开反馈。过去所有 CAP 都观察同一条实际执行历史。用当前各去重合法动作及其来源作为查询，对带相对时间位置的历史表示做注意力聚合。到达当前边界为止的输入可见，当前动作执行后的观测不可见；窗口限于同一 episode，开局做掩码。给每个去重候选一个公共选择器续接 Q，再按提案关系映射回各 CAP。若研究承诺持续执行某个 CAP，需要另外定义每个专家的续接目标。

**历史 Q 的来源。** 初试用冻结的无 trace GA-Q，仅依据当时可见的公开前缀生成历史预测。部署沿用同一模型。历史 Q 是可选输入；旧 Q 的乐观误差也可能被放大。若检验跨模型泛化或 Q 教师过拟合，按完整初态分组产生折外预测。离线转移仅给实际执行的动作提供监督，其他候选继续使用掩码；单 CAP 的终局标签和共同路由器的一步自举价值有不同含义。

**对照。** 固定训练集、更新预算、有效历史跨度、候选支持和网络参数量级。先在相同的时序网络上比较无 trace 与仅当前 trace，再加入过去的 trace，最后比较历史 Q 开与关。固定一个短窗口，例如含当前边界共 8 个；应使用单帧几何或明确对齐有效感受野，避免重复堆叠 8 帧几何向量延长历史。补充同输入、同历史跨度的拼接 MLP，可分辨注意力结构与增加信息的影响。主指标为闭环成功和独有能力保留，次要分析为有足够历史后的排序与重选。中途案例的组成随策略改变，机制分析优先比较共同真实前缀。注意力权重仅作描述，因果解释依赖通道屏蔽和独立闭环结果。

**PPO 微调。** 时序 Q 的带温度合法候选分布可初始化 actor，历史状态表示另接一个输出标量 V 的 critic。采样时保存行为 log-prob、实际候选及窗口引用；更新时从同一 episode 重建相同窗口与掩码。在参数尚未变化时可验证还原的概率比为 1。固定窗口内部保持时序，训练时可以打乱不同窗口。用于输入的旧 Q 在一轮比较内冻结。策略梯度更新后将 actor 输出解释为动作偏好；如需评估成功概率校准，独立读取价值头。匹配在线初态、交互预算和评估面板，分别报告无 trace 与时序 trace 的离线起点、PPO 后闭环成功及配对增益。

**LOCAL 与 GLOBAL 的注意力对照。** 同一架构、时间窗口和参数预算下，依次比较无 trace、只读当前候选全部提案来源的 trace、可读七个 CAP 的 trace。用候选动作作查询后，同一场景中不同候选可从不同专家和历史边界读取证据。LOCAL 必须在进入共享上下文或跨专家自注意力之前隔离其他专家的 trace，共享几何和其他共用通道的定义保持一致；历史 Q 若开启可统一采用冻结的无 trace 版本。每个专家每步一个 token 主要学习专家与时间选择，若要验证程序内部的变量选择，可按稳定的程序模块细分并保留缺失掩码。比较闭环保留率及屏蔽非提案来源 trace 后的变化，注意力可视化作为行为检查。

**本轮落地。** 首轮固定八个边界、每步共享几何及七个 CAP 表示，使用当前候选查询整个窗口。历史 Q 和 PPO 留待单独对照。开发侧 12 个训练初态、6 个留出初态已跑通，Q 的留出损失从 0.00645 到 0.00943。正式对照已使用最高剂量 GA-Q 的训练轨迹、seed17、更新预算和同一批 600 个闭环初态。attention 与 GA-Q 各成功 314 和 323 例，配对差 −1.50 个百分点，95% 区间 [−5.50, +2.50]。[完整配对结果](../key_findings/2026-11-19_global_attention/README.md) · [开发侧小样本报告](../../../outputs/semantic_rl/cap_global_attention_20261119_01/smoke/REPORT.md) · [已冻结的对照设定](../../../outputs/semantic_rl/cap_global_attention_20261119_01/protocol.json)
