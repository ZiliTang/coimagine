## 2. 旧模型的问题主要在哪里

**主要显现于训练拟合与检查点选择，不是验证泛化。**
用“只用原 val”规则选出的 Old 三种子，在**自身完整训练集**上物体位置误差 0.181 m、
原 val 0.196 m——两者几乎一样差；同一样本的 persistence 是 0.169 m / 0.158 m，模型比不做预测还差。
所以旧模型首先是**训练集没拟合好**，而不是“训练好但泛化差”。
检查点选择另有独立问题：合同规则 `0.5×原val + 0.5×分支val` 在本数据上退化，
12/12 新 run 与上一轮 Old 三种子都选中**极早的 checkpoint**（新 run 落在 update 100/250/500，
上一轮 Old 落在 epoch 0）。原因是分支 val 总损失在最初 100–500 步先降后升，
规则的最小值永远落在允许的最早点。仍无法区分的是：拟合不足里有多少来自“预算/优化”，
多少来自“宽度/表达”，本轮把它们分开测了（见 §3）；以及终止头是否**因果地**造成非法预测——
目前只有损失与指标不一致的证据，没有梯度或干预证据。

## 3. 更多更新与加宽是否有效（逐 seed 配对）

**更多更新（1000→6000，同宽同数据同种子）**：训练集物体位置误差 11/12 个种子下降
（如 Old+Branch 512：0.216→0.147、0.197→0.149、0.207→0.144，即 −32%/−24%/−30%；
Old+Random 512 种子 1/2 为 −27%/−25%），训练总损失 12/12 下降（0.0119→0.0044 量级）。
但**原 val 总损失 11/12 变差**（如 Old+Random 512：0.0169→0.0226、0.0174→0.0237），
训练集非法率基本不降（仅 Old+Random 512 种子 1 为 −9.9pp，无一种子达到 −10pp）。
结论：**更新更多确实提升训练拟合，但没有传导到验证，也没有传导到非法率。**

**加宽（512−256，同数据同种子，6000 updates）**：训练集物体位置误差 **6/6 为负**
（−0.0006、−0.0305、−0.0237、−0.0737、−0.0286、−0.0492，均值 −0.034），
训练总损失 6/6 为负；原 val 物体位置误差 4/6 为正、分支 val 3/6 为正，非法率有正有负。
512 的墙钟约 24–27 s vs 256 的 19–20 s。
结论：**宽度在同预算下稳定改善训练误差，但同样没有传导到验证**——这更像泛化缺口，
而不是“MLP 容量不足”的证明；也不能排除更宽模型只是优化更便利。
按预定义工程标记（物体位置误差降 ≥20% 且非法率降 ≥10pp 且 ≥2/3 种子同向），
没有任何组达标（Old+Branch 512 训练物体误差达标但非法率仅 −0.8pp）。

## 4. 单步物理改善是否传递到拒绝率与真实候选收益

**没有传递。** 12 个 `best_mixed_val` 模型在 H=3/K=128 固定候选上：候选拒绝率
**0.79–0.92**（上一轮同口径 0.92），无可行候选起点 0–5/12；仅可行候选的 chosen_true
为 −0.53…+0.28，仍普遍低于同一 uniform −0.361；未筛选 regret 2.71–3.02，
执行 regret 2.19–4.26。分解显示：误拒损失 +0.97…+2.62、集合内排序损失 +0.37…+2.02，
即**真实最优候选被自己判为非法而丢掉**与“保留集合内排序错误”都很大，前者更大。
成功识别仍几乎为零：原 test 12/12 模型无成功召回（真实成功 0），分支 test（50 个成功窗口）
召回 0.00–0.06、precision 0.33–1.00（分母 1–4）；真实物理失败仍为 0，**未验证**。
必须注明：D2 按合同只用 `best_mixed_val`，而该规则选出的是 update 100–500 的近初始化模型
（见 §2、errata E4），所以这 12 个模型的单步训练误差本就较差；D1 里 `fixed_6000` 的
原 test 总损失更低但分支 test 总损失高得多，两种选择不能混为一谈。

## 5. 下一步（仅一项）

**在冻结数据与损失的前提下，只改检查点选择：用“原 val 总损失 + 固定晚停”替代
`0.5×原val + 0.5×分支val`，并显式记录每个选点的物理指标。**
证据：同一个 run 里总损失最优与物理误差最优的 checkpoint 从不相同（12/12），
且当前规则把 12/12 个 run 定格在 update 100–500；先用 `best_original_val`/`fixed_6000`
重做一次 D2 就能判定“选择规则”与“模型能力”各自占多少，而不需要新增训练。
在本轮证据下不应再加宽或加数据。
