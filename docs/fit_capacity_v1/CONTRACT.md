## 2. 统一指标合同

每个模型每次评估必须同时记录：

| 类别 | 指标 |
|---|---|
| 损失 | state / hold / duration / termination 四项逐样本均值及其和 |
| 状态 | 物体/机器人 0/机器人 1 位置误差均值与 p90；物体 wrapped 角误差；速度误差（m/s、rad/s） |
| 合法性 | 原始解码预测的非法率、非有限数、违规类型、穿透 p50/p90/p99 |
| 终止 | 固定类别顺序的混淆矩阵；真实成功数、成功 precision/recall；预测成功且非法的数量 |
| 基线 | 同样本 persistence 的物体位置/角度误差，以及模型与它的配对差值 |

raw termination 分类与“通过合法性检查的有效成功预测”分开报告。零正例或零预测正例填 `null`
并列分母，不填伪造的 0/1。真实 `physical_failure` 无样本时填“未验证”。
训练/验证完整物理指标另按 S0/S1、真实成功/非成功分组。主汇总为窗口微平均；
另列按场景先平均后等权的结果；不得把窗口微平均叫“锚点平均”。

## 3. 阶段 B：固定预算训练 × 容量对照

### B1 唯一实验矩阵：12 次新训练

| 因素 | 取值 |
|---|---|
| 数据组 | Old+Random、Old+Branch（沿用既有 matched 数据，各 3684 训练窗口） |
| 模型 | 2×256 ReLU MLP、2×512 ReLU MLP（仅宽度变化） |
| 种子 | 0、1、2 |
| 优化器 | Adam，lr=1e-3，batch=128，其余沿用原默认 |
| 预算 | 每次固定 6000 次 `optimizer.step`；不早停，不看 test 延长 |

- 全部从新初始化开始；不从缺 Adam 状态的旧 checkpoint 声称无缝续训。
- 同 width、同 seed 的两数据组初始参数 hash 相同。
- minibatch 顺序用独立 RNG；同数据组同种子下两种宽度读取完全相同的样本顺序；
  参数初始化不得影响数据 RNG。
- 按 epoch 洗牌并保留末尾小批，循环到 6000 updates；记录 `seen_samples`。
  不同宽度等更新/等样本，不称等算力，另报训练时间。
- 不改 loss、不调学习率、不因初步效果试第三种网络。

### B2 检查点与评估时间

- 固定评估 updates：`0, 100, 500` 及 `250, 750, 1000, 1250, …, 6000`（每 250 次，加 100；去重排序）。
  每个评估点测完整训练集、原 val、分支 val 的四项损失与物理指标；训练期 batch loss 与
  checkpoint eval loss 分开保存。
- 从同一条轨迹保存：固定进度 checkpoint `1000/3000/6000`；`best_mixed_val`
  （最小化 `0.5×原val总loss + 0.5×分支val总loss`）；`best_original_val`（最小化原 val 总 loss）。
- 两种选择都不含 update=0；分数严格更低才更新，并列保留较早者。主规则不换成物理指标、
  不用 test 或规划收益选模型。
- 保存模型、optimizer、所有 RNG、updates、样本顺序进度、配置与数据 hash，保证可恢复；
  每次评估写日志；任务超时不整批重跑。

### B3 预算与异常停止

单训练进程；固定 `torch.set_num_threads(4)`。前 500 updates 估算整批耗时；新训练累计墙钟
预算 60 分钟；预计超限则写清状态并保留可恢复 checkpoint，不擅自给某些组减半预算。
NaN/Inf 停止该 run 并保存最早异常批次；最多两次针对明确实现错误的修复，不做超参搜索。

## 4. 阶段 C：区分预算、容量与选择规则

所有比较先逐 seed 配对，再报三种子的各值、均值与范围。三张表：

1. **训练进度表**：每数据组/宽度的 1000/3000/6000 updates 的 train 与原/分支 val 的位置误差、
   非法率、总 loss。
2. **容量表**：同数据、同 seed、6000 updates 下 512−256 的上述差值与时间。
3. **选择表**：每个 run 的 `best_mixed_val`、`best_original_val`、`final6000` 所处 updates、
   四项 val loss、train/val 物理指标；明确是否“总 loss 更好、物理误差更差”。

解释约束（照任务书）：同宽度随更新改善支持预算/早停限制，但不能称 6000 已收敛；
更宽模型同预算下稳定降低训练误差支持宽度有帮助，但可能只是优化便利；
train 明显改善而 val 不改善是泛化缺口，不据此继续加大模型；
总 loss 下降而非法率不降只说明损失与物理指标可能不一致，不把某个头断言为因果主因；
更宽没有改善不等于 MLP 不适用。

预定义工程标记“明显改善”（仅统一措辞）：相同配对下物体位置误差相对降低 ≥20%（参考非零）
且非法率绝对降低 ≥10 个百分点，且 ≥2/3 种子同向改善；原/分支 val 分别报告。
这不是显著性门槛，未达标仍完成 D。

C 结束后冻结 checkpoint ID 与表格，再打开固定 test。

## 5. 阶段 D：一次固定留出集与候选复核

- **D1**：对 12 个 run 的 `best_mixed_val`、`best_original_val`、`final6000` 测原 test 与分支 test
  （重复 checkpoint 可缓存），报告第 2 节指标；不据此重训或选新 checkpoint。
  原 test 只称固定留出回归集。
- **D2**：只用每个 run 的 `best_mixed_val`（12 个模型），沿用上一轮 12 起点与同一
  `H=3, K=128` 候选缓存；先核对候选、初态、评分、真实参照 hash，缓存完整则复用。
  分别报告未筛选诊断（chosen_true、candidate_best、uniform、selected_bias、regret）与
  执行协议（预测可行候选数、拒绝率、无可行起点数；仅在有可行候选的起点选预测收益最高者）。
  分解：`全部候选真实最佳 − 保留候选真实最佳` = 误拒损失；
  `保留候选真实最佳 − 实际选中真实收益` = 集合内排序损失；两者之和 = 相对全部候选的 regret。
  无可行候选时后三项填 `null` 并列计数。不同模型条件均值需附分母；
  另在双方都有可行候选的公共起点上做 256/512 配对比较。
  精确对照 `J_hat=J_ref` 的 bias/regret 应为 0；预测非法与真实物理失败分开，
  不把拒绝率解释成预测成功率。
- 本轮到此结束：不跑闭环、不扩大 H/K、不增新种子、不为收益调参。
