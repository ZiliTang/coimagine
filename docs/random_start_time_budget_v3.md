# v3：统一物理时间预算，修正快速失败省成本

日期：2026-10-16；用户授权修正预算与奖励组合。

## 变更

- 任务正常失败只由90秒真实物理时间耗尽触发，删除30次联合技能上限。
- 成功仍是中心到达、低速保持0.5秒，立即终止；异常仍单列并中止训练。
- 普通技能失观测/受阻/安全退出只结束该技能，继续下一次联合决策。
- 进展奖励、距离积分成本、时间成本、成功+10/失败−2与gamma=1均沿用v2，不新增补偿项。
- 失败都执行满1800周期，故每个正常失败episode时间成本固定为−3.6。
  时间成本现在只在成功更早完成时减少，不能通过技能次数提前失败减少。
- 距离积分也覆盖全部失败期限，不再因为30次短技能提前停止收费。
- 一个技能至少推进一个物理周期，因此正常episode决策次数自然不超过1800，
  不另设会改变任务收益的动作数终止机制。
- 时间预算必须为正、有限、整控制周期，避免非整周期的预算超时歧义。

## 接口与兼容性

`ENV_VERSION=random-start-time-budget-v3`，删除EnvConfig.skill_budget与SKILL_BUDGET。
旧调用显式报错，不默默忽略旧参数。渲染改为只显示已执行技能数。
原324维输入中的skills_fraction列改名reserved_zero并固定为0，以保持网络维度不变，
不伪称还有技能次数预算。这是输入语义变更；旧策略只能作为明确标注的历史参考，不能直接续训。
分支/训练恢复已有版本校验，拒绝跨版本恢复。
RL默认输出 `outputs/random_start_time_budget_v3/`，长训练默认输出
`outputs/random_start_time_budget_v3_long/`；不覆盖旧数据。

  非整控制周期预算与旧技能预算参数被拒绝。
- 保留成功保持、奖励独立复算、终态禁止继续执行、分支恢复、并行一致性及正常检查点恢复测试。

## 旧训练与后续范围

旧v2长训练已由用户授权的规则修正主动停止，采样进程组收到SIGTERM；
保留旧日志、检查点、冻结源码和回报分解，不把新旧曲线拼接。
旧监督器可能将非零退出码记录为failed；此次退出原因是主动停止以修正协议，非模型数值异常。
新版尚未启动长训练。本轮只修协议并验证，不宣称成功率收益。

移除动作预算后，每条轨迹可能包含更多高层决策；固定8条episode的PPO批次成本可能增加。
这属于任务修正的实际计算代价，不通过隐藏截断恢复快速失败出口。
失败仍可能在90秒内做无效动作；新协议只消除其提前终止省成本的激励，不保证策略学会成功。
