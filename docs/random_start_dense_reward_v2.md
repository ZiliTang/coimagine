# 中心到达 RL：稠密奖励 v2 与机制清理

日期：2026-10-16。用户明确授权替换奖励并审查不必要机制。
这是新奖励契约，不是旧塑形的等价重写；历史实验与源码快照不修改。

## 1. 唯一奖励定义

每真实控制周期 dt=0.05 s，d 为物体中心到目标圆心的真实距离（米）：

```
r_k = 1.0 * (d_k - d_(k+1))
      - 0.02 * d_(k+1) * dt
      - 0.002
      + terminal_event
```

- 正常成功事件 +10，预算耗尽失败 −2；同周期发生时成功优先，不双计。
- 非终止周期 event=0。成功事件只在实际任务结束时发放一次。
- gamma=1：有限时域直接累计，不再用折扣使延迟失败减轻处罚。
- 始终使用真实距离，包括失败/成功最后周期；无终止势函数归零或终止补偿。
- 联合技能奖励只是其真实周期奖励的和，无技能完成、换面、信息增益、接触或绕行奖励。
- 成功条件仍是中心距离≤0.20 m、线速≤0.02 m/s、角速≤0.05 rad/s，连续保持0.50 s。
  地图、物理、技能、时间预算90 s和30技能上限不变。
- 奖励/真值仍仅供离线训练和评价，不进入 actor/critic/GRU 输入或技能控制。

数值依据：保留原进展权重1、成功10、失败−2、每周期时间成本0.002，只新增距离成本0.02/(米·秒)。
靠近1米产生+1；在1米处等待1秒产生距离成本−0.02、时间成本−0.04。
90秒内保持1米距离的累计距离成本为−1.8，成功事件仍为+10。
这些是明确登记的首版工程系数，未调参、未证明最优。

## 2. 实现与可检验性质

- `src/coimagine/random_start/spec.py`：冻结系数，版本 `random-start-dense-reward-v2`。
- `src/coimagine/random_start/env.py`：每周期记录真实距离，技能末统一求和；从原始物理日志独立复算。
- 不同技能切分但相同物理序列，回报相同。
- 同初态/时长的失败，靠近与远离具有不同回报，真实终点差异不再相消。
- 相同终点和时长，较早靠近的距离积分成本更小。
- 静止等待只有负成本，延迟失败不再折扣失败罚分；往返抖动没有进展净收益，仍付成本。
- 数值异常不转化成可利用的廉价失败：非法距离显式报错；训练遇模拟异常立即停止，不用来更新策略。
- 保留完整 MC 估计，不新增 GAE、目标网络、额外价值训练、课程或模仿模块。

## 3. 附加机制审查与处理

| 机制 | 处理与理由 |
|---|---|
| 终止势函数归零 | 删除；不符合失败仍评价实际进展的目标 |
| 周期折扣0.997 | 替换为有限时域gamma=1；避免延迟失败获益，并统一真实进展核算 |
| 默认启动800次独立bandit训练 | 删除函数/CLI；其更新不是实际PPO，且会改变全局RNG；由测试真实update方向替代 |
| 子集缺失则回退到前几个实例、默默过滤清单 | 删除；显式文件完整、无重复、仅train且有成功证据，否则报错；默认scan=64可加载原8个实例 |
| 允许validation名称进入训练子集 | 删除；train名称白名单，validation仅评价 |
| 熵奖励0.01 | 关闭为0；熵仍记录，不额外优化接近均匀分布；随机策略采样仍存在 |
| AdamW隐含weight_decay=0.01 | 显式设为0，删除未登记的参数范数正则化 |
| PPO裁剪0.2、梯度裁剪5、批次优势归一化 | 保留：分别约束概率更新、避免梯度爆炸、缩放梯度；不是额外任务奖励，未声称最优参数 |
| GRU及技能级TBPTT | 保留：部分可观测历史与有界反传；不增加网络或记忆模块 |
| 失观测/接触/无进展/超时退出，碰撞与力限制 | 保留：技能与物理安全契约，不加对应奖励；技能控制未发现读取目标来规划任务步骤 |
| S5旧策略采集每边界重置记忆、混合概率不完整、结构哈希冒充权重哈希 | 本轮不扩展修复采集系统；直接禁止checkpoint/trial CLI，避免旧机制被当作可用数据路径 |
| 默认结果写入旧审查包 | RL与schema采集默认改到v2目录，禁止覆盖既有初始模型；旧v1重训/诊断入口拒绝用v2奖励运行 |
| 旧奖励检查点/分支继续执行 | 恢复状态增加环境版本校验；不跨奖励版本续训或恢复 |

“保留”表示有明确功能/契约依据，不表示已经做过全部消融。此次审查范围是当前random_start奖励、
RL、相关采集/恢复入口与技能控制的数据流，并非声称全仓库历史模块均已审计。
