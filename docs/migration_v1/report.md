## B. 旧 Grid 候选选择偏差诊断

固定前 20 个场景、H=1/2/3、K=16/64/128、种子 0/1/2；同一 H 内由确定性随机顺序给出嵌套
候选集；模型从初始输入推演整条固定序列，中途不读真实状态；真实侧在与“机器人自己观测
一致的世界集合”上逐世界执行并取精确期望（不使用 θ 边缘×状态）。检查全部通过：嵌套、
mock（J_hat=J_ref）偏差与 regret 为 0、候选顺序不改变真实轨迹、检查点 SHA256 不变。

**结论：支持“选择性高估”。** 选择偏差在所有 H/K 为正（+0.39…+0.56），而候选均值偏差在
H≥2 时接近 0 或为负，超出项随 H 从 0.41 升到 0.76，regret 从 0.03 升到 1.29。代表案例：
场景 3、seed 0、H=3、K=128，选中 candidate_id=10，J_hat=+8.79 而 J_ref=−2.50。证据限度：
只覆盖“固定序列、不中途重规划”的策略类；H=1 仅 6 条、H=2 仅 36 条不同序列，更大 K 复用
同一集合。

## C. 连续 2D 环境

使用 Pymunk/Chipmunk 6.9.0（官方 wheel，锁定版本）。俯视平面、零重力、显式黏性阻尼；
机器人是有力上限的圆盘，物体只通过物理接触受力；reset/restore 外无写位姿。实现
reset/export_state/restore/step_control/execute_joint_skill/rollout，三个反馈技能
`move_to`/`push_contact`/`hold`，同步联合技能窗口 2 s（40 控制周期，6 物理子步）。
候选模板由公开几何（物体位姿、目标、墙）生成，含面采样接触点与内向法向。

物理验收 10/10 通过：初态无接触；静止物体不自行移动；偏心推的转动响应可区分；力不超上限且
机器人不进入物体内部；接触推动不计失败；最大穿透 0.0011 m；相同前缀完全复现；快照克隆与
精确前缀重放一致；候选副本互不污染；成功需目标内低速保持 0.5 s；S1 witness 可复现完成。

## D. 精确模型 MPC 与数据

统一候选生成器用于规划器与随机对照。排序键：成功优先；成功按完成时间、控制用量；失败按
物体到目标的几何距离（含通道可通行性的几何代价）、朝向误差（本轮无终点朝向，恒为 0）、
控制用量；并列按稳定 candidate_id。执行首个窗口后重新观测、重新规划。

工程门槛：S0 与 S1 各至少一个场景被 depth-3 MPC 完成；S1 的成功计划包含准备性动作
（先改变朝向再通过通道）。depth-1 解全部 5 个 S0，但 S1 只解 1/5；depth-3 解 2/5 个 S1；
随机对照 0/30。depth-1 与 depth-3 计算预算不同，已分别报告节点数、物理步数与墙钟时间，
未宣称公平。

**depth-3 并非一致更好（反例）**：S1_v1 上 depth-1 成功（7 窗口），depth-3 beam=3 失败（12
窗口）。限定诊断显示这是**束宽伪影**：beam=1 成功（7 窗口，20 s），beam=2/3/5 全失败。固定
字典序键在 3 窗口想象序列上选出的首窗口，在滚动执行下并不最优。S1_v2、S1_v4 两种深度都失败。
方向与旧 Grid“搜索越深越差”一致，照实报告，不据此宣称深度无用。
