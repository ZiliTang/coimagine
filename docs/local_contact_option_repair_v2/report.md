## 0. 旧结论：保留 / 撤回 / 尚不确定

**保留**
- 分阶段协议把终态速度压下来：O 中位 0.1634 m/s → P 0.0073 m/s（N 对 F 为 0.0343 → 0.0078）。
- 位置扰动敏感度 N 优于 P：10 mm 位置扰动终态 P90 0.0055 对 0.0137 m（配对 bootstrap 见 tables）。
- N 的假稳定仍为 **0**（625 次判稳中 0 次；P 为 13/565 = 2.3%）。
- 相同 0.26 m/s 命令下新控制仍然明显少推：N 0.284 m 对 P 0.423 m，实际速度 0.142 对 0.275 m/s。

**撤回**
- 「N 几乎总能判稳」：v1 的 92.8% 判稳率是在**把位移当速度**、与 0.02 m/s 门槛比较时得到的；
  修好单位、加时间戳新鲜度（0.20 s）与 RMS 聚合后降到 **65.1%**（P 90.5%→58.9%）。
  因此「零假稳定」这个数字保留，但它 v1 时的**证据强度撤回**：当时的门槛基本不起作用。
- 「角度敏感度也更好」：G5 现在同时检查角度，N 相对 P 的 10 mm 角度 P90 从 0.0192 升到
  0.0215 rad（**+12.2%**，绝对差 +0.0023 rad），超过 +10% 上限 → **G5 整体不通过**，角度结论撤回。
- G2/G4 的旧 92.5% 分母：改用指定主分母 solo_central+dual_same_side（40 root），
  次要分母（四可推动类 80 root）另列，不把旧数字搬过来。

**尚不确定**
- 65.1% 里 190 次 `settle_timeout` + 82 次 `settle_unobserved` 有多少是真实残余运动、多少是
  2 mm 射线量化与最近邻匹配噪声，需要一个受控的「已知静止」基准才能分离。
- P 的 13 次假稳定是否全部来自旧公式的停手时机，样本太少，不足以定论。

## 3. 最终回答

1. **判稳与延迟修复后，零假稳定仍成立；低敏感度只在位置上成立。** N 判稳 625 次零假稳定，
   但判稳覆盖率从 92.8% 掉到 65.1%，延迟变体下 `settle_unobserved` 明显增多（延迟帧不能无限
   参与判稳）；位置敏感度仍显著更好，角度敏感度**不再**更好。
2. **分阶段协议仍有收益，代价是约 3 倍墙钟。** P 对 O 终态速度中位 0.1634→0.0073 m/s，
   墙钟 2.00→5.78 s；N 对 F 为 0.0343→0.0078 m/s、2.00→6.30 s。分阶段位移表显示这些时间花在
   READY 握手与 BRAKE/SETTLE 上，而不是更长或更强的预推动（P 的预推动位移仅 0.008 m）。
3. **相同 0.26 m/s 命令下，新控制仍明显少推：位移比 0.67、实际速度 0.142 对 0.275 m/s，
   两者力饱和都是 0。** 差距是参考速度跟踪问题而非稳定性问题，**值得做一轮速度跟踪校准**；
   但在校准把 G4 拉回 0.80 之前，不建议启动大规模 option 数据采集。
4. **三步真实正常完成率：N 7/12、P 7/12**（三步都有效推动且判稳；入口资格 12/12，
   假判稳后仍继续的案例 0 次）。
