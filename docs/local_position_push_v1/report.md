## 1. 实际实现的 p_ref 与它依赖的观测

```
d         = dot(c − p, n)          c = 观测片段质心，n = 滤波后的内向法向
q         = p + d·n                机器人中心到局部支撑线的垂足
p_contact = q − r·n                无压入时的接触中心参考
direction = cosα·n + sinα·t        t = Rot90(n)
p_ref     = p_contact + β·δ·direction   β 从 0 线性升到 1，0.20 s
e         = p_ref − p；e_b = clip_norm(e, 0.10)
F         = clip_norm(Kp·e_b − Kd·v, 15 N)     Kp=100 N/m, Kd=25 N·s/m
```

只用了白名单观测：自身位姿/速度、机器人坐标系下的片段点集与其拟合线段、滤波法向、技能 δ/α。
垂足若离开观测线段切向范围超过 0.01 m 且持续 0.15 s，标 `patch_support_lost` 并按公共协议中止；
`gap_signed = d − r` 允许为负，不做 `max(gap,0)`，真值穿透从不回喂。

**是真的位置反馈**：静止时 `∂F/∂gap = Kp = 100 N/m`（测试逐点核对），正间隙推、负间隙拉，
符号随 δ 关闭后完全由间隙决定。

## 2. 零间隙等价性与差异发生的位置

零间隙、β=1、未限幅时 `F = Kp·δ·direction − Kd·v`；取 `δ = Kv·s/Kp`、`Kd = Kv` 则与 V 的
`Kv(v_ref − v)` 完全一致。测试在 s∈{0.08,0.16,0.26}×α∈{0,0.25,−0.35} 上比较两套**实现**，
最大差 1e-9，通过。实测 PUSH 期 `gap_signed` 中位 **−0.0001 m**，所以两臂在推动期确实近似同一律。

差异只出现在两处：**PUSH 起始 0.20 s 的 β 爬升**（力被按比例压低）与**间隙项 Kp·gap**。
APPROACH/READY/BRAKE/SETTLE 是同一份实现，首周期逐位相同（有测试）。

## 4. 是否值得保留

**作为控制器：不值得。** X 是所有指标里更差或持平的一方，而且差异方向明确指向实现语义而非
噪声：同一律下多出 7 个百分点的接触丢失与 1.3% 的 `patch_support_lost`，位移少 21%。
根因是 β 爬升期推力被压低、以及间隙项在压入时反向拉，二者都会削弱跟随。
它不是"更稳但更慢"的权衡——终态速度、假稳定、判稳覆盖都没有变好。

**作为表示：值得保留。** δ 是一个有几何含义的长度（不是"预期位移"），p_contact/p_ref/q
可逐周期检查，这使技能参数比"速度 s"更好解释。若下一轮要做技能终态学习，X 的参考几何是
更自然的输入/标签表示，但**必须另起一轮证明收益**，不能把"更易解释"当作控制改进。

## 5. 下一轮能否开始小规模技能终态学习

**证据不足，不要开始训练。** 三个硬障碍：(a) X 不是更好的控制器，用哪一臂做教师未定；
(b) 判稳覆盖率只有 0.62–0.67，约三分之一的执行没有"终态"可学；(c) X 的接触丢失率 0.153，
样本里会混入大量非正常终止。补齐路径：先把判稳覆盖提高到 ≥0.90（此前已知表面法向速度 RMS
门槛偏严），再在 V/X 之间用同一份数据做一次表示对照，然后才谈训练。
