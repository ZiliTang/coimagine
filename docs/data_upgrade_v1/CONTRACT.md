# CONTRACT — data_upgrade_v1（基线修复与成功轨迹分支数据升级）

任务书 `docs/tasks/20261012_2137_CoImagine_基线修复与成功轨迹分支数据升级任务书.md`。
本文件在任何正式运行之前冻结；实现不得静默偏离，偏离需要新版本。

研究问题：当前单窗口世界模型的不足，是否主要与训练数据缺少任务相关状态及动作后果有关。
允许“数据升级无效”；不要求优于随机，不要求暴露高估。

## 0. 不可变项与版本

- 平台、场景（十场景最新合法版 `closeout_v2`）、物理参数、2 s / 40 控制步窗口、
  三个技能控制器、真实成功（`object_in_goal && object_slow` 保持 `success_hold_time`）
  与真实失败判定：全部冻结，本轮不改。
- 网络仍是 2×256 ReLU MLP（`continuous2d_learning.model.ModelConfig` 默认值）、
  原输入语义、原损失（状态 MSE + hold MSE + duration MSE + 终止 CE，系数各 1）、
  Adam lr=1e-3、batch=128、最多 100 epochs、patience=12。
- 候选生成规则、评分 `J = 10S − t/24 − d/L − 20F`、失败罚项与几何阈值：
  沿用 `forecast_baseline_v1`，候选文件沿用，不为某个模型重新挑选候选。
- 精确物理引擎只用于离线数据和诊断参照；学习模型在线规划不得查询真实未来。
- 旧结果与旧 checkpoint 原样保存；本轮所有新结果写到新目录。
- 每个实现问题最多两次有明确依据的修复，记录原因与影响范围，不重构项目。
- 本轮不实现：多尺度、接触模式模型、合法域投影、新损失、集成、分布式融合。

## 1. 阶段 A：修复已确认问题

### A1 Grid 聚合（`deterministic_grid/audit.py::aggregate_by_state`）

`model_seed="mean"` 行只对学习种子 0/1/2 求平均；精确模型（`model_seed=-1`）单独成行，
绝不进入任何均值。验证：
- 各状态重复次数相同时，“先状态内平均再跨状态平均”等于全部学习模型行的平均；
- 该差异不得解释成 3/4 倍关系；
- 旧验证集 H=4/K=256 重新得到约 `1.250 / −1.450 / 2.700`；
- 新验证集约 `selected_bias 0.867 / mean_bias −1.719 / excess 2.586`、`regret ≈1.075`、
  `chosen_true ≈ −5.650`（仅作定位参考，正式值由全精度记录生成）；
- 手算样例：一个精确行 + 两个非零学习行，精确行不进入均值。
只重算统计，不重训 Grid。

### A2 Grid 单候选反事实（`build_traced_case`）

新主分析：
1. 缓存全部候选的原始 `J_hat`，记原选中编号 c；
2. 只对 c 的首次指定错误做一次修复并继续该候选的模型预测；
3. 只替换 `J_hat[c]`，其余元素逐项不变，然后重排；
4. 同时报告新选择的**真实**收益是否改善（“选择改变”≠“修复有收益”）。
两类干预 `full_state` / `object_anchor`；`false_success` 通过替换整个真状态实现，命名为
“首次虚假成功处的完整状态干预”。物体位置干预若使组合状态非法，按原协议终止，不再补修
机器人位置。旧“全部候选干预”结果作为历史附件保留并更正因果表述。

### A3 连续终止与可行性协议（`closed_loop.py`、`rollout.py`、`contract.py`）

- 闭环选择只允许 `exit_class ∈ {window_complete, success}`。
- `invalid_prediction`、`non_finite`、`physical_failure` 都不得被执行。
- 无可行序列 → `planner_no_feasible_plan`，`live_env` 不再前进一步；记录停止时刻、已用时间、
  末端距离，作为独立任务失败原因，不与真实物理失败混称。
- 离线固定候选诊断保留全部候选的分项与 J；**另行**记录按闭环可行性筛选后的选择/拒绝，
  两种结果分开命名，不混成一张 `chosen_true` 表。
- 预测同时声称 success 且状态非法时，非法/非有限优先。
- 初态已成功/已失败：直接吸收，不调用模型展开。
- 修正几何检查中 y 用 arena width 判界的错误，改回 height；核对预测检查与环境的越界语义，
  以冻结的环境合同为准。
- 测试覆盖（构造输出，不改模型）：全非法、合法与非法混合、非法+success 冲突、全合法、
  终止吸收。

### A4 报告与旧测试

- Grid 递归累计终止率由原始 JSON 重算并更正（旧 STATUS 的 0.918 与明细表 0.137 不一致）。
- 连续状态不再用“完全相等错误率”；改用固定容差：任一体位置误差 > 0.05 m、
  物体角度误差 > 0.10 rad、错误终止或非法预测；三项另列独立发生率。
  正确成功吸收不计错误；teacher / recursive 各自独立的累计变量。
- 允许更正过期测试：正向“简单自由空间可解”用已确认可解的 S0_v1；对修复后的 S0_dev
  验证初态合法性 + 协议，不改场景、不删正向检查。
- 输出 errata；A 完成后 Grid 冻结。

## 2. 阶段 B：几何、拟合与旧基线验收

### B1 几何检查验收

把几何检查用于原数据全部真实窗口末状态，按真实成功 / 普通窗口 / 物理失败分组统计：
真实正常状态被判非法的比例；`robot_object / robot_robot / robot_wall / object_wall`
各对穿透；engine 接触/穿透记录与独立几何检查的差异。误判记录逐条保存。
先确认快照时刻、形状尺寸、边界半径与穿透定义一致；“有接触”不算失败。
阈值附近的差异必须解释；出现超过数值容差的系统性不一致且两次修复仍不解决 →
`GEOMETRY_BLOCKED`，停止 C/D。

对旧模型预测状态同样分组输出穿透 p50/p90/p99、违反阈值的类型与比例。

### B2 编码与小样本拟合

- `encode_state_target → apply_state_delta` 往返能恢复真实下一状态（角度按周期等价比较）。
- 核对 loss 的角度残差是否按合同 wrapped；若有实现偏差，修复并统一应用到 D 的三个正式组。
- 从原 train 选 32 条不同转移：16 条平移或转动、8 条静止、最多 4 条真实成功、其余补齐；
  组内按固定 SHA256 排序、不看模型误差、去重；保存样本 ID；不从 val/test 抽样。
- 同结构、新初始化 seed=0、原损失、Adam lr=1e-3、全批最多 3000 更新；checkpoint 不用于
  正式评估。目标（同批 32 样本）：物体位置 ≤0.02 m、机器人各 ≤0.03 m、
  物体角度 ≤0.05 rad、终止类别 ≥31/32、无非有限输出；同步报告非法率，不做几何投影。
- 未达标：查训练曲线/梯度/归一化/字段顺序/冲突标签，最多两次针对性修复；
  仍失败 → `FIT_CHECK_FAILED`，停止正式扩充训练，交付诊断。不换网络结构。

### B3 原模型分组与闭环复核

三个原 checkpoint 在原 train/val/test 上：各体位置、物体角度、速度、终止混淆、非法率；
平移/转动/静止、接触/无接触、任务族分组并列样本数；与 persistence 的逐样本配对差值。
全链累计错误使用 A4 的固定容差；存活链与全链分别列分母。

用修复后的 A3 重跑原 36 个学习模型闭环回合；精确/随机结果仅在哈希与定向复核一致时复用，
否则重跑。保留第一次旧协议结果，并说明其 59 次非法执行涉及 22 个回合。

## 3. 阶段 C：成功轨迹附近的分支数据

### C1 划分

train：S0_dev/S0_v1/S0_v2、S1_dev/S1_v1/S1_v2；val：S0_v3、S1_v3；test：S0_v4、S1_v4。
原 test 已被研发过程查看，只称固定留出回归集。新分支 val/test 在正式训练前生成并冻结。
禁止同一锚点及分支跨 split；保存 `teacher_episode_id / anchor_id / branch_id / prefix /
scene hash`，不逐转移随机拆分。

### C2 引导轨迹（精确模型只用于离线采集）

每场景用修复后的 `exact_fixed_pool`、H=3、K=128、最多 12 窗口，episode seeds={0,1}；
两条都失败才允许 seeds={2,3}。每场景最多 2 条真实成功轨迹；所有失败尝试也记录；
最多 40 次精确规划回合。某场景无成功 → 报告缺少引导，不用 test 场景补训练。
train 的 S0 或 S1 整个任务族无成功 → `GUIDE_COVERAGE_LIMITED`，停止正式分支比较。
val/test 某族缺失则明确评价缺口。原始成功轨迹的窗口转移进入对应 split；
只记录真实执行标签，不用精确模型预测状态当监督。

### C3 锚点

仅从真实非终止窗口起点取锚点，不从吸收成功状态继续采样。先保留最后两个非终止窗口起点，
再按窗口序号均匀选其余，去重至最多 6 个；轨迹短则全取。使用完整精确快照/前缀恢复并保留
`success_counter`；不平移/不扰动状态。锚点进入新窗口时控制器按既有规则重置。

### C4 分支

每锚点首动作：1 条原引导下一联合技能、1 条双方 hold、4 条邻近动作、10 条 root 库均匀随机；
全精度结构化技能，去重不足 16 用 root 随机补齐。邻近动作 = 在现有 root 技能库中按双方
`skill_features` 与专家首动作的平方距离取最近 4 个不同候选，稳定 ID 打破平局，排除已选；
该规则只用于离线采样。之后最多再执行 2 个窗口：0.5 重复上一联合技能、0.5 从当前真实公开
观测的 root 库均匀采样；种子由 split/scene/teacher_episode/anchor/branch 派生；
成功或物理失败立即终止。保留全部分支，不按收益筛除。预算：每引导 ≤6×16×3=288 分支窗口；
train ≤12 引导（3456）+ ≤144 原引导窗口；val/test 各 ≤4 引导（1152）+ ≤48 引导窗口。

### C5 RandomAdd 对照

原采集策略、从原场景初态开始、最多 12 窗口、首窗口均匀随机、后续 0.5 重复 / 0.5 root 均匀；
不使用专家轨迹或锚点；各 train 场景新增有效转移数尽量与 BranchAdd 相同；固定种子、
确定性顺序，不按回报筛选。采集上限为 BranchAdd 总有效转移数的 3 倍尝试窗口；
达到上限仍不足则记录真实缺额；等数量比较使用两者各场景可用数的较小值，按固定哈希取样。

两组新增数据按“完整输入、动作、输出、持续时间、终止标签”去重，并排除与原训练数据完全
相同的转移；保留来源索引。相同输入不同标签必须列出冲突，不静默合并。轨迹边与 episode
结构保留，单独建训练索引。

### C6 覆盖报告

分别报告 Old / RandomAdd / BranchAdd：场景、回合、独立锚点、不同状态、不同 state-action 对、
窗口数；平移/转动/静止（阈值 0.01 m / 0.02 rad）、技能组合、接触类型；真实成功终止窗口、
近成功非终止窗口（物体角点全在目标区内但未满足低速保持，不得标为 success）、物理失败窗口；
同锚点不同动作的真实进展差异。
成功窗口 < 20 或来自 < 4 个 train 锚点 → `SUCCESS_COVERAGE_LIMITED`（只限制成功类结论）。
物理失败为零允许，不制造失败。

## 4. 阶段 D：同结构数据对照

三组：`Old`（原 train）、`Old+Random`（原 train + 等数量 RandomAdd）、
`Old+Branch`（原 train + 等数量 BranchAdd）；各 seeds={0,1,2}，共 9 次正式训练；
相同种子相同初始化；沿用原网络与训练协议；记录更新次数、采样数、训练时间；
不声称严格等计算量；不每组单独调参；不按 test 挑种子。

checkpoint 选择（训练前冻结）：
`val_score = 0.5×原 val 平均原损失 + 0.5×新增分支 val 平均原损失`；
无分支 val 则标记验证不足，不临时改权重继续正式比较。验证集含成功数据只用于选 checkpoint。

预测评估：所有模型同时评估原 test 与新增分支 test，不合并成单一总准确率；沿用 B 的指标，
新增成功召回率与 precision（写明分母）、同锚点多动作的真实/模型进展排序、
非法预测导致可行分支被拒绝的比例。分支集按锚点先汇总再按场景报告。

固定候选：沿用原 12 起点、原候选池、原精确参照（哈希匹配后复用真值）；只复核
H={1,3}、K={16,128}、原三个候选种子；三组九个模型使用完全相同的候选文件；同时报告
“全候选按 J 排序”与“仅可行候选选择”；筛选后无候选时记录拒绝率、conditional regret 记 NA，
不填 0、不删起点。

闭环：S0_v4、S1_v4；学习方法只跑 H=3：3 组×3 模型种子×3 episode seeds×2 场景=54 回合；
exact H=3 的 6 回合与 uniform 的 6 回合在协议/哈希一致时复用，否则重跑；最多 12 窗口；
沿用 A3 筛选；模型预测 success 仍只执行首窗口；`no_feasible` 作为独立任务失败原因报告。
不得临时扩大 K/H、调罚项、加投影或改场景。至少保存 2 个改善与 2 个无改善/退化对照案例，
没有就如实说明。

## 5. 结论判据与停止条件

- Branch 比 Old 好但不比等数量 Random 好 → 支持数据量/覆盖改善，不支持分支采样额外优势。
- Branch 在关键转移误差、非法率与候选选择上同时优于 Random → 支持任务相关分支覆盖有帮助
  （仍只是小规模工程证据）。
- 状态误差改善但排序/闭环未改善 → 指出误差未转化为决策收益。
- 成功识别改善但非法率仍高 → 不宣布世界模型可靠，分开定位几何预测。
- 三组连训练集关键样本都拟合不好 → 报告拟合问题。
- 训练集好、留出场景差 → 报告泛化/覆盖问题。
- 结果无规律 → 报告不确定。

`GEOMETRY_BLOCKED` / `FIT_CHECK_FAILED` 停止 C/D；`GUIDE_COVERAGE_LIMITED` 停止正式分支假设
比较；`SUCCESS_COVERAGE_LIMITED` 只限制成功类结论。所有停止状态写明已完成、未运行、
最小复现与下一项具体需求。
