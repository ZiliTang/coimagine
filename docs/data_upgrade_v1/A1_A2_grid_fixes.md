### 2.2 与上一轮同一批追踪状态的对照

四个追踪状态（role / 模型种子 / 候选种子 / state_key / 原选中 id）与上一轮完全一致：True。上一轮的高 regret 案例仍是 `(3, 4)/(0, 2)/(1, 2)`、`(4, 3)/(1, 3)/(2, 2)`、`(5, 5)/(1, 2)/(3, 1)`。

- 单候选 `full_state` 干预仍对 3/3 个高 regret 案例改变了选中候选，但新选择的真实收益改善只有 1/3（`(3,4)` 案例 −5.5→−4.5）；单候选 `object_anchor` 为 3/3 改变选择、1/3 真实收益改善。上一轮“3/3 改变了排序”的说法成立，但它不等于修复有收益。
- 上一轮关于虚假成功案例的句子（“只修复该候选自身这一次虚假成功后对全部候选重排，选中 id 变为 12”）描述的是旧全候选重排；本主分析的单候选干预也把 id 变为 12，但真实收益没有改善。全候选版本现作为历史附件单列。

## 3. A4 Grid 递归累计终止率对账

定义：recursive 模式在固定真实轨迹上从自身上一合法预测继续；非法预测立即终止、预测成功吸收；累积终止率 = 到该步为止已终止链数 / 全部链数；末步即累计终止率

| 新验证集 | 4 | 16 候选×每状态 | 0: 48/320；1: 43/320；2: 41/320 | 0.137 | 0.164 |
