## 3. 原 probe 分析的错误

`experiments/option_rl_v19/analyze_d007.py::body_t_at` 读取 `effect.n`，但原始记录实际字段是 `effect.face_normal`。缺失时脚本静默返回备用方向，最终**两台机器人都被投影到世界 Y**。

robot0 的面法向约为世界 X，切向约为世界 Y，误差暂被掩盖；robot1 的面法向约为世界 Y，切向约为世界负 X，故原脚本主要测了它的法向运动。镜像的 +t 也被错误固定，导致 G 正负抵消。把这种抵消称为“符合镜像”不正确：按各自局部 +t 定义的增益应保持响应语义，不能直接抵消求中位数。

此外：

- 使用世界绝对位置差，未减物体平移、未转换各轨迹的物体坐标系；原 G≈1.36–2.69 不能解释为接触相对位置的真实增益。
- `contact_ticks` 累计整条 5 s，而有效条件要求扰动窗口 2–3 s；support 用绝对值而非请求方向；未检查 anchor 切换/跳面。
- 额外加入响应末窗 `abs(dq_target)>=.02` 条件，任务规定的是扰动窗累计支持≥.5 s，两者不等价。
- `near_ready_ticks` 实际读取 ready，不是 contact_ready；goal_distance_end 从不存在的 after 字段读取并默认 0；`analysis.source` 仍写 `_001`。这些字段不能直接引用。

所以旧 probes.csv、增益汇总与部分链路图需要订正；不能作为修控制逻辑的依据。

## 5. 实际链路：偏移已进入，参考估计随轨迹变化

全部 16 条 probe 的 2–3 s 窗口，`target_before_visibility → target_before_reservation → target_final` 差均为 0；本面板没有证据表明可见性或 reservation 裁掉了 probe。

将未投影 target 拆为：

```
target = reference_without_offset + t*(point_offset + role_offset + q_rot)
```

在各轨迹物体坐标系中比较零扰动基线，直接 offset 对目标的响应归一化后约为 **1.000**；说明偏移正常写入。差异主要来自 `reference_without_offset` 随观察/跟踪历史改变，后段抵消甚至反转净目标差。

例如 adjacent/B/robot1/−4 cm，在 2.8–3.0 s：直接 offset 增益约 +1.000，跟踪参考项约 −1.547，净 target 增益约 −.547；C 对应为 +1.000−1.163≈−.163。这里是相对两条闭环轨迹的分解，不等同于相同瞬间状态上的开环导数。

支持的解释：**目标生成中的 offset 通路存在；跟踪参考点的变化会显著干扰净目标与真实侧移的关系。** 尚不能把所有参考变化定为 endpoint 算法错误，也不能从命令力推断实际接触力矩。
