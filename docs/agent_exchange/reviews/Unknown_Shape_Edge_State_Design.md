# 未知物体形态：局部边状态估计的设计约束

2026-10-30，GPT；记录用户本轮明确修正。本文是设计约束，不是已实施算法、任务书或实验结果；不改变历史 D008 的执行记录。

## 1. 用户目标与信息边界

不把物体尺寸、完整形态或中心作为控制器已知先验。允许不同物体具有相同可见面、不同背面形态。策略应根据推动目标、已有运动/接触反馈和绕行成本，决定是否实际绕到背面获取几何与法向信息。

历史矩形真值仍可用于离线误差评分，不能因此进入新估计器、策略输入、动作 mask、重捕获或目标生成。是否需要背面信息应由统一任务成本和后续物理效果体现，不加人为的信息奖励，不设置免费揭示背面的动作。

## 2. 估计对象与运动

以持续跟踪的局部边为实体，维护：有向直线的方向与法向位置、一个持续参考点的状态与不确定度、局部平移/角速度、两端的已观测/区间/遮挡状态，以及观测支持范围、关联与新鲜度。

参考点是边上的跟踪坐标原点，不是物体中心，也不默认是整条边的中点；不能每帧重置为当前可见点云的质心。边的总长未知，仅从合法观测约束；一端被遮挡时保留开放/单边约束，不能通过固定长宽补另一端。两端得到可靠观测后，可估计长度及不确定度；“刚性长度随时间不变”与“长度预先已知”须区分。

可用局部运动表达同一条边上各点的速度：

```
v(p) = v(a) + omega * J*(p-a)
```

a 是持续参考点，J 为逆时针90°。这不要求知道真实转动中心。短步预测可对整条边施加共同的平面刚体变换；a 的速度/omega 从历史合法观测估计，模型误差进入不确定度，不能把机器人指令速度直接当成物体速度。不要给两端分别估计互不一致的刚体运动。

单条无特征直边主要约束方向和法向位置；沿边滑移不可由无限直线本身观测。没有可靠端点/角点时，持续参考点的切向位置只能预测并承认不确定，不能称为已识别材料点。若用直线 rho/theta 表示，沿线平移是不可观测自由度，不能在 EKF 中虚构强约束。

## 3. 新观测如何校正

- 用当前可见点对预测边的法向残差/方向一致性进行校正；不因边缘相邻射线命中跳变而重新定义边的实体或参考原点。
- 物理端点采用区间观测；区间中点不是确定点。遮挡边界只约束当前可见支持，不能当作边的物理端点。
- 可靠角点/相邻边交线可以提供更强定位；依然要验证关联，不借真实形态 ID 配对。
- 多条确定属于同一物体的边可以共享运动，但不同边的关联须来自合法历史；不能用后台面 ID 或整物体模型做关联。
- 输出边的位置、方向、运动与各自可信度供控制器一致使用；保留安全的当前可见支持，预测几何不自动授权穿过遮挡或安全边界。

## 4. 已确认的旧先验依赖

当前源码仍有：`effect_push.py::estimate_face` 用 rectangle_size 在两种长宽间选面并补全边；`EndpointTracker.update` 用已知 length 融合两端、由 anchor±length/2 生成中点；`FaceEstimate.centre` 由 depth/2 推出物体中心。此外接触偏移限幅、旋转偏移、同面分配和历史面关联依赖 face.length/depth。

因此未来实现必须审计完整感知→目标→mask/控制路径。仅替换滤波器、继续给旧接口伪造一个 length/centre，会保留不符合用户目标的信息或几何假设。旧依赖的逐项替代方案应在下一份实施任务书中写明，暂不直接修改生产代码。

## 5. 未来比较应满足的条件

1. 先在既有记录扫描上比较局部边状态误差、尾部误差、滞后和不确定度；无需先推断完整物体形状。
2. 两种隐藏背面在可见输入/历史固定时，估计器输出、策略输入与普通候选 mask 不得变化；绕行后由实际新观测更新。不同物理反馈本身可以成为合法辨识证据。
3. 显式比较需要/不需要背面信息的不同目标方向；绕行计实际时间和成本，不硬编码何时“应该探测”。
4. 未知尺寸版本与历史矩形先验版本必须标明契约差别，历史训练结果不直接视为新版本效果。

下一份方案以本文件约束为准，不继续采用“已知尺寸→估计物体中心”的默认设计。
