## 2. 保留的正确思路

`unknown_shape.py:65–80` 使用固定世界原点的速度场：

```
v_surface(p) = u + omega*J*p
contact: n.T*v_robot = n.T*u + omega*n.T*J*p
line:   n.T*p=rho;  rho_dot=n.T*u;  phi_dot=omega
```

这套固定空间原点参数化在数学上成立；**不要误判为rho_dot一定漏了旋转项**。
对材料点微分：rho_dot=(omega*J*n).T*p+n.T*(u+omega*J*p)=n.T*u，旋转项抵消。
前两个状态是速度场在固定原点的截距，不能直接当物体中心速度来评分。
以邻近合法里程计位置o作固定原点、用p-o代替p，可改善尺度；换原点时均值/协方差必须一同变换。

当前实质是观测相关H的三维速度KF，并没有非线性状态传播或共同位姿/地图状态。这不因名称不叫EKF就无效；**可以先保留三维模型修对，不必为名字立即扩维**。
持续局部线约束、实际接触法向约束、端点不作为PUSH必要输入，仍值得保留。
真实接触也不代表切向无滑动；只加法向等式正确，见[Modern Robotics接触运动学](https://modernrobotics.northwestern.edu/nu-gm-book-resource/12-1-2-contact-types-rolling-sliding-and-breaking/)。

## 3. 优先修复一：没有共享运动估计，且丢掉了最有价值的线

源码 `unknown_shape.py:98–99,145–171`：每个 UnknownShapePush 自己new一个滤波器，只把当前选中用于推动的一条patch送入line更新。factory/环境没有共享感知更新。

后果：

- N机器人和E机器人的接触/线约束分别留在不同滤波器里，无法利用互补信息。
- 即使同一机器人的扫描看到第二条非平行线，也没有送进运动估计器。
- Wait/Reposition阶段没有持续更新这套运动估计；切换新PUSH时重新初始化，丢掉换面过程中已经看见的边和历史。
- 一条N向线的法向位置/方向＋同面N向接触，一般仍只有秩2，E向速度无法辨识。复核矩阵确实为rank2。

这正是最初N+E、Push+Wait、Push+Reposition讨论希望解决的条件，不是次要增强项。30/30通过的六个根以单推/同面双推为主，尚不能证明邻面运动跟随有效。

改进：把MotionEstimator提升到环境**合法感知层**，按tick收双方明确共享的传感器包，在控制前统一predict/update一次；给两个控制器同一个不可变快照。跨option切换持续保留。
所有可靠局部线都可贡献约束；用于感知的线集合与用于接触控制的目标线分开。去重、同线相关性、弱方向与新鲜度显式记录。不能通过让控制器读env真值实现“共享”。

## 4. 优先修复二：速度状态的Q/R与门控没有校准

### Q的状态含义错配

`unknown_shape.py:44–46` 对速度状态使用 q*dt^3/3。这是原6维设计中位置积分块的形式。
如果此处的q仍表示速度随机游走的谱密度，应为q*dt；在dt=.05s时两者相差**1200倍**。
并非任何小Q都数学违法，但目前参数的单位和转移假设没有自洽解释。

隔离现有类，重复100次零速度/零转速线观测，再输入.16m/s：NIS=185.64>9，更新被拒，速度仍0。
这是**合成输入门控反例**，不代表实测运动一定出现该情况，也不直接解释换面失败；但足以否定“数值/响应已经验证无问题”。

### 差分噪声不能沿用位置/角度噪声

`119–139,75–80` 直接用相邻采样差分，但R固定为(.01m/s)^2与(2deg)^2，没有按时间间隔和拟合不确定度传播。
例如单帧角误差若为1deg，间隔.05s的独立差分角速度std约.494rad/s，而代码用.0349；此数值是误差传播示例，并非实际雷达噪声测量。
相邻差分复用同一帧，误差还相关。rho使用第一个返回点而非拟合线的中心化截距，额外受单点残差影响。

最小改进方向：

1. 先明确三维状态的随机游走模型，恢复正确dt量纲；Q/R通过速度启动/停止、转动启动、缺测合成序列和真实记录检验，不以成功率盲扫。
2. rho用拟合线中心化结果，传播角/距联合协方差；采用约.2s的稳定关联窗口或显式线状态更新，避免.05s裸差分。
3. 有限窗的Delta_rho/Delta_t对应**时间平均法向**乘u，不精确等于窗末n乘u；角变化大时使用积分/中点近似及对应R，不硬套瞬时式。
4. 实际估计误差、P覆盖、NIS拒绝率及可观测性都要有日志。门控连续拒绝不能继续输出“fresh/可信”。使用Joseph形式与PSD检查。

## 5. 优先修复三：接触后恢复了一个错误的位置外环

`187–212`：接近阶段追当前points.mean；接触后继续以同一个可见点云质心计算e_c，用1.5*e_c驱动切向速度。

**射线点的均值既不等于物体中心，也不等于整条边的中点，甚至不等于可见支撑区间的中点。** 它受采样密度、视角、遮挡与距离影响，机器人自身移动就能使目标移动。
解析例子：固定直线段x∈[-.5,.5]、y=0，机器人在(-.3,.3)，72条等角射线/1.2m量程，命中点均值x=-.1645，而边中点为0。物体没有运动，这个“目标”就已偏移；不是物理试验。

当前 `u_adjust` 限幅实际为**.15m/s**，超过任务硬上限.08；进度Round5写的是.05，参数/版本没有闭合。
它可大于FF上限.06，是一个很强的追质心外环，不能描述为“小幅直接微调”。仅关闭FF而保留此项，不能检验原来的surface-following设计是否失败。

改进：

- APPROACH可以在当前观测支持中选一个固定、留足余量的接触候选；支持点按弧长均匀化可减少射线密度偏置，但不能把它称物体中心。
- 接触确认后取消points.mean的归中项。先用u_adjust=0独立验证表面速度跟随，保留当前支持/peer的安全约束。
- 若实际出现持续角偏，再增加**一项依靠合法运动反馈的接触调整**：轻推测响应、减速/撤力、沿面重定位，确认改善再推进。要校准局部响应符号，不假定某个切向方向普遍抑制转动。
- 这是接触策略候选，不是已证明可在所有未知形状成功；不会凭空获取未见几何，也不必先识别几何/质量中心。

## 6. 速度跟随和模式约束仍有确定缺口

### 6.1 FF被限制得无法跟随典型邻面推动

`203`把tangent FF裁到±.06m/s。另一机器人导致表面向E平移.16m/s时，N机器人最多只补37.5%，缺.10m/s；这是设计上限的算术结论，不是实测速度。
主动相对滑动限幅与**被动跟随表面**限幅应分开；前馈由可信估计、现有总速度/力/加速度限制约束，不能套很小的微调上限。

### 6.2 “法向权威独立”的修复仍会被后置裁剪部分抵消

`217–220`仍按speed_command(+push阶段.08)裁整个raw向量。
例如正常vn=.16、FF=.06、归中=.15，raw切向=.21，后置限幅使vn从.16降为.14545；.04档可降为.02245。
这不是说所有状态都截断，也不是反对必要的物理限制。应删掉这个按动作档位限制整向量的额外规则，使用统一的现有物理限幅/明确分配器，并记录避障、总力和加速度最终如何改变各分量。
`211`的min(speed_command,max(.03,speed_command))恒等于speed_command，表达式可直接简化。

### 6.3 当前接触不一定属于被选中的那条线

`157`没有合适方向时回退最近obs.patch；`174–181`有任意真实接触就用所选patch法向更新接触等式，没有检查它是否对应当前接触。
角点接触时，真实法向可与邻边法向不同。当前圆机器人合法contact_point_robot可给出径向接触方向；应核验其长度/质量和与所选线的一致性，不用后台面ID。
接触点缺失时不能悄悄以机器人中心代替接触点：旋转杠杆可能错误；应缺测/增大不确定度。
没有方向匹配面应返回可解释的unavailable/等待/重定位，不悄悄执行另一个方向的推。

### 6.4 旧生命周期没有完整接回

新step没有调用原_safety、处理pending_exit_reason/进展守护，且不按release/joint_active决定推进；保留obstacle_avoidance不等于保留所有安全/协调语义。
上层coordinator会在部分phase对力门控，但不能因此认为新skill内部恢复/结束契约正确。
应复用共享的安全/生命周期hook，接触门控、恢复和控制计算分开记录；不复制另一套物理step。

## 7. 对DS失败归因的修正

1. “切PUSH以后开始分叉、偏心接触后旋转”是DS报告的轨迹观察；当前缺原始行，GPT未独立物理复现。
2. **PUSH固定窗口不是1.4s。** 冻结JSON为14.4s REPOSITION＋8.0s PUSH＋3.2s BRAKE。1.4s若指某次接触前局部区间，需要原始时序佐证，不能当窗口总长证明来不及。
3. 可见支撑质心无法变成物体中心是真的；但控制目标没有必要定义为“找到物体中心”。应评估“能否选择/调整到产生可接受运动的接触”。
4. 没有几何/接触因子误差、共享融合与去归中项的独立对照，不能排除估计/控制设计问题，也不能升级为未知形态的不可行性结论。
5. ICP只提供扫描间几何对齐，不能生成未观察的背面或自动确定稳定推力作用位置。其部分重叠/表面采样问题仍需处理，见[Generalized-ICP原论文](https://www.robots.ox.ac.uk/~avsegal/resources/papers/Generalized_ICP.pdf)。是否需要加它，应由剩余的具体不可观测方向/关联失败决定。
