## 要实现的机制

作者提交 Python 中的字面量 SYMBOLIC_POLICY。选择条件、可执行条件、评分与并列优先级、语义派生表达式可抽取；同一解释器语义驱动执行和 SMT 检查。预测下一边界元表达式的联合后果，再真正重新求值策略，检查被选择动作的可执行条件。不能用“存在另一个合法动作”代替实际选择检查。

前端只读公开历史，将几何、可见法向、接触、路径和搜索摘要变成带单位元表达式。模型只预测这些摘要及过程安全量；无预测的受影响量失效为 unknown，不能默认为保持。有限联合分支保留关联。缺证据生成定向开发分叉请求，并抽查高置信动作。部署临场仿真只由公开历史构造假设，冷启动控制器与未观测几何的不确定性明确记录。

当前环境：compact20，机器人半径 0.10 m，绕行目标净距 0.05 m，PUSH 可见面法向阈值 45°，72 body-frame rays。绕行与 PUSH 独立；绕行效果可以承诺获得支持特定推向的可见面。多短动作提示给作者，不把命令窗口等同箱体位移。
