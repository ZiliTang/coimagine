## 1. 最新授权与交付目标

用户允许本轮长时间自主探索方法，直到得到信息边界内可用的运动估计与推动控制，或总预算到期。
这明确覆盖长期协议中“固定方法、不可调参、单轮负结果立即交回”的默认限制，**仅对 D009 v2 生效**。
负结果后可在本任务内部继续实现/对照，不自行开 D010、不启动 RL、不再等待用户醒来批准普通可逆修复。
不得改信息边界、物理/奖励/成功判据、最终验收矩阵和总预算。

固定目标：

1. 维护路径彻底移除物体尺寸/中心/矩形结构先验；这项不能因为效果不好而回退。
2. 用共同刚体 EKF，融合真实接触法向速度与稀疏局部几何，估计接触处表面运动。
3. APPROACH 用局部可见轮廓选点；PUSH 改为表面速度跟随＋有限的直接侧向调整，取消端点锚定位置外环。
4. 用固定矩阵回答“多数工程场景是否可用”，同时独立评价估计误差、控制契约、任务成功，全部给分母。

## 2. 可自由修改的部分与不可越过的部分

| 项目 | DS 权限 |
|---|---|
| EKF状态参数化、误差状态、特征管理、解析/数值Jacobian | 可改；保持共同刚体模型、给公式与测试，不能退成真值速度/命令速度 |
| Q/R、时间窗、关联、鲁棒权重、接触置信、退化判定 | 可多轮调整；只用合法在线量调权，离线真值用于开发评分 |
| 局部轮廓、首次接触选择、未知形态同面分配、局部恢复 | 可改；不得补全矩形/中心/未知端点，不靠真实face ID |
| 侧向前馈与一个主动纠偏项、相对速度阻尼 | 可改；明确误差/符号/单位并消融，遵守现有力/加速度限幅；主动纠偏上限.08m/s |
| 工厂/日志/schema/绘图/headless与testbed接入 | 可改；版号明确、旧checkpoint拒绝隐式复用；不改页面大布局/增加无关功能 |
| RL、模型训练、奖励/成功/物理、雷达硬件采样、动作ID/档位/actor周期 | 不可改 |
| 真实非矩形物理后端、全量ICP、学习模型、质量/尺寸识别 | 本轮不实现；允许解析多边形扫描fixture和稀疏线关联 |
| 最终case、计分门槛、预算、失败样本分母 | 不可改；不能挑好seed或修改脚本刹车时机救分 |

每轮围绕一个可验证问题，保存源码快照/配置/动机/结果。可以累计多轮修改，但最终要解释每一项为何保留，优先选择较少项的可用实现。
不得在同一批正在运行时改源码；先结束/终止该批，再记录新版本。禁止覆盖旧产物、删失败尝试。

## 3. 总预算和自主执行节奏

- 从 DS 开始 preflight 起 **8小时墙钟硬上限**，包括实现、测试、运行、分析和报告；完成目标可提前交回。
- 最晚 T+7h40m 停止新计算并终止仍运行的子进程，最后20min用于汇总和交接；总到点不继续“补一个测试”。
- workers≤4。所有物理尝试总计≤1200：开发/探针/含物理单测≤1000，最终冻结比较184条，另预留16条仅用于与算法无关的I/O/记录错误修复。
- 最终有效清单仍只有184条；16条重复必须连同原失败一起登记，不可替换算法失败。无记录能力/算法异常均算失败，不可按I/O错误免责。
- 每次实例化用于推进的物理 episode/branch 都计数，包括probe、失败、超时、重试；纯解析传感器fixture/不推进backend的单测不计物理数，仍计墙钟。
- 开发物理单次模拟时长≤60s，独立作业墙钟≤300s；普通测试进程≤600s。统一剩余总预算截断，子进程新建进程组，超时 TERM 后≤5s KILL 并 wait/reap。
- 任一批新增物理异常>5%或出现NaN/越界写入：立即停止该批，查明再开下一内部轮；所有尝试留账。不能忽略异常继续长批。
- 约 T+2h / +4h / +6h 各落一次中间报告与 CURRENT 心跳：已用预算、当前最佳合法版本、主要失败、下一轮问题。无外部通讯要求，写文件即可。
- 若剩余预算不足最终184条+分析，提前停止开发、执行能完成的固定前缀并写 incomplete；不能缩小分母宣布验收通过。

## 4. 实施顺序（内部轮次可迭代，不设原v1一次失败即停的闸门）

### A. Preflight、信息边界与先验剥离

保存 HEAD+dirty、实际源码/配置哈希和快照、开始时间、硬截止、计数器，核验输入。
源报告/验收文件缺失或冻结输入不匹配不可悄悄改用其他数据；先记录差异，若无法恢复原输入则停止相关比较，不影响独立的合法实现工作。

交付 prior_removal.csv，至少覆盖规格第8节全部调用点；对维护路径内旧矩形推断函数加 raise 哨兵的集成测试。
同一合法传感器历史、不同隐藏尺寸/背面metadata：估计/观测向量/mask/目标/控制输出一致（数值容差1e-12）；让这些metadata访问抛异常，真实 factory→observe→mask→control 路径仍通过。
**这不是只改config名字**。env.observe 中旧 AnchorTracker 的隐式调用、ROTATE/FOLLOW/REPOSITION、同面分配也要查。
历史源码保留，维护入口与默认构造迁移到无先验版；若效果不达标，保留新版本并标不适合训练，不能回矩形默认。

### B. EKF 与独立离线验证

实现推荐模型或提交有公式的等价实现。至少覆盖：

1. 预测/线观测/接触观测 Jacobian 有限差分核对（相对误差≤1e-5，零量用绝对误差1e-7）。
2. 纯平移、纯转动、混合刚体运动；参考点选择改变后同一点 v_surface 不变。
3. 两个非平行接触的秩2反例；单面/同面接触切向不可观测；不能用v=0假收敛。
4. 无接触但两机器人看非平行线、移动观察者看静物、单推+移动观察者。
5. 遮挡/角点切换/法向反号/错误关联；近接触ready不生成接触等式；接触丢失立即撤销。
6. 初始化交叉协方差、同帧不重复、特征退出、长缺测、PSD与不确定度退化。
7. 运动中另一机器人approach不累积静态幽灵图；旧端点强扰动不能改变已接触PUSH的运动估计和跟随（固定其余合法输入）。
8. 全局平移/旋转与交换机器人编号的等变性；纯直线、任意夹角多边形；解析圆用于验证曲率法向不能冒充刚体角速度，不声称已支持曲面控制。

除新增测试，运行受改动影响的既有 D003/D004/D005/D007、joint、v13/v14 聚焦测试；选择与未跑项写清，不默认启动耗时未知的全量pytest。涉及物理的单测同样进入1000条开发预算。

已有 D007 第二轮34条完整扫描记录可做开发离线证据；两条稀疏nonint仅来源审计。只重放合法扫描/里程计/接触包，禁止读取历史融合端点/中心/隐藏face label给新算法初始化。
先从真实schema做golden样本/字段断言，再跑全量，不得缺字段就回退到世界Y或填0。
这些是旧控制器产生的数据，不能当作新闭环效果；误差和置信度可用于选方法。

### C. 闭环开发

用开发 seeds 20000–20999（按尝试顺序，不挑seed）生成原有场景族的平移、朝向、间隙、切向位置、速度档扰动；同时覆盖 Push+Wait、Push+Reposition、邻面、同面、转动和遮挡。
每轮记录case生成规则与完整初态；不预设矩形面数/名称进入控制。生成器/scorer知道真几何不等于控制器可用。
至少做4条ROTATE与4条FOLLOW功能检查并给轨迹/失败说明，不把它们混进主80条多数场景指标。
首先验证 u_adjust=0 的表面跟随，再决定是否加一项纠偏；不能同时恢复多个历史外环，靠扫gain掩盖估计错误。

本地服务允许在保存presets/当前配置、记录旧进程命令后**受控重启到新维护版本**，不删除历史runs。若没有可恢复命令，先提供新版本独立端口入口并写清旧服务仍是历史代码，避免杀掉用户未知进程。
不做外网发布。保存可双击打开的replay/index；无浏览器则明说视觉未验，不能用HTTP成功冒充视觉验收。

final 阶段算法失败后不再调参重跑这套验收；如预算内还有开发时间，也只写明未来建议，不用已看过的最终集救分。

40契约=邻面/同面/Push+Wait/Push+Reposition×5扰动×2整体朝向；6s固定请求＋1s BRAKE。其环境goal固定放在推进反方向，避免提前success截断窗口；该组以控制契约评分，不作为到达goal任务。
详细初态/命令已落JSON，不由DS重新选代表。目标只用于任务判定；契约组另用方向推进评分，不冒称达到目标。
测试初态合法性只在生成器/scorer侧验证；任何运行拒绝、mask不可用、异常均保留对应case，计失败。

## 6. 固定验收口径（阈值不能为过关而修改）

### 必须同时通过的三个层次

**信息与数值**：先验哨兵/相同可见输入不变性测试全部通过；无后台真值依赖；F_full 80条无NaN/物理异常/强制fallback。
最终源码、配置、日志schema与记录匹配；纯数学测试之外，必须从真实JSON行独立重算指标。

**估计**：只对有足够信息的时段评估完整速度准确率，但要把“没有足够信息”也报告。
最终80条逐20Hz有效时刻，用独立scorer计算当前机器人接触附近的真实表面速度
`v_true(p)=v_object+omega_true*J*(p-c_true)`；真中心仅在scorer。
在1s热身后、实际接触、输入几何明确支持完整twist的时段：

- 接触点切向速度 RMSE≤.03m/s、绝对误差P95≤.06m/s；omega RMSE≤.08rad/s、绝对误差P95≤.15rad/s。
- 条件内输出有效的覆盖率≥90%；误差对所有条件内有限输出算，**包括算法自己标invalid的输出**，不能只留好帧。非有限输出计失败并单列。
- “输入支持”由独立的合法观测ledger定义：过去.5s有至少两条已持续≥.3s、无向法向夹角≥30deg（用acos(abs(dot))）的线约束，且有重复线方向观测；或接触/线因素的离线白化设计矩阵确为满秩。不能直接用估计器自己valid标志选择评分子集。
- 对应条件时长至少10s，来自≥8条轨迹，含Push+Wait、Push+Reposition各≥2条；不足则estimation evidence insufficient，不能宣布通过。
- 另给全部接触时长/弱可观测/缺测分母、各族误差、95%区间覆盖与高置信大误差事件。不可观测时不强制小误差，但须显示退化而不是伪确定。

**闭环**：F_full 任务成功≥32/40，且8根每根≥3/5；契约通过≥32/40，且4族每族≥7/10。
契约同时要求：6s内指定推向的物体净推进≥.25m；t∈[2,6]s每个请求PUSH机器人的真实接触时间≥2s；物体相对初始最大角偏≤.35rad；无异常/出界/静态或队友碰撞/持续控制器失败。
Push+Reposition另要求reposition机器人的机器人轨迹长度≥.15m（不是物体位移），防止实际一直等待也被算协作。
安全等待/无可用动作算控制失败；不得以滤波器很谨慎为理由剔除。
BRAKE停车单列末.5s速度（沿用既有成功判据），不借修改阈值增加任务成功。

全部通过才写 **engineering-accepted**；先验合法但性能不达标写 **prior-free implemented / performance not accepted**；没有跑齐/记录不足写 **incomplete**。
阈值是本轮工程目标，并非论文统计显著性；80条含关联扰动，不宣称80个独立随机样本或未知形态泛化。
旧矩形路径只能历史上下文，不能因它更强而重新作为维护默认。新实现未达标时明确阻止正式RL训练入口误用。
