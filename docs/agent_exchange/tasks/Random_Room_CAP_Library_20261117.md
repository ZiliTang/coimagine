主模型GDA及同示范等优化预算G、GA对照；固定最终checkpoint，不按最终留出调参。训练更新数取min(30000,max(12000,100*ceil(N/32)))，N为训练边界；单臂90分钟优化保护，三组独立seed17进程并行拟合，各进程torch单线程；与串行数值目标相同。训练侧小样本可训练性检查先通过。全开发集闭环、20验证、20最终留出；各单CAP在留出同条件评估，报告最佳单CAP（开发集选择）、教师成功并集（离线上界）、整合保留/新增/丢失。完整未覆盖分母保留。最终评估每例墙钟保护1800秒（不改变90秒仿真上限），避免多程序特征计算因较短工程超时而人为降低成功率；若仍超时单列基础设施问题。若单CAP已覆盖充分或监督整合失败，均原样报告。
