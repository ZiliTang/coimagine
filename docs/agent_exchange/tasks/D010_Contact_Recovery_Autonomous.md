## 5. B阶段：连续自主修复，首选先对齐再触碰

按参考方案先做一个主要改动：**先达到安全间隙→在间隙处切向对齐候选→再法向触碰**，去掉接近过程中“无论是否对齐都至少向物体运动.06m/s”的耦合。
候选用连续可见支持内留边距的点，支持中点只作启发式；接触后不追点云质心。新视角增加支持时，可在接触前有界更新候选，避免锁定一个明显的遮挡边缘。
首版数值与允许校准范围见参考设计；这些可调，信息边界、物理限幅、固定验证与预算不可调。
所有准备/试推/重定位可被BRAKE或新意图抢占，不改变原模式切换的制动握手，不用内部准备期限延长短PUSH请求。

允许失败后转向：短期静止局部轮廓累积、更合理的候选评分、边界旁有界探视、轻推响应检查、撤力及沿面重定位。它们属于本任务内部方法自由度，不需另发D011。
优先单项递进：先几何分阶段接近，确有残余转偏再加响应检查。不同时恢复多个位置外环，不立即引入全量ICP；若需配准，先证明是关联/运动不足且仅限合法局部片段作为观测，不改冻结EKF。
普通失败不是硬阻塞；在开发预算内继续调查新的首断点。无法做到纯平移时允许可解释的失败，不要求把可见支撑中点“变成物体中心”。
