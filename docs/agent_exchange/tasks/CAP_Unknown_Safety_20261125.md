验收：没有覆盖证据的扫掠区域返回unknown；模型/在线样例不能越过该义务；真实观察动作自身有安全依据；观察后允许解除unknown并真实推进；停止段也包含在运动范围内。逐前缀追踪14间旧首次接触，旧确认集只作开发诊断。小场景同时包含相同公开输入的遮挡空/有障碍对照、历史记忆、预测失败与停止余动；记录逐tick安全与运动范围越界、观测成本、有效推进和所有暂缓。

固定72射线不是连续深度图，不能填充未测量扇区。新的几何证据以真实自由射线形成的闭合小区域为依据，并明确依赖静态障碍最小连通面积等宿主先验；缺少先验或运动范围证据时返回unknown。初始安全条件、外廓与运动范围的依据分开记录和独立核验，不把工程区间写成无条件物理保证。不新增奖励、真值探测按钮或部署真值输入。

当前状态：本轮局部验收完成。实际执行14个历史首次接触前缀、12个开发短回合、12组冻结三臂小场景（空/遮挡障碍/不观察，共36局），另对首组不观察控制作一次独立复现。未启动更大整局评估，无新增LLM调用。原开发上限40回合；不观察控制用于防止把全停策略误当安全闭环。
