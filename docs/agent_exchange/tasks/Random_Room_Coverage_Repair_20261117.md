# 冻结 CAP 库的覆盖扩充与真实接管监督

用户授权：长期自主完成下一轮。冻结既有10个CAP、技能/观测/执行预算；不开发新CAP、不做PPO。

1. 对旧GDA在40个已知留出中丢失的教师成功案例，比较最快成功教师与学习器的首个动作分歧，在分歧边界及后8边界尝试全部10个CAP接管。仅取正边界且前缀不超过1200ticks；无适合切点时取最早8边界内的可用点。这是预定诊断采样，不宣称定位了真正因果失败点。前缀真实重放，接收CAP从实际历史更新记忆；公开观测和物理前缀均需精确匹配，全部tick计费，任务总1800ticks/300决策不重置。
2. 原随机生成规则不改，seed2026111741生成200个新开发场景（每可动物体数50个），每场景执行全部10个冻结CAP。每初态选最快完整成功轨迹，库序破平；失败不作为正模仿标签。加原124条示范，构成expanded。
3. 原124条数据control与expanded各训练G/GA/GDA，均从头seed17、28000更新、相同32×32评分器/Adam/完整合法动作空间。每组3进程、每进程单torch线程；5400秒优化保护。旧14000更新权重单列original，避免把额外优化误算为数据作用。
4. expanded GDA执行200个新开发初态，对教师可解但它失败的案例，每物体数最多选6个（固定ID序），按同切点规则让全部10CAP尝试接管。每切点选最快成功后缀，保留完整因果历史提取特征，但不监督坏前缀的动作。与expanded合并为repaired，三组各28000更新。没有成功修复也如实记录。
5. seed2026111742预生成100个独立最终留出（每物体数25个）；在全部数据和9个模型冻结后首次执行。9新模型均测旧200诊断+新100；旧3模型与10CAP测新100。旧40留出已经看过，不再称盲测。报告全分母、教师成功并集保留/丢失/新增、配对变化与训练拟合率。

16worker有界在途；逐worker写压缩回放后仅返回摘要；4worker特征提取、分片/memmap组合。最多8000正式执行、1440万ticks、9正式拟合；无LLM调用。少量预检另计并保留。单执行1800秒墙钟保护；接口故障、计算超时单列停下修复，不伪装任务失败。CAP非法输出记策略失败。原始负结果、旧封印和源文件不改。

## 执行前修正：独立接管开发初态

在expanded优化进行中、所有最终新留出尚未执行前，发现只在已提供完整示范的初态上找恢复失败可能退化为空任务。另预冻结100个repairdev（seed2026111743），与此前500个初态无重合；执行10CAP参考+expanded GDA，仅用成功接管后缀训练repaired。原200训练初态仍测保留。正式最多7990执行，不超原8000上限；9拟合不变。旧源不改，新增random_room_coverage_repair_amendment模块；原编排进程暂停准入，优化worker继续，到全部模型保存后接续新宿主，零丢弃训练/物理工作。新100最终留出不变；PROTOCOL_AMENDMENT、AMENDMENT_PREPARED和ORCHESTRATION_TRANSITION保存具体证据。

## 新最终留出执行前登记的机制验收

实际产生330接管分支、25条可监督成功后缀，主实验将为7840次执行。在原8000上限内增加repaired GDA的25个相同前缀接管复播，以及100个repairdev初态完整执行，共125次；与主实验共7965次。只读验证已冻结模型，不增加训练、不改变新最终留出。REPAIR_ACCEPTANCE_PROTOCOL.json在最终留出执行前保存；独立acceptance宿主等待主实验正常退出后执行。
