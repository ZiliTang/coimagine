# 固定示范的输入贡献辨析

用户2026-11-17授权开始上轮讨论的输入对照。使用固定CAP-COVERAGE-150.v1，不新增CAP、语义函数、任务初态或RL。

## 输入与公平性

- G：公开观测/动作的中性几何历史表示。每个边界371维，保留两机器人的全部72束扫描距离与类别、自身运动、接触/执行反馈、公开目标、按目标/非目标角色聚合的可见点云边界及法向统计、上一步动作。历史保留初始边界、全前缀均值/最小/最大及最近8边界；共4452维，再使用原18维候选几何。没有CAP记忆、阶段、建议或隐藏物理状态。该表示仍有损，不冒充完整历史学习器。
- A：CAP动作建议、匹配/方向/速度/时长信号，以及程序内部phase、时间余量、route进度、handoff等控制状态。将这些保守地归入A，避免把直接程序输出包装成独立物理语义。
- D：18个候选描述通道及对应8帧历史，包括可见形状余量、障碍存在、公开目标相对量、历史接触/受阻比例、表面方向、机器人相对位置和初始布局描述。精确分类保存在FEATURE_LAYOUT与源码CONTROL_NAMES。
- 四组G、GA、DA、GDA，合法动作支持、动作顺序、目标实体绑定、方向/速度/时长协议完全相同。共享动作编码、决策前缀标记及历史有效/年龄标记。
- 每组同一4724维上下文＋248维候选槽位、32×32 tanh评分器，319329个名义参数。被移除输入的数值和缺失标记都在归一化后置零；有效输入列不同，不声称有效函数类容量完全相同。
- 首层将共享上下文和候选线性投影相加，与拼接输入的同一MLP等价，避免为每个候选重复计算历史。已验证前向/梯度数值一致。
- 本轮统一用BC损失，不使用几何残差惩罚；避免惩罚唯一使用几何的对照。这是输入贡献诊断评分器，与旧双分支模型不同，不能把与旧136/216的差异归因于单一因素。
- 四组为保证一致均计算全部特征后屏蔽；运行耗时不作为最优部署成本比较。

## 数据、预算与评估

- 150完整成功轨迹/5351边界始终固定。另预先选定嵌套50轨迹：原13＋新增137中按任务×扰动尺度分桶、seed2026111701打乱后轮转抽37。选择不读取本轮模型结果。
- 4输入×2数据量＝8份独立从头模型；每份seed17、16800更新、batch32、Adam lr.003、梯度裁剪1、优化墙钟≤1800秒，固定最终模型。不同输入组在同一数据规模使用相同采样顺序；每份仅用其训练子集拟合归一化。
- 不选择checkpoint、不调参，因此不使用测试反馈；若后续调参，须使用训练侧按完整场景/轨迹分组的validation。单训练seed、单50轨迹子集，不声称消除优化方差。
- 全部模型冻结后才评估：13原锚点＋27训练侧诊断初态（每家族×尺度固定前3个）＋216已查看的测试初态，256×8＝2048执行。既有216标为固定已见诊断面板，不叫新盲测。
- 16worker，每例1800ticks/300决策/180秒，每个条件3600秒停止准入；最多3686400ticks。接口错误停止保留现场；物理失败/决策预算耗尽计入失败，不删除。
- 输出全量训练示范动作匹配、四条件动作字段匹配、旧407边界保留、50子集外的离线决策匹配、各任务闭环成功率，以及同初态分层bootstrap10000次的配对差。区间为探索性、未多重比较校正，不支持普遍语义充分性断言。
- 前置工程检查：8项测试；150轨迹5501公开事件编码核对；临时100次更新及四组各4ticks接口验收（共16ticks）。临时权重不进入正式拟合或结果。
