# GDA专属随机覆盖扩充与多种子监督

用户要求：优先检验数据覆盖不足，冻结CAP库，增加CAP采集和GDA监督，期待可重复的数据收益。此次按该方向执行有界对照，不预设结果为正。

1. 冻结10个CAP、技能/观测/网络、候选和最快成功轨迹筛选规则。旧基线数据使用270条完整成功示范，不包含25条修复后缀；已查看100测试不进入训练。
2. 同一随机房间生成器，seed2026111751、2026111752生成400新开发初态（每物体数100例），每例跑10CAP，共4000执行。每初态只取最快完整成功示范，平局按库序，失败保留不作正标签；与旧270条合并。
3. seed2026111753预先冻结200个新最终测试（每物体数50），所有新旧初态做重复检查。几何合法不等于动态可解，不按当前方法成功筛场景。
4. control270与expanded各训练seed17/29/43，全部从头42000更新，3训练进程，每进程单torch线程；每fit7200秒墙钟保护。原28000模型仅历史参照，不混为等预算对照。固定更新不是固定epoch，必须报告全部拟合率；不因测试结果追加训练。
5. 全部模型冻结后，200新测试执行6GDA+10CAP=3200次；旧100已见面板仅执行6GDA=600次诊断。总正式7800执行、至多14040000控制ticks、6拟合；16路采样，4路特征提取，无新CAP作者或PPO，无检索基线。全程墙钟上限6小时，耗尽显式incomplete，不自动扩预算。预检只重算已存公开历史，无新物理执行。
6. 保留原数据与失败，冻结新数据/模型/结果。主要看三个训练seed各自扩充减对照的配对成功差、均值/范围、教师并集保留与丢失；三个seed共享场景，不伪称三次独立数据采样。若要声称显著改进，另报告按场景配对置信区间，不能把600个模型—场景结果当600独立初态。

本轮只改变随机初态覆盖，不改变“一初态一最快成功轨迹”。多成功教师标签、针对分歧点采集和重加权留为后续独立因素，避免把采样策略变化混入数据量效果。若扩充无稳定收益，需检查拟合、训练预算/epoch和监督选择偏差，不能据单轮否定整合范式。
