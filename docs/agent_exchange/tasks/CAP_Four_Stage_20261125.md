## 运行语义

第三段是只读注册符号的纯函数，支持可抽取分支、局部候选与有界循环，输出候选及评分。零分、负分和准备动作均可参与。当前边界按分数选首个通过阶段4的候选；未来只复用第三段并检查启动条件，不递归调用未来预测器。实际下一边界用新的观测重算。

预测器可以读取当前原始观测和合法历史。输出下一边界公开语义的联合结果与本次过程摘要；不预测整个未来传感器，也不要求语义成为Markov状态。隐藏状态仅用于开发复现与物理审计，不能用于部署候选、评分或在线rollout起点。
