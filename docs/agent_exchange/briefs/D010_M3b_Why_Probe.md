# 为什么现在只跑8次

m3b已通过本轮离线检查：候选有状态、接线缺口已修，ALIGN也能在位置和速度同时稳定后才触碰。
这说明可以开始问真实物理问题，不说明机器人已经推好了；新版本还没有成功率。

下一步固定两个换面根和两个dual根，冻结旧版与m3b各跑一次，总共8次。
我们要看新候选是否真的改变首触位置、物体是否少转且推进更多，同时确认dual没有回归。只保留成功率看不到这些区别。

旧任务账不完整就保持unknown，不再假算剩余量。这里提出一笔独立的8次、20分钟新预算；只有你实际移交任务后生效，DS逐次先登记再运行。
这批不调算法、不训练、不扩40场景；即使全失败，只要记录完整，也能为下一次修复给出清楚依据。
