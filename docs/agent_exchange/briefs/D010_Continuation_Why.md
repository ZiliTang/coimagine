# 为什么建议继续原D010，而不是再选择一条新路线

当前30/40基线保住了，但我们还没有完整检验“撤退后重新选择接触”的效果。
代码把撤退和侧移放在“仍接触物体”的分支里；一旦真的退开，就跳回接近。失败可能来自操作链没有执行完，而不是操作链本身没用。

所以先让DS完成三件事：核算原任务还剩多少预算；补齐能看清阶段/接触/实际移动的日志；用事件测试和少量轨迹确认撤退、侧移、重新接触真的按计划发生。
这比再重复整套40条后只看成功率更能解释问题。

局部轮廓、探视和必要的局部配准在原任务里已经允许，不需要你再批准一次。物体形状先验仍不能进入控制器。
本说明不增加预算：如果原预算已到或无法核实，停止物理计算并补离线报告，不能重新起算12小时。
完整数据之后仍可得到负结果；我们要知道实际尝试了什么、为什么失败，再决定是否改变研究方向。
