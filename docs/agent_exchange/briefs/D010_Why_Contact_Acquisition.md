# D010 为什么给DS一个完整长周期

现在单机接近、普通推和双推已经恢复到固定回归30/30，剩下10次失败都发生在换面后重新接触。
机器人可能还在角部外侧，就一边横移一边向物体靠近，提前碰到角部，把物体推转。持续换一个gain，很难解决这个接触顺序问题。

这次让DS用一个完整的**12小时自主周期**完成诊断、修复、回归、对照和回放，不要求它每修一行或碰到一次负结果就回来等确认。最多1600次物理尝试，失败/探针/重跑也计数；最后保留验证和报告时间。

优先实现的办法很具体：**先退到安全间隙，在间隙处移到候选位置，再温和接触，最后正常推。**
候选来自实际看到的边界，留足边距；不要求知道物体大小、中心或背面。若这仍会推转，允许轻推观察真实运动反馈，再撤力或重定位；这些操作都有时间和成本。
EKF、FF和已修好的dual逻辑先冻结，避免同时修改多处后又无法解释回归。

原诊断还有一个必须先纠正的地方：reposition_0的动作实际是向西，不是向南。它看到的向西法向并非错面；两条失败更接近同一个角部接触问题的旋转对应。日志也要把控制前观测和推进后位姿分开。

DS可自主调整候选选择、分阶段接近、局部观察和必要重定位，但每个内部版本只改一个主要机制，保留代码与全部结果。
最终要检查原40条任务、40条协作控制、新40条扰动，并与冻结旧版及单项消融比较；不能只交两条好看的轨迹。
目标是原40条至少36次成功，换面每根至少3/5，同时保住至少29/30的原六根；新扰动和协作控制另有最低要求。

这对RL的帮助是：策略选择推之前的“获取可用接触”变得可靠，减少策略替角部碰撞、错误接触顺序兜底的负担。本轮不训练，也不能证明RL已经学会换面。
完整未知形态系统仍有先验审计和估计验收缺口；这次接触修复通过后也不能自动宣布全部完成。
