# M3的动机：让机器人换一个接触点，而不只是多走一段

状态机修好后，机器人确实会进入撤退和侧移阶段。但“进入侧移”不等于“选了一个更好的点并在那里重新接触”。
目前候选误差没有接入，侧移仍走默认方向；下一次接近又追当前点云均值，可能把刚才的移动抵消。

这一步只把候选变成持续保存的目标，让对齐、触碰、侧移和重接触引用同一个对象。换目标必须有记录，不能每帧随点云重选。
接着用机器人里程计和原始接触信息确认：它实际移动多少、是否在新点重新接触、角偏与推进是否改变。
这才是在检验接触候选，而非继续加重试次数。

仍属于原D010，EKF/FF/物理/奖励不动，不增加预算。次数无法核实则先只做离线实现与纯测试；正式RL和整个未知形态系统验收仍未就绪。
