# 这次检索对照回答什么

现有GDA在100个已看场景成功50个；单CAP最好46个，但两者成功分布差异较大。需要检查，用更简单的经验检索能否保留程序库的互补能力。

这次不给检索额外的成功轨迹或失败标签，只用GDA原来的270条完整示范。初态检索选一份CAP跑到底；动态检索在每个边界重新选CAP。默认k=1，不按测试结果调参。两者各跑相同100例，再与已有GDA逐场景比较。

若初态检索接近GDA，说明当前分布可能主要需要场景适用性识别；若动态检索更好，说明过程中的接续有价值；若GDA更好，还不能立刻归因于网络架构，因为它同时使用更多历史及程序语义。后续需表示匹配对照。
