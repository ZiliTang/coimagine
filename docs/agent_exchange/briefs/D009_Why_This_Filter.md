# D009 给用户的说明：跟踪看到的边，不预先补出整个物体

本轮做一个能直接实施的新版本：机器人记住一条边的位置、方向和运动，下一帧先预测它在哪里，再用新雷达扫描校准。边缘射线发生跳变时，边的实体和控制参考不跟着重新初始化。

它不需要知道物体有多长、多厚、中心在哪。没看到的端点保持未知；看到的端点通常也是一个区间，滤波器按这个区间更新，而不是把区间中点当精确位置。只有真的看到两端后，才估计边长。

这比“把现有滤波调强”更根本，但也不能凭空补信息。只有一段直线时，沿边移动可能看不出来；新版本必须把这种不确定性表示出来，控制器不能把平滑当准确。

DS将完成三件具体工作：

1. 实现固定参数的共同边状态滤波，两个端点共享同一个平移和旋转。
2. 清理旧代码里尺寸/中心先验的整个使用链，包括目标生成、动作mask、旋转偏置、同面分区和旧anchor模块；不会只换滤波器，其他地方仍用已知长宽。
3. 在相同扫描上检验误差和不确定度，再检查真实闭环动作能否执行。

对照分三层：旧矩形先验日志供历史参考；无先验、无记忆的扫描几何作为公平基线；新滤波器与后者比较。这样可以分清改善来自滤波，还是来自尺寸信息。另有“正面相同、背面不同”的解析扫描对，验证新版本不会在看到背面前读到形态答案。

第一阶段复用34条完整轨迹，并加8条不运行物理的传感器测试流；通过信息边界、数值稳定和基本精度门槛后，最多16条闭环集成轨迹。任何失败都计入预算，记录先验证，再启动物理。运行总预算40分钟，不训练、不自动替换当前服务。

本轮能回答：滤波器是否更可靠，以及未知尺寸的动作执行链是否打通。它还不能证明策略学会何时绕到背面；我们先把这个实验所需的感知与控制基础建立起来。最终只交回候选，依据结果再定下一项改动。
