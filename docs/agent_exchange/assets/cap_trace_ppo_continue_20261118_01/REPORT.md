# GA 与 GLOBAL 再训练 2000 episode

这次单种子对照未确认续训时差距进一步扩大。

|新面板|起点|终点|
|---|---:|---:|
|GA|94/200|105/200|
|GLOBAL|103/200|97/200|

|比较|差值（百分点）|95% 场景配对区间|
|---|---:|---:|
|差距变化，主指标|-8.5|[-17.0, +0.0]|

两组采用同一 seed17，来自上一确认面板并列最优的检查点。各重放36批历史更新，每批权重逐张量复现，再用恢复的Adam和小批次随机数状态继续40批。两组共4000次新增训练，800次已查看面板诊断，800次新面板评估。每200次访问同一批200训练初态一次，场景顺序与动作采样种子成对。固定最终检查点，同一批200个新场景评估起点与终点。区间条件于本次训练链，按物体数分层、配对重抽场景10000次。
