# CAP候选动作上的PPO对照

固定seed17与累计2000 episode，PPO成功 117/200，同场景顺序的Double DQN成功93/200，共同起点112/200。PPO相对配对DQN差 +12.0 个百分点，按场景分层bootstrap 95%区间 [4.5, 20.0]。新增成功46例，丢失22例。7CAP并集内成功109/151，并集外成功8/49。

起点为相同的GLOBAL模型。训练时PPO使用合法候选上的softmax(Q/0.03)和独立状态critic，仅使用当批轨迹估计优势。DQN使用ε-greedy与历史回放。两组共享场景、采集量、奖励和输入。单种子、已查看诊断面板及两种不同的探索机制限制了归因。实际新增1800条训练轨迹、288次开发监测、800次诊断。固定最终模型，确认集继续封存。
