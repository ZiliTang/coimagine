## 1. 要解决的具体问题

N 向机器人推动时，若另一机器人把物体向 E 推，它需要向 E 跟随接触表面的运动。
所需量是**当前接触位置处的表面速度**，并非物体中心、整条边的中点或距某端点的距离。
因此保留刚体运动状态估计，但取消 PUSH 对端点位置和端点锚定目标的持续依赖。

运动校准优先使用两类低维约束：

1. 真正接触时，机器人和物体在接触法向上的速度相同；允许切向滑动。
2. 未接触也可以用扫描持续跟踪一小段直线的方向、法向位置；不需要知道它的端点。

第二条需要跨帧的局部线关联，**不是完全无关联的单帧估计**，但不要求全量轮廓 ICP。
Push+Wait、Push+Reposition 中，未接触机器人也能提供这一类观测。

## 2. 信息边界与几何契约（不可放宽）

- 输入：当前及过去的合法扫描、机器人自身里程计/速度、时间、合法接触反馈、已公开的机器人几何/命令与公共记录。
- 本轮沿用集中式工程基线，可融合双方主动共享的上述合法传感器包；共享内容/时间戳入账。不宣称满足 B-bit 去中心化协议，不偷读未共享私有历史。
- 禁止输入物体真位姿/速度/角速度、尺寸/中心、完整形状、惯量、后台 face_id、hidden raw_labels、环境/backend 对象。采样器、传感器光线求交、独立 scorer 可用真值，部署调用图必须隔离。
- 控制器不得导入 OBJECT_WIDTH/HEIGHT 或通过默认常数猜形状。机器人半径 R=.18m 是公开信息，可以使用。
- `contact_ready` 包含近接触容差，**不等于真正接触**。不得据此写入速度相等约束；命令速度、期望推速也不是实测物体速度。
- 法向从合法扫描或合法接触几何取得。无可信法向/接触点时降权或缺测；不得调用后台真实面法向。
- 实际接触反馈沿用当前传感器抽象；若没有可观测的接触冲量，不能声称使用了力传感器。
- 保留相同物理、传感器采样、奖励、成功判据、动作 ID/速度档。禁止通过修改这些条件取得正结果。

## 3. 推荐状态：任意材料参考点，绝不是物体中心

推荐实现一个共同刚体 EKF；每条持续局部线是未知的刚体附属特征。也允许数学等价的误差状态/速度 EKF，但必须通过下述可观测性与数据关联测试。

选择固定世界坐标原点 o（例如首帧机器人里程计位置，之后不逐帧改）。以下位置均先减 o。
基状态：

```
x = [a_x, a_y, theta, v_x, v_y, omega]
J = [[0,-1],[1,0]]                   # 逆时针 +90°
v_surface(p) = v + omega * J @ (p-a)
```

a 是任意刚体附属参考点，v 是该参考点的世界速度；不要求该点是实际观测到的材料特征。
theta 的零点任意；不能把不可观测的 a 切向坐标包装成准确材料点定位。
初始化可令 a=0、theta=0、v=0、omega=0，定义一个初始位于 o 的虚拟刚体附属参考点；它可以位于物体外，不要求是真实接触点。此后禁止每帧把 a 重置成新点云质心。

每条线 j 追加两个未知静态特征参数 beta_j、eta_j：

```
n_j = [cos(theta+beta_j), sin(theta+beta_j)]
t_j = J @ n_j
世界线： n_j.T @ p = eta_j + n_j.T @ a
```

beta/eta 都从实测初始化；没有正交、平行、长短边、闭合轮廓、已知总长约束。
多条已确认属于同一被操作物体的局部线共享刚体运动；关联不明时保持独立候选，不靠隐藏物体 ID 强合并。
同一物体可见性由当前允许的 object 类别扫描提供；若类别不保证唯一物体，须加运动一致性验证，不能无条件合并。

### 预测起点

```
a^- = a + v*dt
theta^- = theta + omega*dt
v^- = v; omega^- = omega
beta_j^- = beta_j; eta_j^- = eta_j
```

F 的 a-v、theta-omega 块为 dt，其余单位阵。共同材料参考点常速度只是短时模型；真实转动下的向心加速度进入过程噪声，不暗示 a 是转动中心。
Q 对每组位置/速度用 q*[[dt^3/3,dt^2/2],[dt^2/2,dt]]；起始 q_v=.5² m²/s³、q_omega=1.0² rad²/s³。
基状态初始 std=[.02m,.02m,5deg,.20m/s,.20m/s,.5rad/s]。
初始 gauge 误差不能靠反复观测同一线无故消失。dt 使用实际时间，单预测步≤.05s，倒序时间报错。

## 4. 观测 A：实际接触的法向速度

在同一采样时刻，p 为当前机器人接触点，n 为该处可信单位法向：

```
z_c = n.T @ v_robot_contact
h_c(x) = n.T @ v + omega * n.T @ J @ (p-a)
H_a = omega*t.T; H_v = n.T; H_omega = n.T @ J @ (p-a)
```

H 中 theta/线特征列为零（这里 n 是测量量）。实际实现须考虑 p/n 测量不确定度对 R 的贡献。
圆机器人径向接触的自身自转不产生法向速度；若使用一般接触速度，计算自身 v_robot+omega_robot*J*r_robot。
**不能另加切向速度相等**：物体和机器人可以沿面滑动。

起点：真实接触连续2个 tick 才启用，首个 tick 仅记录；接触丢失立即撤销等式，不能用 ready 续命。
接触速度噪声 std=.02m/s，启停/恢复阶段=.05m/s；标量创新 NIS>9 拒绝并记录。
接触冲击时采样前速度与采样后接触标志不混用；准确的 pre/post 时序必须从代码和日志证明。
若底层包只提供混合快照，采用一拍延迟的同时间包或放弃该拍约束，不用“看起来接触了”修复时间问题。

## 5. 观测 B：持续直线的方向与法向位置

每帧从**实际**扫描点拟合局部直线，输出 z_l=[phi_obs,rho_obs]、完整2×2 R_l、可见支持区间和质量。
rho_obs=n_obs.T@(point-o)。自身移动由自身里程计变换消除，不能把机器人运动当成物体运动。

```
h_l(x) = [theta+beta_j, eta_j+n_j.T@a]
H_angle: theta=1, beta_j=1
H_rho: a=n_j.T, theta=t_j.T@a, beta_j=t_j.T@a, eta_j=1
```

角残差 wrap；统一 n/rho 的符号，再做关联，禁止把法向反号误读为180°旋转。
一条线的朝向变化可约束物体角速度；它的法向位置变化可约束运动。它**不观测沿无限直线方向的平移**。
不能简单把 (rho_k-rho_prev)/dt 当作当前位置的法向速度；旋转法向和坐标原点都会产生额外项。

起始拟合门槛：≥3点、span≥.06m、RMS≤.015m；sigma_plane≥.004m、sigma_angle≥1deg。
应使用中心化参数拟合再传播到 rho，保留角度/截距相关性；不得只给“世界截距独立噪声”。
线创新 NIS 门槛9.21；可用 robust 权重，但不得用真值误差作在线权重。
同 tick 同一片段只更新一次；同一扫描的重叠碎片不当作多份独立证据；同一线连续观测有量化相关性，允许噪声膨胀/限频等保守处理，须说明近似。

新特征初始化：beta=phi_obs-theta；eta=rho_obs-n_obs.T@a。
必须通过联合 Jacobian 初始化特征与基状态的交叉协方差；**不能将刚初始化的该次观测再更新一次，也不能把未知线当作已知地图**。
例如 J_x 的 beta/theta=-1、eta/a=-n_obs.T；J_z 的 beta/phi=1、eta/phi=-t_obs.T@a、eta/rho=1。
用 P_xf=P*J_x.T、P_ff=J_x*P*J_x.T+J_z*R_l*J_z.T。

先做稀疏关联：预测角差≤20deg、法向距离≤.10m、观测支持间隔≤.15m；NIS/歧义联合判断。
匹配后保持 track 身份；视角变化、遮挡拆分/合并不能凭无限线外推武断确认同一材料边。
连续3帧确认新 track，缺测>.5s可退休；默认最多8条。退役保留其他状态的边缘协方差，不随意清零。
两机器人观测同一线时联合处理/显式去相关；禁止各自含共同先验的后验直接相乘。

## 6. 可观测性与置信度

接触速度对 twist [v_x,v_y,omega] 的一行是 [n_x,n_y,n.T@J@(p-a)]。

- 两个非平行接触通常只有秩2，仍缺1维；未观测模式可解释为绕两条接触法线交点的瞬时转动。
- 同面、不同位置接触可约束角速度和法向速度，但沿面平移仍不可观测。
- 持续直线朝向补充旋转信息；第二条非平行线的位置观测可补足平移。均须有足够时间基线和正确关联。
- 光滑曲面上“新采样点法向变化”可能来自曲率和采样迁移，不能直接等于刚体角速度。

输出不只 v/omega/P，还包括每个请求接触点处的 v_surface、完整2D协方差、各方向测量支持/退化标志、最后有效时间、来源、拒绝计数。
用当前/短窗 Jacobian 的白化信息矩阵评估秩与弱方向；角速度以 .3m 杠杆归一化后再判断，不能直接对混合单位矩阵设秩阈值。
默认有限窗=.5s，最小/最大奇异值比<1e-3标弱方向；窗口传播到同一线性化状态，不能把不同时刻不同参考点的 H 直接叠加。
这是工程退化指标，不能替代 P 或误差评估；DS可换更合适的可观测性实现。

一条无端点直线+同面接触不得输出“完整速度可信”；预测可能仍给出切向均值，但置信度须体现未知。
禁止用速度模长/静止先验把不可观测自由度强锁成0后声称收敛。
数值采用 Joseph 更新、P 对称化、PSD/非有限检查；传感器缺失不产生伪零误差。

## 7. APPROACH 与 PUSH 的分工

### APPROACH：选首次接触处

局部边界用有时间戳的点/短线段/surfel 序列表示，保留法向、观测支持、不确定度，不补全背面。
静止确认后可在世界系累积短期扫描；默认只保留最近.5s。
静止确认需至少.3s有效信息，估计运动的95%上界≤.01m/s且角速度≤.03rad/s；不可观测时不能据均值0宣布静止。
运动中可按可信 EKF 变换旧片段到当前时刻；运动不可信就仅用当前扫描/丢弃旧片段，禁止把幽灵轮廓交给接触选择。
目标只在当前可见支持中选，使用机器人尺寸、安全余量、peer 避让；不要求先有两个物理端点或物体中心。

### PUSH：跟随表面，直接微调

```
v_t_ref = t.T@v_surface(p_contact) + u_adjust
F_t = clip(K_v * (v_t_ref - t.T@v_robot), physical_limits)
```

保留现有执行内环、总力限制、参考加速度限制、接触/障碍恢复。接触位姿可靠性差时减速或短时恢复。
**u_adjust=0 表示没有相对表面的主动侧滑，不是世界侧向速度=0。**
不得在这个内环前再扣一次 world_vt 阻尼，否则会抵消跟随 feedforward；需要阻尼时对相对表面速度定义，并避免和 K_v 重复计入。
取消 PUSH 的 anchor±L/2→接触世界目标→位置误差链；可保留与 peer/当前可见安全支持的直接局部约束。

默认先设 u_adjust=0 验证跟随链。随后允许 DS 增加**一项**有明确误差量和符号依据的反馈（运动方向或角速度偏差），默认限幅 .04m/s，探索上限 .08m/s。
不能直接迁移旧 q_rot 正负号；未知中心/摩擦时，某个侧滑方向的转动效果没有普适符号。须用镜像/旋转等变性及实测局部响应校准，失败时退回0并记录。
不同时保留 heading/rate/lateral 多个位置外环叠加。最终需列出每个保留项的测量、误差、单位、符号、饱和及独立消融。

可信侧向速度默认要求 std≤.03m/s且有效信息年龄≤.20s；否则先对可观测子空间提供跟随，对未知分量保守衰减/限速，同时报告降级，不能继续用高增益世界位置锁定。
缺测>.25s进入 perception_wait/安全恢复；安全退化时间计入可用率，不能删出评价。

## 8. 彻底剥离先验与通用形态接口

逐项审计 estimate_face、EndpointTracker 已知长度融合、AnchorTracker 默认长度、face.centre/depth、所有 mask、PUSH/ROTATE/FOLLOW、same_face reservation、反馈/绘图/session。
旧物体中心估计字段置 None，不把 a 改名塞进去；使用 motion_reference/local_boundary 等新语义。
同面分配仅用当前局部线/支持、公开 peer 位置与机器人半径/间距；不知道总长也不能按 L/2 分半。
ROTATE 无中心先验时只按局部偏移/合法运动反馈实现并报告可用率，不保证所有局部推力一开始就产生指定转向；不得用真中心决定力矩符号。
REPOSITION 复用局部边界跟随，禁止内藏矩形四面顺序；未知拓扑不假设总共4面。
端点可作为 APPROACH 的可选信息，但**不再是刚体速度估计或持续 PUSH 的必要状态**。

接口为未来曲面保留短段序列/局部法向及关联不确定度；当前只验直线/多边形传感器序列与既有矩形物理。
曲面以后可用局部 surfel/曲线片段约束替换线因子，不需更换 v_surface 的刚体速度接口；无纹理圆的旋转本身可能不可观测，不能承诺任何形状都能完整估计。

维护中的默认工厂/headless/testbed 必须迁移到新无先验路径。历史实现可保留用于显式复现，但不能自动 fallback，也不维护两个不同物理/协议环境。
新语义版本 `unknown-shape-motion-v2`；旧 checkpoint 默认拒绝加载，除非以后单独审查兼容迁移。本轮不训练。
