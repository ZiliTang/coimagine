# D010参考方案：先建立安全接触几何，再执行推动

## 1. 目标与固定部分

解决换面后机器人仍在角部外侧时，法向接近与切向移动同时进行，过早撞到角部并产生旋转的问题。
不以寻找物体中心作为控制目标。局部可见支撑是可接触材料，不是完整形状；支持中点是候选启发式，不保证零力矩。
保留当前共享运动估计、Q/R、接触更新、FF公式与±.16m/s限幅、P0修复、动作46 ID、现有force/reference limits。
本轮可在接触获取阶段重写控制；接触稳定后的常规PUSH控制保持冻结，除可选的有界响应检查/重定位。

## 2. 坐标和合法输入

n为所选扫描线指向物体的单位法向，t=J*n；线为n·p=h，h由拟合线中心化计算。
把当前实测片段投影到t，得到连续支持区间S=[s_min,s_max]，遮挡/不连通片段不能凭共线强合并。
同样射线点不因插值增加信息。可按弧长均匀化用于候选评分，禁止把points.mean当物体中心。

只用合法扫描、自己的里程计/接触、已共享peer观测和冻结估计器输出。不读物体尺寸/中心/惯量/faceID/隐藏labels。
机器人半径R=.18m是公开信息；同面间距和peer避让用公开几何，不以已知面长分区。
已接触时cp来自合法contact_point_robot，径向方向作为圆机器人的接触法向；缺失不伪造成机器人中心。

## 3. 推荐状态机与起始数值

状态必须跨.2s重复请求持续保存，同意图速度档变化不重置。每个tick记录状态转移原因。
请求推向改变时使旧候选失效并重新获取，不能沿用旧面的目标；遵守原Slot的模式/制动语义。内部阶段与上层coordinator的控制权要明确映射，不能靠自定义阶段名绕过安全门控。

| 状态 | 行为与默认数值 | 转移条件 |
|---|---|---|
| ACQUIRE_VIEW | 选择与请求方向夹角≤35deg的可靠局部线；不足则有界寻找视角，不能fallback到错误方向面 | 同一候选连续3个不同tick稳定 |
| STANDOFF | 先保持/退到线外侧，目标机器人中心与线距离R+.04m；法向速度限幅.12m/s | 实测支撑和扫掠路径允许继续，法向间隙误差≤.01m |
| ALIGN | 在上述间隙下切向移到接触候选对应位置；切向gain=2.5/s、速度限幅.20m/s | 切向误差≤.015m、相对切向速度≤.03m/s，持续.15s |
| TOUCH | 沿法向温和接近，速度≤min(action.speed,.04m/s)，保持候选切向位置/必要的表面跟随 | 真实接触持续2tick、接触法向与候选线夹角≤20deg |
| PUSH | 进入冻结的表面跟随PUSH；接触后不追可见质心 | 沿用正常停止/失联/安全条件；可选响应检查见下 |
| REACQUIRE | 减速/制动，再回STANDOFF或选下一候选；所有运动均计真实时间/成本 | 最多3次，不能原地无限循环 |

STANDOFF的线外侧目标：先选线上的候选q，再令机器人中心目标为`q-(R+g)*n`。
先切向对齐、后法向触碰，不能为了快速接触始终保留一个最小正法向速度。机器人位于线段延长线旁时，不把无限线垂足称为有效接触点。
碰到角点/邻面且实际法向不符时，先撤回安全间隙，不能立即按所选面全速推。

### 候选选择

- 先把S两侧内缩m=R/3=.06m；至少留下.02m可用区间，否则标view_insufficient并尝试合法的视角变化，不补未知端点。
- 首版从内缩后的连续区间中点选候选；这是减少边缘接触风险的起点，不称物体中心。
- 记录可见支持、候选、机器人投影、peer限制的全部裁剪。不得依赖根名字、目标坐标表或seed选择位置。
- 在视角改善、支持新增≥.05m并连续3tick确认时，允许在接触前更新候选，默认最多2次；其余时间锁定候选，避免每帧追点云。
- 候选在世界系固定只适用于物体静止/信息可信；运动中可用冻结运动估计短时搬运，并以当前扫描验证。无可信搬运时回到当前观察，不累积静态幽灵轮廓。
- 物体静止的局部轮廓累积是允许的后备办法，但需时间戳、有效性及当前扫描复核；不得缓存整矩形/背面补全。

### 有界视角变化与重定位

没有足够支撑时，允许沿观测边界在安全间隙处移动获取更好的视角。默认一次≤.20m、速度≤.12m/s；扫掠圆盘与实际扫描点/peer避让验证，未知空间不自动视为空闲。
可复用现有rounded_scan局部跟随的无先验部分，不假定四个面/固定转角/绕一周长度。
PUSH内部准备默认上限6s；DS可在2–6s内校准，环境固定8s PUSH窗口不延长。准备耗时和退让必须与推进、总任务时间一起报告。
其他固定脚本的PUSH可能短于8s；6s是上限而非必等时长。BRAKE/其他新意图必须按原模式切换契约抢占，不能为完成准备而拒绝停止。

## 4. 只有几何准备仍不足时，才加响应检查

先只实现上述分阶段接近，验证真实首次接触位置与转偏。若仍有稳定偏心转动，再加一个响应检查，单独保存版本：

- TOUCH后轻推.40s，法向速度≤.04m/s；用持续同一局部线的方向变化/冻结omega观察响应，不能用物体真角。
- 默认触发：相对该次触碰开始角变化>.03rad，或可信|omega|>.10rad/s持续.15s；角状态无效时标无法判断，不填零通过。
- 触发后先撤力/制动，再回安全间隙；候选沿观测支撑移动.08m，最多3次，主动相对侧移速度≤.08m/s。
- 移动方向不能固定照搬旧q_rot符号；用已有合法响应/两个可比候选结果选择较小转偏者。每个尝试有真实成本，不免费复位物体，不读真中心算力矩。
- 不假定单个局部接触一定能在任意形状实现纯平移；找不到合适接触要可解释地失败。

响应检查是新的控制候选，不是已证有效。DS可用更简单或更合理的方法替代，但须给误差量、单位、符号、限幅与逐项对照；不同时叠加多个历史位置外环。
