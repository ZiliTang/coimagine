## 1. 标签来自哪个时刻，多少条复用/重放/不可恢复

**T = option 实际退出的物理时刻**，即记录里终止状态被采集的那一刻。阶段机在 append 日志行
**之前** break，所以"最后一条已记录日志"比 T 早一个控制周期，旧 `_exit_block` 不是 T。
改为**精确重放**（同 root/命令/快照/控制器/协议/传感，退出后不推进、不额外控制）：

| | 数量 |
|---|---:|
| 重放并逐条核对（退出原因/步数/终态物体/两机器人终态） | **5120 / 5120 全部一致** |
| 重放补取 T 观测 | **5120**（无一条可直接复用逐周期日志） |
| **不可恢复** | **0** |
| 类别 1（T 有合法片段） | 5120 条；每机器人 **9099** 个槽可见 |
| 类别 2（T 确实无片段，`patch_valid=0`） | 每机器人 **1141** 个槽；样本保留、几何 mask=0 |

T 与最后一条日志的差（抽 16 条 × 2 机器人）：片段距离中位差 **0.38 mm**、法向角 **0.03°**。
重放的价值在**时刻正确且可追溯**，数值差很小。

## 2. 与旧"真实参考面"标签的区别

旧标签用**真实物体位姿**与**真实面编号**，是特权量；切向偏移按真实面中心量起，
与观测片段不是同一个量。新标签只用**自身位姿 + 自己的 360° 扫描片段**，变换到各自起始系
R_i0，不含物体朝向/中心/面编号。旧 8 维几何头语义已变，用新字段名与版本，
**旧检查点不作为同一目标模型**。

## 4. 是否捕捉了同 root 动作造成的观测变化

| test | 动作差值 p50 (r0 中点 x) | Spearman ρ | 置换对照 ρ |
|---|---:|---:|---:|
| P0 | 0.1085 m | 不可定义（真值恒定，0/64） | — |
| **P1（修正后）** | **0.0414 m** | **0.714** | −0.008 |
| 新模型 | 0.0197–0.0223 m | 0.729–0.748 | −0.010–0.016 |

模型的动作差值比 P1 小 **1.9–2.1×**，秩相关只略高于 P1。**ρ 是秩相关系数、不是排序正确率**；
几何列排序不等于任务动作优劣。即：模型确实用了起始观测、而不只是命令平均效果，
但优势是**中等**的，不是量级差距。

| 分组（test） | 样本 | **独立 root** | 中点二维 p50 |

**更正上一版报告的归因**（评审意见，采纳）：

1. 0.1495 m 对 0.0416 m 是**机器人 1、单个种子**的分组结果，只建立在 **7 个独立起点**上；
   56 条占机器人 1 样本的 10.9%、占两机器人全部观测槽的约 **5.5%**。
2. 它**不能**与该分组之外的"终态不可见约占 11%"混用——那是另一个量
   （机器人 1 终态不可见 100/512，机器人 0 只有 4/512）。
3. **"起始不可见时误差更大"不能推出"输入实现漏了信息"。** 也可能来自样本覆盖、
   构型或动作差异，或现有可用信息确实不足。要区分就得先做诊断，不能靠补入不可获得的信息。
4. 机器人 0 测试集只有 **4 条**终态片段不可见，**三个模型全部漏报**。总体可见性准确率很高，
   **不代表**模型已经会预测观测丢失。

## 6. 能支持什么、不能支持什么

**能支持**：存在一个部署可用的接口，把"技能结束时机器人会看到什么、自身移动了多少"
从**自身**终态观测监督起来，并在留出 root 上**明显优于起始持久化**、
在**中点/位移/时长/退出类别上优于命令分组统计**；动作条件变化被部分捕捉。

**撤回**：上一版"同时超过两个基线"的完整表述——法向角仅持平，残余线速度不如两者。

**不能支持**：① 预测观测比预测物理状态更容易（两轮监督目标不同，不能直接比误差）；
② 已足够支持技能衔接（几厘米中点误差是否可接受要看下一技能容差）；
③ 状态可辨识、分支合法、可递归或规划会改善（单步观测误差推不出）；
④ 已解决部分可观测性（每机器人仍有 **1141/10240** 个槽在 T 无片段）。

**登记的实现限制**：归一化沿用上轮**按组单标量**方案（mean/std shape `(1,)`，**不是逐列**），
几何组内米与 sin/cos 共用一个尺度。
