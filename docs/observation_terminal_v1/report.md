## 1. 标签究竟来自哪个时刻，多少条复用/重放/不可恢复

**T = option 实际退出的物理时刻**，即记录里终止状态被采集的那一刻。阶段机在 append 日志行
**之前** break，所以"最后一条已记录日志"比 T 早一个控制周期，旧 `_exit_block` 不是 T。
本轮改为**精确重放**（同 root/命令/快照/控制器/协议/传感，退出后不推进、不额外控制）：

| | 数量 |
|---|---:|
| 重放并逐条核对（退出原因/步数/终态物体/两机器人终态） | **5120 / 5120 全部一致** |
| 直接复用逐周期日志（未重放） | 0 |
| 重放补取 T 观测 | **5120** |
| **不可恢复** | **0** |
| 类别 1（T 有合法片段） | 5120 条（每机器人：**9099** 个槽可见） |
| 类别 2（T 确实无片段，`patch_valid=0`） | 每机器人 **1141** 个槽；样本保留、几何 mask=0 |
| 类别 3（不可恢复，不得伪装成不可见） | 0 |

T 与"最后一条日志"的差（抽 16 条 × 2 机器人）：片段距离中位差 **0.38 mm**、法向角中位差
**0.03°**、32 个槽中 1 个的片段点数由 20 变 19。重放的语义价值在于**时刻正确且可追溯**，
数值差很小。

## 2. 与旧"真实参考面"标签的区别

旧标签 `segment_geometry(terminal_object, face, ·)` 用**真实物体位姿**与**真实面编号**，
是特权量；切向偏移更是按真实面中心量起，与观测片段**不是同一个量**。
新标签只用**自身位姿 + 自己的 360° 扫描片段**：可见拟合线段两端点中点与指向表面的法向，
全部通过 §4.1 变换到各自起始系 R_i0，**不含物体朝向/中心/面编号**。
旧 8 维几何头的语义已变，本轮用新字段名与版本，**旧检查点不作为同一目标模型**。

## 5. 能支持什么、不能支持什么

**能支持**：存在一个部署可用的接口，把"技能结束时机器人会看到什么、自身移动了多少"
从**自身**终态观测监督起来，并在留出 root 上同时优于起始持久化与命令分组统计；
动作条件变化被部分捕捉。**能支持**：负结果式的边界——残余速度目标当前无区分度、
起始不可见样本明显更难。

**不能支持**：① 状态可辨识或未来分支合法（单步观测误差不能推出）；② 可递归 rollout 或
规划会改善（本轮无规划器、无闭环成功率）；③ 跨目标比较"精度提高 N 倍"（旧模型预测真实参考面、
新模型预测可见片段）；④ 已解决部分可观测性——标签仍有 **1141/10240** 个机器人槽在 T 无片段。
**登记的实现限制**：归一化沿用上轮**按组单标量**方案（mean/std shape `(1,)`，**不是逐列**），
对几何组把米与 sin/cos 混在一个尺度里；这是冻结方案的结果，不是最优选择。
