# CoImagine：基线修复与成功轨迹分支数据升级任务书

时间戳：2026-10-12 21:37（Asia/Shanghai）
执行对象：DeepSeek V4.1 Flash coding agent
依据：forecast_baseline_v1 审查结果与用户本轮确认。

## 0. 目标、执行顺序与结束位置

检验：当前单窗口世界模型的不足，是否主要与训练数据缺少任务相关状态及动作后果有关。

按 A → B → C → D 顺序执行：
- A：修复已确认的统计、反事实和规划协议错误。
- B：验证几何检查、编码和小样本拟合；得到可信的旧模型基线。
- C：从精确规划成功轨迹的中间状态生成分支数据，同时构造等数量随机数据对照。
- D：保持同一模型结构和训练方法，比较原数据、随机扩充、分支扩充。

阶段通过即可继续，不逐阶段请示。遇到本文明确的阻塞，停止依赖部分并交付事实，不循环尝试。
本轮不迁移服务器，不改物理环境，不实现多尺度、接触模式模型、合法域投影、新损失、集成或分布式融合。
允许数据升级无效；不得以“必须优于随机”“必须暴露高估”为目标。
所有新结果使用独立目录，旧结果和 checkpoint 原样保存。

## 2. 阶段 A：修复已确认问题

### A1. Grid 聚合

位置：deterministic_grid/audit.py 的 aggregate_by_state。
当前 model_seed="mean" 混入 model_seed=-1 的精确模型。改为只平均种子 0/1/2；精确行单列。

验证：
- 当各状态重复次数相同，先状态内平均再跨状态平均，应等于全部学习模型行平均。
- 不得解释为不同聚合口径造成 3/4 倍关系。
- 旧验证集 H=4/K=256 应重新得到约 1.250/-1.450/2.700 的 selected_bias/mean_bias/excess。
- 新验证集对应约 0.867/-1.719/2.586，regret 约 1.075，chosen_true 约 -5.650；以上仅作定位参考，正式值由全精度记录生成。
- 用一个精确行和两个非零学习行的手算样例验证精确行不会混入均值。

只重算统计，不重训 Grid，不扩展 Grid 实验。

### A2. Grid 单候选反事实

位置：build_traced_case。旧实现修复了全部候选，却写成只修选中候选。

新主分析：
1. 缓存原始所有候选的 J_hat，记原选中编号 c。
2. 仅对 c 的首次指定错误做一次修复，继续该候选的模型预测。
3. 只替换 J_hat[c]，其余元素逐项必须完全不变，然后重排。
4. 同时报告新选择的真实收益是否改善；“选择改变”不等于“修复有收益”。

保留 full_state 和 object_anchor 两类干预，并逐项记录被替换的字段。false_success 若通过替换整个真状态实现，命名为“首次虚假成功处的完整状态干预”，不得称为只修成功分类。
物体位置干预若造成组合状态非法，按原协议终止，不能再额外修机器人位置。
旧全候选干预作为历史附件保留，更正因果表述，不强求新反事实仍改变选择。

### A3. 连续终止与可行性协议

位置：continuous2d_learning/closed_loop.py、rollout.py。

- 闭环选择只允许 exit_class 属于 window_complete 或 success 的序列。
- invalid_prediction、non_finite、physical_failure 都不能被执行。
- 若无可行序列：返回 planner_no_feasible_plan，live_env 不再前进一步。
- 固定候选离线诊断仍保留全部候选的分项和 J，以维持原评分分析；额外记录按闭环可行性筛选后的选择/拒绝情况。两种结果分别命名，不混成一张 chosen_true 表。
- 若预测同时声称 success 且状态非法，非法/非有限检查优先，不能因 success 提前绕过合法性检查。
- 初态已经成功或失败的吸收语义也要检查，不调用模型继续展开。

测试必须覆盖：全非法、合法与非法混合、非法+success 冲突、全合法、终止吸收；用构造输出测试，不通过改模型制造场景。

修正几何检查中 y 坐标使用 arena width 而非 height 的条件。核对预测检查与环境的越界语义；以冻结的环境合同为准，不静默扩大或缩小失败范围。

### A4. 报告与旧测试

- Grid 递归终止率以原始 JSON 重算；当前 STATUS 的约 0.918 与详细表的约 0.137 不一致，查明后更正，不能直接手改数字。
- 连续状态的“完全相等错误率”不再作为有效指标。报告位置/角度误差分布，以及按下节固定容差计算的错误率。
- 累计错误不能把正确吸收成功算成失败；teacher/recursive 分别统计，不能复用另一条链的累计变量。
- 已知 S0_dev 初态修复后 depth1 不再成功：允许更正过期测试。保留“简单自由空间场景可解”的正向测试，可使用已有且已验证可解的 S0_v1；另对修复后的 S0_dev 验证合法性和协议。不得为通过测试改场景或删除全部正向检查。
- 输出 errata，明确哪些数字更正、哪些结论撤回。A 完成后 Grid 冻结。

## 3. 阶段 B：几何、拟合与旧基线验收

### B1. 几何检查不是先验正确的 oracle

将当前几何检查用于原数据全部真实窗口末状态，按真实成功/普通窗口/物理失败分开统计：
- 真实正常状态被判非法的比例；
- robot–object、robot–robot、robot–wall、object–wall/obstacle 各对的穿透；
- engine 的接触/穿透记录与独立几何检查差异。

对真实状态误判的记录逐条保存；先确认快照时刻、形状尺寸、边界半径和穿透定义一致。仅“有接触”不得视为失败。检查器与引擎数值不必逐位相等，但阈值附近的差异必须解释。
若出现超过数值容差的系统性不一致且两次修复仍无法解决，标记 GEOMETRY_BLOCKED，停止 C/D。

对旧模型预测状态，用同样分组输出穿透 p50/p90/p99、违反阈值的类型和比例。判断 79% 是哪些几何对造成的，禁止仅凭总数直接提出新模型。

### B2. 编码和小样本拟合

先验证 encode_state_target → apply_state_delta 往返能恢复真实下一状态；角度按周期等价比较。核对 loss 的角度残差是否按合同 wrapped，而不是仅对标签 wrap 后做普通差。若确有实现偏差，修复并统一应用到后续三个正式组；旧模型仍可作历史复核。

从原 train 选 32 条不同转移：
- 16 条物体平移或转动样本；
- 8 条静止样本；
- 最多 4 条真实成功样本；
- 剩余从 train 补齐。
组内按固定 SHA256 排序、不看模型误差，去重；保存样本 ID。不能从 val/test 抽样。

用同结构、新初始化 seed=0、原损失和 Adam lr=1e-3，全批最多 3000 更新；这是训练链路检查，checkpoint 不用于正式评估。
目标为同批 32 样本上的：
- 物体平均位置误差 <=0.02 m；
- 两机器人各平均位置误差 <=0.03 m；
- 物体平均角度误差 <=0.05 rad；
- 终止类别至少 31/32 正确，无非有限输出。
这些是诊断用容差，不是泛化或论文达标线。同步报告非法率，不用几何投影降低它。

未达到时查看训练曲线、梯度、归一化、字段顺序、重复输入对应冲突标签等。最多两次针对性修复；仍失败则 FIT_CHECK_FAILED，停止正式扩充训练，交付诊断。不能直接断言是 bug，也不能自动换网络结构。

### B3. 原模型分组与闭环复核

使用三个原 checkpoint，在原 train/val/test 上计算相同指标：
- 各体位置、物体角度、速度、终止混淆、非法率；
- 平移、转动、静止、接触/无接触、任务族分组，均列样本数；
- 与 persistence 的逐样本配对误差差值。
不得以“接触样本数量多”替代接触类型及效果的覆盖分析。

连续全链累计错误使用固定容差：任一体位置误差 >0.05 m、物体角度误差 >0.10 rad、错误终止或非法预测；另外列三项的独立发生率。正确成功吸收不计错误。存活链和全链指标分别列分母。

用修复后的 A3 对旧 checkpoint 重跑原 36 个学习模型闭环回合；精确/随机结果仅在相关语义未变、哈希及定向复核一致时复用，否则重跑受影响条件。保留第一次旧协议结果，说明此前 59 次执行预测非法序列涉及 22 个回合，不能继续称其符合原合同。

## 4. 阶段 C：成功轨迹附近的分支数据

### C1. 先冻结分组，后生成数据

沿用按场景划分：
- train：S0_dev/S0_v1/S0_v2、S1_dev/S1_v1/S1_v2；
- val：S0_v3、S1_v3；
- test：S0_v4、S1_v4。

原 test 已被研发过程查看，只称固定留出回归集，不称全新盲测。
新分支 val/test 在正式训练前生成并冻结；来源场景仍与 train 分离，但不是新的任务族泛化。
禁止同一锚点及其分支跨 split。保存 teacher_episode_id、anchor_id、branch_id、prefix 和 scene hash，不能逐转移随机拆分。

### C2. 生成引导轨迹：精确模型只用于离线采集

在每个场景用修复后的 exact_fixed_pool、H=3、K=128、最多 12 窗口生成 episode seeds={0,1} 的轨迹。
若某场景两条均未成功，只允许额外 seeds={2,3}；不改变评分、候选、场景或控制器。

每场景最多保留 2 条真实成功轨迹；所有失败尝试也记录，不能隐去采集成本。
最多 40 次精确规划回合。一个场景仍无成功，报告该场景缺少引导，不用测试场景补训练。
若 train 的 S0 或 S1 整个任务族都没有成功引导，标记 GUIDE_COVERAGE_LIMITED，停止该数据假设的正式比较。
val/test 某族缺失则明确其分支评价缺口，不用错误分母掩盖。

原始成功轨迹的窗口转移可进入对应 split 的新数据。只记录真实执行标签，不使用精确模型的预测状态当监督标签。

### C3. 锚点：最多 6 个窗口起点/引导轨迹

仅从真实非终止的窗口起点取锚点，不从吸收成功状态继续采样。
- 先保留最后两个非终止窗口起点；
- 再按窗口序号均匀选其余起点，去重至最多 6 个；
- 轨迹较短则全取，不重复凑数。

使用完整精确快照/前缀恢复，保留 success_counter。不平移机器人或物体、不改速度、不把状态直接塞进模拟器来制造扰动。
锚点进入新窗口时，控制器按既有规则重置；环境物理状态、成功计时和引擎恢复语义保持不变。

### C4. 同锚点动作分支：16 条，最长 3 窗口

每个锚点的首动作包含：
- 1 条原引导轨迹下一联合技能；
- 1 条双方 hold；
- 4 条邻近动作；
- 10 条 root 技能库的均匀随机动作。
全部用全精度结构化技能，去重后不足 16 条用 root 库随机动作补齐。

邻近动作不改参数范围：在现有 root 技能库中，按双方 skill_features 与专家首动作的平方距离选择最近的 4 个不同候选，稳定 ID 打破平局；排除已选动作。该规则只用于离线采样，不能进入新部署策略。

首窗口之后最多再执行 2 个窗口：
- 概率 0.5 原样重复上一联合技能；
- 概率 0.5 从当前真实公开观测的 root 技能库均匀采样。
随机种子由 split/scene/teacher_episode/anchor/branch 派生。成功或物理失败立即终止。

保留全部分支：成功、停滞、接触丢失、逆向移动都不能按收益筛除。不要强迫轨迹留在带内；偏离后的真实状态同样是训练资料。
这些“分支”是从真实锚点重新执行得到的轨迹，不是给标签人工加噪声。

预算：
- 每条引导最多 6×16×3=288 个分支窗口；
- train 最多 12 条引导，即 3456 个分支窗口，另加最多 144 个原引导窗口；
- val/test 各最多 4 条引导，各 1152 个分支窗口，另加各最多 48 个引导窗口；
- 实际终止、去重会减少数量。记录预算使用和样本覆盖，不追加无限采样。

### C5. 等数量随机扩充对照

为区分“数据更多”与“成功轨迹附近采样更有用”，在 train 场景增加一个 RandomAdd 数据集：
- 使用原采集策略，从原场景初态开始，最多 12 窗口；
- 首窗口均匀随机，后续 0.5 重复上一技能/0.5 当前 root 库均匀随机；
- 不使用专家轨迹或其锚点；
- 各 train 场景新增有效转移数尽量与 BranchAdd 相同；
- 固定随机种子，按确定性顺序取得所需数量，不能按回报筛选。

采集上限为 BranchAdd 总有效转移数的 3 倍尝试窗口数。达到上限仍不足，记录真实缺额；等数量对比使用两者各场景可用数量的较小值，按固定哈希取样。
不混入 val/test，不为随机组特意删失败或补成功。

对新增数据按“完整输入、动作、输出、持续时间、终止标签”去重，并排除与原训练数据完全相同的转移；保留所有来源索引。
相同输入却不同标签不能静默合并：列出冲突，检查引擎缓存、状态遗漏、数值容差。轨迹边和 episode 结构保留，单独建立训练索引，不能因去重破坏序列复现。

### C6. 覆盖报告与数据不足

分别报告 Old、RandomAdd、BranchAdd：
- 场景、回合、独立锚点、不同状态、不同 state-action 对和窗口数；
- 平移/转动/静止、技能组合、接触类型；
- 真实成功终止窗口、近成功非终止窗口、物理失败窗口；
- 同锚点不同动作带来的真实进展差异。

平移 >0.01 m、转动 >0.02 rad，沿用旧统计阈值。
近成功只用于覆盖统计：物体所有角点在目标区内但尚未满足真实低速保持判据；不得将其标为 success。

成功窗口数少于 20 或来自少于 4 个 train 锚点，标注 SUCCESS_COVERAGE_LIMITED；仍可比较动力学预测，但不据终止识别得分下强结论。
物理失败样本仍为零是允许的，不制造灾难性失败以凑类别。失败分类头的学习能力继续标注未验证。
不要宣称单个成功锚点的许多近似重复分支等价于许多独立成功案例。

## 5. 阶段 D：同结构的数据对照

### D1. 三组正式训练

| 组 | 训练数据 | 用途 |
|---|---|---|
| Old | 原 train | 修复后、统一验证口径的基线 |
| Old+Random | 原 train + 等数量 RandomAdd | 控制新增数据数量 |
| Old+Branch | 原 train + 等数量 BranchAdd | 检验分支采样价值 |

三组各 seeds={0,1,2}，共 9 次正式训练。相同种子使用相同初始化。
沿用原网络、batch=128、lr=1e-3、最多 100 epochs、patience=12。记录更新次数、采样数和训练时间；Old 与扩充组更新数不同，不能声称严格等计算量。
Random 与 Branch 组新增数量相同，使用同一训练协议。禁止每组单独调参或挑最佳 test 种子。

所有组使用同一 checkpoint 选择规则：
val_score = 0.5×原 val 平均原损失 + 0.5×新增分支 val 平均原损失。
两部分按各自记录均值计算，权重在训练前冻结；无分支 val 则标记验证不足，不临时改权重继续正式比较。
验证集包含成功数据只用于选择 checkpoint，不能加入 train。小样本拟合 checkpoint 不得混入正式组。

### D2. 预测评估：原回归集与分支集分开

所有模型同时评估原 test 和新增分支 test，不把两者混成一个总准确率。
沿用 B 的位置、角度、速度、终止、非法和 persistence 对照；新增：
- 成功召回率和 precision，均写明确分母；
- 同锚点多动作的真实进展与模型进展排序；
- 非法预测导致可行分支被拒绝的比例。
新增分支集按锚点先汇总，再按场景报告；不可把同锚点几十个窗口当独立场景。

先看指标再解释，不能用总 val loss 很小证明模型已经可用。

### D3. 固定候选与闭环

固定候选：
- 沿用原 12 起点、原候选池、原精确参照；哈希匹配后复用真值；
- 本轮只复核 H={1,3}、K={16,128}、原三个候选种子；
- 三组九个模型使用完全相同的候选文件；
- 同时报告原“全候选按 J 排序”与修复后“仅可行候选选择”的结果。
- 筛选后无候选时，记录拒绝率，conditional regret 记 NA；不能给 NA 填 0 拉低均值，也不能静默删掉这些起点。全候选 regret 保持可比较。

闭环：
- 场景仍为 S0_v4、S1_v4；
- 学习方法只跑 H=3：3 数据组×3 模型种子×3 episode seeds×2 场景=54 回合；
- exact H=3 的 6 回合、uniform 的 6 回合作参照，协议/哈希相同可复用，否则重跑；
- 最多 12 窗口，沿用 A3 筛选规则；
- 模型预测 success 仍只执行首窗口，由真实环境决定是否成功；
- no_feasible 作为独立任务失败原因，报告停止时刻、已用时间和末端距离，不与真实物理失败混称。

不得因为新模型变好或变差临时扩大 K/H、调整罚项、加入投影或修改场景。
至少保存 2 个有改善和 2 个无改善/退化的对照案例；没有该类案例就如实说明，不凑数。

## 6. 结论判据与停止条件

- 若 Branch 比 Old 好、但不比等数量 Random 好：支持数据量/覆盖改善，不支持分支采样有额外优势。
- 若 Branch 比 Random 在关键转移误差、非法率和候选选择上同时改善：支持任务相关分支覆盖有帮助；仍是小规模工程证据，不宣称算法创新。
- 若状态误差改善但排序/闭环未改善：指出误差改善没有转化为决策收益，检查成功识别和决策相关误差。
- 若成功识别改善、非法率仍很高：不能宣布世界模型已可靠，分开定位几何预测。
- 若三组连训练集关键样本都拟合不好：报告拟合问题，不直接归因于多步漂移。
- 若训练集好、留出场景差：报告泛化/分布覆盖问题，不直接换成几何约束新框架。
- 若结果无明显规律，报告不确定，不以一次数据升级失败否定单窗口模型。

GEOMETRY_BLOCKED、FIT_CHECK_FAILED 会停止 C/D；GUIDE_COVERAGE_LIMITED 停止正式分支假设比较。
SUCCESS_COVERAGE_LIMITED 只限制成功类结论，不阻止动力学比较。
所有停止状态写明已完成、未运行、最小复现及下一项具体需求。
