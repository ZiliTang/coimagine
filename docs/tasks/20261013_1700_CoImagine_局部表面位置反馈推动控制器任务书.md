## 1. 目标与执行边界

实现一个新推动控制器：**局部观测生成接触几何参考位置，以位置误差产生推进力，以自身速度反馈提供阻尼。** 与当前速度式控制器在同一物理环境、同一 option 协议下配对测试。

主要问题不是速度跟踪率，而是：接触是否更容易维持、有效运动是否足够、状态转移是否对小扰动更稳定，以及是否更适合后续技能预测。

按 A→B→C→D 完成实现、测试、实验、动画和报告，不只提交方案。保留失败样本；负结果允许且有价值。参数不合格不代表需要一直调到成功。

冻结物理质量/形状/摩擦/阻尼/力上限/时间步、局部传感信息边界、物体真值只用于传感仿真及评估的隔离。不训练世界模型，不扩大旧数据集，不实现全局物体定位、物体轨迹控制、切向材料点追踪、yaw控制或新规划器。

旧位置控制代码只作为设计参考：不要复制旧增益2000/250，不复制限幅后额外加单位力的实现，不启用直接设置速度的分支。新控制全程经真实受限力驱动。

## 2. A：确认基线，先排除协议错误

用户提供的当前基线是 `local-contact-option-push-v3`：Kv=25 N·s/m，参考加速度上限3.0 m/s²，其余值以实际版本配置为准。先输出一页事实表：提交、配置hash、实际控制公式、APPROACH/READY/BRAKE/SETTLE语义、观测延迟、判稳实现。

此前已发现的问题必须已有修复与回归证据：

1. 表面法向速度用采样时间戳差，逐点RMS；重复/乱序帧不能累积新稳定证据。
2. 延迟队列不冻结最初帧，不删除未来待投递帧。
3. BRAKE实际施力使用正在减速的参考，阶段重置是否有跳变明确记录，不能用日志参考代替实际执行参考。
4. 每台机器人独立READY，双ready握手；有效接触计时无多加一周期。
5. 成功接续不是 `len(steps)==3`；终态速度含两机器人和物体的线/角速度评估。
6. root级配对bootstrap使用真实root_id，并同时报告位置和角度。

若仍有错误，先修复公共协议并让两种控制共同使用，再做实验。记录为协议修复，不归功于新控制器。不要直接把旧报告的结果拼入新表。若版本与用户参数不一致，记录差异并冻结实际当前版本，不猜测或拼装不存在的v3。

## 3. B：新控制器定义

### 3.1 信息与符号

机器人i已知自身全局中心位置p、速度v、朝向及队友共享信息。局部测距给出表面线段/点及法向；不提供物体质心位姿、速度、完整顶点或真实面编号。

n为滤波后的单位法向，朝向物体内部；t=Rot90(n)。机器人为圆形、半径r。单位统一为m、s、N。

当前版没有稳定的材料接触点跟踪。本轮的“表面参考”指当前局部几何，不宣称能恢复指定物体材料点或固定切向接触位置。

### 3.2 参考接触位置：写清楚，不让agent自行选择

使用当前已通过可见性/置信度检查的局部线段。将该段观测质心c和滤波法向n转到世界系，构造穿过c的局部支撑直线。机器人中心到该线的有符号距离：

`d = dot(c-p, n)`

垂足为 `q = p + d*n`，对应无压入的机器人接触中心参考：

`p_contact = q - r*n`。

若垂足落在观测线段切向范围之外超过0.01m，不向无限延长面继续推动；标 `patch_support_lost` 并按公共协议处理。测量略受噪声影响可以用既有丢观测容忍时长，但禁止无限保留旧面。法向跳变/角点规则沿用已验证协议。

`gap_signed = d-r` 可为微小负值，不用 `max(gap,0)` 隐藏穿透。负值是否可信由传感及物理评估判断，不把真值穿透反馈给控制器。

### 3.3 虚拟推进偏置与施力

技能参数为 `(delta, alpha, active_duration, force_limit)`。delta表示虚拟位置偏置长度，不称为物体预期位移。

定义 `direction = cos(alpha)*n + sin(alpha)*t`，PUSH阶段：

`p_ref = p_contact + beta*delta*direction`

`e = p_ref-p`

`e_bounded = clip_norm(e, e_max)`

`F_raw = Kp*e_bounded - Kd*v`

`F_applied = clip_norm(F_raw, F_max)`。

初始固定配置：Kp=100 N/m；Kd等于冻结基线Kv（预期25 N·s/m）；e_max=0.10m；F_max沿用物理上限15N。推进偏置delta≤0.08m。默认delta=0.04m，alpha沿用基线动作角。

beta在进入PUSH后由0线性升至1，默认爬升时间0.20s。这是虚拟推进量的平滑启用，不承诺整个p_ref具有全局加速度界；表面运动和方向更新也会改变p_ref，必须记录真实参考变化及力变化。

本轮不做增益搜索。先使用上述配置完成小验收；如失败，检查符号/单位/传感/阶段实现，修复后复测。确认无bug仍失败则交负结果，不自动增加积分项、力前馈、阻抗优化器或更换参数网格。

### 3.4 这个控制与旧控制的关系必须说明

按上述定义，忽略限幅且beta=1时：

`e = gap_signed*n + delta*direction`

`F = Kp*gap_signed*n + Kp*delta*direction - Kd*v`。

所以新控制增加的是**观测间隙的位置反馈**及位置偏置语义。接触间隙为0时，如果 `Kp*delta=Kv*s` 且 `Kd=Kv`，两种控制的稳态代数形式相同。这是预期关系，不是失败。

必须写一个固定平面、零间隙、未限幅、参考已稳定的单元测试验证两者输出相等；再给正/负间隙案例，证明新控制确实响应几何误差。禁止用 `p_ref=p+delta*direction` 替代本节定义后声称新增了位置反馈。

本轮切向偏置是推进偏置，不是切向位置恢复器。新控制能否减少切向滑动必须实测，不预设成立。

### 3.5 阶段集成

为隔离PUSH控制的影响，**APPROACH、READY、BRAKE、SETTLE采用同一已修复基线实现，两臂完全相同**。不同时改接近速度和制动策略。

进入PUSH时冻结技能delta/alpha，beta从零开始；传感几何持续更新。脱离接触时按既有短暂掉接触/超时协议处理，不能无限用位置误差追赶。退出PUSH后撤销虚拟推进偏置，进入公共制动；不要把侵入式p_ref保留到SETTLE造成持续推物体。

控制器内部状态及参考缓存重置规则显式定义。不得重置物理速度、位姿或接触历史。非活跃机器人继续采用共同制动协议。

## 4. C：配对实验

### 4.1 两个主要实验臂

- V：冻结v3速度式PUSH＋公共分阶段协议。
- X：新表面位置反馈PUSH＋完全相同公共分阶段协议。

不需要重跑所有历史O/P/F条件。本轮只回答更换PUSH控制的收益。

从既有120测试root、8扰动变体完整继承初态、alpha、主动机器人和扰动。V的速度s映射为X的偏置：

`delta = Kv*s/Kp`。

Kv=25、Kp=100时，s={0.08,0.16,0.26}分别对应delta={0.020,0.040,0.065}m。这个映射只匹配零间隙下的名义推进项，不保证相同实际速度、冲量或轨迹。不可写成“等实际作用力对照”。

若实际冻结基线配置导致delta超0.08m，不静默clip；标明动作超出本轮定义并在运行测试前解决配置一致性，不能基于结果选择保留样本。

先用24开发root跑2臂基准变体（48次）完成执行验收。通过信息/物理/记录正确性后，跑120×8×2=1920次测试。开发集物理效果不好但没有实现错误，也运行并报告；严重数值不稳定可停止对应臂，标明失败范围。

### 4.2 主要指标

各场景类型、各推进等级分层，名义与扰动分开。必须报告：

1. 有效推动完成率、接触占比、接触丢失/局部片段丢失/角点中止率、接近与PUSH耗时。
2. 沿初始命令方向的有效位移、物体转角、PUSH阶段与全option位移，实际线/角速度。无运动与正常推进分开，不能用更少移动解释成更稳定。
3. 力请求与实际施力的峰值/P95、限幅占比、冲量、最大穿透；法向/切向力分量、gap_signed、参考位置误差。不能用仅有“力不超15N”证明没有冲击。
4. 真值终态残余速度、观测判稳覆盖率、假稳定率及超时。接触稳定和物体静止是不同指标。
5. 同root扰动对终态的平移/角度影响，中位数/P90/P95；按扰动种类分别报，不能把噪声与初始速度扰动混为一个分数。
6. 两机器人接触状态组合、相对物体的切向滑移量。此处可以由评估器用真值跟踪接触坐标，结果不得反馈控制器。

主要比较使用同root/同等级配对差，bootstrap按root重采样，输出位置和角度各自的区间。主表包括所有案例；共同正常完成子集仅作辅助。

另列双方都能产生明显运动的root。可用2cm或3°标为运动明显，但两者分别展示；阈值不得根据结果修改。运动量分箱只作辅助，不把不同root的分箱结果当严格因果对照。

主要工程判断不再使用“速度跟踪接近1”或“位移必须达到旧oracle的80%”。明确哪些推进等级有实际用途，给稳定性与运动量的权衡。如果X只是V的近似等价重参数化，直接报告这一结果。

### 4.3 三类必交时序诊断

中央单推、双机器人同侧推、偏心转动，各预先按root_id选1个基准案例，V/X并列输出：

- p_ref、p_contact、机器人/物体轨迹；
- gap_signed与位置误差的法向/切向分量；
- 参考/实际速度（X没有速度目标时明确N/A）；
- F_raw、F_applied、接触冲量和穿透；
- 阶段、beta、接触状态。

需要解释力尖峰时，以这些时间对齐的数据为证据，不再直接写“限幅导致尖峰”。若变差，区分参考点跳变、片段切换、接触负载、公共协议和数值积分等候选解释，不凭聚合量定因果。

### 4.4 接续

使用之前固定的12个root，各臂连续执行3次原技能；共24条链。仅重置控制器内部状态，真实物理状态继承。不把失败后的制动稳定当正常推动完成。

分别报尝试步数、正常完成步数、三步均正常完成的链数，以及真假稳定后下一步的可执行性；检查是否出现每步看似稳定但接触位置持续漂移。
