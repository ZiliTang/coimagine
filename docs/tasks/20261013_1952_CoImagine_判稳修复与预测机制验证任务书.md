**本轮固定使用 V 控制器，修复判稳测量与记账，开始真正的小规模终态预测训练，并用精确仿真验证“看起来相同、但下一步应该做不同选择”的机制。**

| 阶段 | 问题 | 应交付的证据 |

## 1. 已有结论与固定约束

### 1.1 可以沿用什么

最新报告中，V 有效推动完成 850/960、正常局部判稳 647/960；X 分别为 772/960、592/960。V 是本轮默认执行器，理由是现有任务上的完成与保持接触表现，而非速度跟踪率高低。

noise 和 delay 变体都出现 0/120 判稳。前者存在相邻帧差分的噪声放大，后者存在重复时间戳清空保持窗的问题。已有窗口化估计仅是 dev 诊断，尚未证明可安全替换正式估计器。

“未判稳退出时真值已低速”不等于可以删除判稳条件；“可观测终态位置预测误差较小”也不等于完整状态可观测，或已经具备递归规划能力。

### 1.2 不得改动的部分

1. V 的动力学、底层力控制、参数、推动方向定义及接触计时规则保持不变。预计 Kv=25、a_ref_max=3、F_max=15、控制周期 0.05 s；先核实当前版本，差异登记，不静默覆盖。
2. 保留有效接触推动累计 2 s、原 APPROACH/READY/PUSH/BRAKE/SETTLE 结构，以及现有超时预算。
3. 保留法向速度门槛 0.02 m/s、保持 0.30 s 和现有机器人低速门槛。
4. 控制与可部署预测输入不得读取物体全局位姿、速度、真实面编号或物理参数真值；自身和共享的机器人位姿、合法局部传感、静态地图和技能命令可用。
5. 真值可以用于生成合法初态、标签、审计和精确参照；必须与部署输入分离。
6. 不把旧固定 2 s 窗口数据直接混入新 option 终态数据。控制器、终止协议、传感和字段版本必须随记录保存。
7. 使用 PyTorch 及其自动微分。不得手写自动微分，也不得将未训练回归器的结果称为世界模型训练结果。

先创建 CONTRACT.md，冻结输入输出、拆分、评分与预算，再运行正式实验。例行实现无需再次询问授权；超出本任务的扩展只列建议。

## 2. 阶段 A：小范围判稳修复

### A1. 先把退出原因与静止状态分开记录

保留首次中止原因；中止后完成制动并判稳，只更新 settled_after_abort，不能改成正常完成。

至少分别记录：

- effective_push_completed；
- primary_exit_reason；
- locally_settled；
- settled_after_abort；
- 退出时及完整保持窗内的真值低速审计标签。

不得将“中止后静止”计入“正常完成并判稳”。修复该标志的不可达赋值路径，并以合成中止后判稳轨迹验证可达性。

### A2. 修复时间戳，再评估窗口化估计

时间戳处理要求：

- 采用传感器采样时间，不采用重复读取时的控制周期时间。
- 同一帧只能作为一份证据。重复帧不重复累计静止时长，也不因“重复”自动清空已积累证据。
- 数据过旧、真正丢失观测、片段无法匹配时必须标记不可用；明确最大新鲜度和允许采样间隔。
- 只有新鲜、可比较的证据覆盖保持窗时才可确认；仅收到陈旧静止帧不能证明当前已静止。
- 100 ms 延迟须显式记录。报告判据证明的是哪个采样时段的静止，以及与当前时刻的滞后，不能把历史低速说成当前真值保证。

窗口化估计优先复用上一轮已有 dev 实现。审查其坐标变换、对应关系和因果性，只允许比较预先写入合同的两个窗口长度：0.20 s 与 0.30 s。不进行额外参数搜索。

要求先在时间上估计有符号局部运动，再作必要的空间聚合；不得靠先取绝对值后简单平均消除噪声，也不得把不同点正负运动平均抵消来掩盖旋转。

最低验证：

1. 静物体、机器人自身运动：估计应抵消自身运动。
2. 已知法向匀速，包含低于与高于 0.02 m/s 门槛的运动。
3. 旋转使不同采样点法向运动相反：不能因均值抵消而判静止。
4. 2 mm 噪声、100 ms 延迟、重复帧和长时间无新帧。
5. 先静止后运动，检查窗口滞后造成的错误确认。
6. 纯切向运动明确标为本地传感盲区，不宣称此修复保证物体全状态静止。

上述检查使用真值作为审计参考，不能反馈给部署估计器。

### A3. 选择与复核

仅在 dev 上选一个候选；选择顺序是先检查运动误判与陈旧数据误判，再比较静止时确认率和确认延迟。不得仅按判稳率选型。

采用候选后重跑 V 的原 test 960 条，与旧 V 日志按 root/variant 配对。X 不重跑。旧 test 已被多次查看，称为“既有回归集”，不称为全新泛化验证。

输出按变体的正常完成、中止后判稳、超时、不可观测、错误确认、确认延迟；所有比率注明分母。关键安全检查不通过则不启用候选，保留旧协议并记录失败，本轮不继续发明第三个估计器。

**B/C 统一使用 A 最终冻结的协议。**即使仍有未判稳样本，也保留真实退出与残余速度继续 B，不要求先达到 90% 判稳率。

## 3. 阶段 B：小规模真实终态预测训练

### B1. 数据单元与规模

每条记录为一个实际联合 option：从执行前信息到执行退出时的信息与标签，时长可变。不得将其偷换为固定 2 s 后的状态。

先审计已有数据能否满足字段、版本及独立 root 拆分；可以复用合格数据。明确上一轮 V 的 n=958 与 960 的两条差额：逐条说明缺失原因，并计入数据总账。

新采样采用同一物理初态下的动作分支：

- 初始 train 256 roots、val 64 roots、test 64 roots；
- 每个 root 最多 8 个固定生成的联合技能命令，共最多 3072 次执行；
- 同 root 的命令集合必须包含真正不同的合法控制选择，不以重复随机种子冒充动作分支；
- 选择命令只能使用允许观测，不能根据真值挑选最有利动作；
- 不要求每个 root 都有成功动作，不删除失败、中止、传感缺失或未判稳结果。

新 root 覆盖现有合法构型类别和已有技能参数范围。优先沿用已有构型生成器，不修改物理任务来方便学习。训练、验证、测试按底层初态家族分组，几何近重复、扰动版本、同轨迹派生状态不得跨 split。

本轮主训练先采用无附加噪声和延迟的传感条件，隔离基本可学习性；A 的噪声/延迟测试单列，不混成“鲁棒训练已完成”。保留真实传感范围和遮挡限制。

先采 32 个 train roots 完成管道和小样本拟合检查，通过后才扩至规定规模。采样失败单列，不无限补采。

### B2. 输入、输出与参考模型

训练前提交字段表：名称、维数、坐标系、归一化、来源、可用时间、mask；检查不存在未来信息泄漏。

**主模型输入：**双方机器人可共享的起始局部观测、自身运动学、静态场景信息、联合技能命令。沿用现有合法局部几何特征，并保留观测有效性。不要因为本轮使用融合输入，就宣称已经实现分布式模型。

已有真实执行历史可以作为单独诊断，但本轮不新增历史编码网络。没有历史时明确预测器以当前信息为条件，不伪造历史。

**主输出：**

- 双方可观测终态几何：有符号距离、切向偏移、法向方向，统一表达在各自起始机器人坐标系；
- 机器人终态自身位姿变化与残余速度；
- option 实际时长；
- 观测有效性与执行退出类别。

先核实切向偏移所依赖的片段对应是否可部署计算；若实际只是片段质心变化，就按该名称报告，不能称为物体材料点位移。法向用 sin/cos 处理周期性，报告角误差。

缺失几何用 mask，保留离散结果；不能填零后参与几何损失。未观测类别样本仍计入分类评价。预测失败不能通过过滤从分母消失。

**必须有的比较：**

1. 简单基线：持久化终态几何/机器人状态；时长和类别使用 train 统计量。所有坐标转换必须与标签一致。
2. 可部署信息模型。
3. 特权信息参考：在同样模型中额外提供物体真值初态，仅评估信息增益，不作为可部署结果。

可以给两种学习模型预留相同输入槽，可部署版本的特权槽恒为零；保持隐藏层和训练预算一致。特权参考未改善只说明此实验未用出收益，不能据此证明完全可观测。

该模型是**局部观测与执行结果的终态预测基线**，尚不是可递归调用的完整信念世界模型。

### B3. 固定训练配置

默认采用 2×256 MLP、ReLU、Adam、学习率 1e-3、batch 128、最多 200 epochs、验证 patience 20、种子 0/1/2。不做宽度或学习率搜索。

连续目标按 train 统计量标准化并使用带 mask 的回归损失；离散目标采用相应分类损失。各目标组损失权重先写入合同，固定后不得按 test 调整。checkpoint 只按预先定义的 val 综合损失选择；不得混入精确模型行平均。

记录参数量、训练时间、每组训练/验证曲线。32-root 小样本检查若无法明显降低训练误差，先检查标签、归一化、mask、梯度和优化是否工作；最多一次有依据的实现修复，不用大采样掩盖错误。

### B4. 允许一次有限扩充

只有第一档完成实际训练、没有数据/标签故障，且在验证集上出现至少一项超越简单基线的任务相关预测收益，才允许新增 256 个 train roots。是否扩充仅根据验证集决定，两档配置冻结后再汇总测试结果。

第二档 train 共 512 roots，val/test 不变、命令生成不变，总执行上限 5120 条。两档训练使用相同配置和种子；本轮到此停止，不启动第三档。

若第一档没有上述信号，交付负结果、误差分组和原因候选，不自行升级模型或采十万条数据。

### B5. 评价要求

逐目标报告 MAE 或角误差的中位数与 p90，报告分类混淆、各类数量及召回。按构型、真实发生运动/近静止、正常结束/中止/未判稳分组。

单列“动作是否产生不同终态”：同 root 不同命令的真实输出 spread，以及模型是否捕捉其变化。整体误差被大量近静止样本稀释时，不能宣称推动已学会。

结果按 root 聚合，三种子完整列出；不把同 root 的 8 条分支当作 8 个独立实验。测试集只用于最终报告，不参与第二档的样本挑选或参数设置。

## 4. 阶段 C：精确仿真的信息歧义机制实验

### C1. 需要证明的具体命题

寻找两个合法物理世界 sA、sB：

- 双方机器人所有允许共享的当前输入相同或在明确传感噪声下难以区分；
- 可执行技能命令集合相同；
- 真实后续结果表明：在 A 中合适的选择，在 B 中明显更差，反之亦然。

“物体状态不同”本身不是正例。“局部法向一样”也不是正例；必须检查双方完整允许观测和可用历史。

这是检验信息结构是否影响决策，不是证明新世界模型优于已有方法。

### C2. 有界搜索

只尝试两个模板，每个最多 32 对候选：

1. 双机器人接触同一长直边，物体沿边切向位置不同；
2. 在相同合法局部接触观测下，与已知通道或障碍有关的后续动作选择不同。

先使用已有物体与传感配置。若物体端点始终可见而不存在歧义，可以另建一个明确版本的长矩形机制场景；同一对世界内形状、尺寸、质量、地图完全一致，并检查初态合法。新场景与旧基准分开，不能悄悄缩短传感范围或裁去端点。

每对比较以下内容：双方位姿与速度、原始扫描、有效性与遮挡、局部片段、接触读数、已知地图、命令以及已有历史。不能只比较网络压缩后的几个特征。

优先寻找在确定传感下数值容差内相同的观测。近似但可分的确定观测只能称“近似”，不能直接当成完全不可区分；若采用已有 2 mm 噪声条件，需给出重复观测的可分性诊断，并说明其只是经验支持。

如使用冷启动、无历史场景，明确标记。不得把它推广为拥有长历史的机器人仍然无法辨识。

### C3. 用收益矩阵证明“选择不同”

对每对候选使用同一组至多 8 个可部署联合技能。先测单技能，必要时枚举最多两技能序列，不继续加深。

使用项目已有任务评分；如该机制场景没有可用评分，在运行前固定“完成、进展、时间/动作代价”的定义。所有方法用同一评分。精确模拟不等于全局最优，只相对于该有限候选集。

报告各世界、各动作/序列的真实结果与收益。若收益越高越好，定义：

- Q_h(a)：世界 h 下候选 a 的真实收益；
- R_h(a) = max_b Q_h(b) - Q_h(a)。

正例要求两个世界的近优动作集合没有交集，且错误选择的 regret 超过事前设定的数值容差及重复仿真误差。仅仅 argmax 因微小并列误差不同，不算。

每个正例保存完整快照、观测和技能命令，以精确重放核验。

### C4. 展示信息乐观，而不是制造无法执行的策略

对通过 C3 的案例，可采用明确声明的 50/50 两世界先验。这是受控机制实验，不宣称是自然任务中的真实先验。

先计算：

- 全知参考：0.5 max_a Q_A(a) + 0.5 max_a Q_B(a)；
- 未区分世界时的共同动作：max_a [0.5 Q_A(a) + 0.5 Q_B(a)]。

二者之差展示隐藏状态信息的潜在价值，**本身不证明某个现有规划器犯了信息乐观错误**。

对于两技能序列，进一步检查第一技能之后双方会获得的观测：

- 仍不可区分，则第二步必须采用同一个决策规则，不能按真值世界分别挑动作；
- 已经能够区分，允许根据实际观测分支，不能把合法适应算作作弊。

至少给出一个遵守这一约束的有限候选信念规划参照；不可只与均值状态规划器比较。可直接枚举，不开发通用 POMDP 求解器。

若现有技能允许重新接触、移动到端点等获取信息的动作，可以附加比较“直接推”与“先改变观测再推”。必须计入实际时间和动作代价，不提供免费的真值扫描。没有合适的信息动作则如实止于收益矩阵，不新增控制器。

**负结果处理：**64 对候选搜索后无正例，记录是观测已足够区分、动作排序没有实质差别、还是技能集合不足。本轮停止 C；不删观测、不反复改评分，也不因此取消 B 的结果。

## 5. 工程边界、预算和测试

1. 新建隔离实验目录，例如 experiments/option_prediction_mechanism_v1/ 和对应 docs/outputs；只在判稳实现与必要记账处改现有运行代码。
2. 按 A → B 小样本检查 → B 第一档 → C → 可选 B 第二档执行，长步骤保存可恢复状态。
3. 一台机器总墙钟预算默认 12 小时。60 分钟无新有效产物须诊断耗时；预算不足优先交付 A、B 第一档及 C 已完成部分，不跑空、不静默降低合同。
