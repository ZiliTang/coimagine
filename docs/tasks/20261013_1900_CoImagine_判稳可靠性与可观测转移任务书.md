## 1. 本轮要解决的问题

上一轮把控制律的问题排除了：速度式 V 与位置式 X 在零间隙下代数等价（测试 1e-9 通过，
实测 `gap_signed` 中位 −0.0001 m），X 在所有指标上更差或持平。**继续比较控制律没有意义。**

同时留下一个未解的关键缺口：**"每个 option 结束都镇定"只有 62–67% 成立**，而
"每步镇定以降低学习难度、缩小模型要覆盖的分布"正是整条路线的前提。本轮把它当作第一优先。

第二优先是把上一会话做错的一个分析重做：可预测性分析的目标里混进了**原理上不可观测**的
物体全局朝向，导致结论不可用。

第三是用户提出的方向性假设：两台机器人在**不同边**上推（"夹出来"）能不能让可观测转移
对隐藏位姿不敏感——这个还没测过（上一会话那个粗糙检验被 `dual_rotate` 混淆了，无效）。

## 2. 执行边界（冻结，不得改）

物理质量/形状/摩擦/阻尼/力上限/时间步；局部传感的**信息白名单**；`continuous2d` 的冻结场景；
物体真值只用于传感仿真与评估的隔离。不训练世界模型，不扩旧数据集，不实现全局物体定位、
物体轨迹控制、切向材料点追踪、yaw 控制或新规划器。不为了把指标做正面调门槛或筛样本。

**负结果照原样交付**；门槛未达到不算 BLOCKED。

## 3. A：判稳可靠性（第一优先）

### A1 先把账算清

用现有 1920 条测试日志（`outputs/local_position_push_v1/local-position-push-v1/`，若本机没有就重跑，
`run_pair.py --split test` 约 1 分钟）测量：

- 从 PUSH 结束到**真值**物体法向相对速度降到各门槛以下的耗时分布；
- BRAKE+SETTLE 预算（4 s）的实际消耗分布，以及有多少执行是"只差一点点时间"；
- 未判稳执行的退出原因细分（`settle_timeout` / `settle_unobserved` / 接触丢失 / 片段丢失 / 支撑丢失）；
- 真值窗检查：若把门槛放到 T，**新增判稳**的执行里，在 0.30 s 保持窗内是否物体与两台机器人都真的
  低于门槛（`analyse_settle.py::hold_window_is_truly_still` 已有实现，直接复用）。

### A2 选一个方案并给出真值验证的误报率

候选（至少评估前两个，第三个作为对照）：

1. **门槛 0.02 → 0.03**：上一会话的反事实显示 +7 个百分点、190 例新增里只有 1 例真值不达标。
   这是唯一接近免费的改动，但要按 A1 的真值窗口径重新确认。
2. **主动制动**：现在 BRAKE/SETTLE 只让机器人自己停（`F = clip(Kv·(0−v))`），物体靠自身阻尼滑行
   （时间常数 ≈ 0.38 s）。改成在制动阶段让机器人**贴着物体把它也按住**（仍只能用局部观测，
   仍受 15 N 上限），看尾迹是否显著缩短。注意这改的是公共协议，两臂共用。
3. **延长预算**：把 4 s 放宽。报告它对总时长和"卡住"观感的影响。

**目标：判稳率 ≥0.90 且真值窗误报率 ≤5%。** 达不到就如实报告卡在哪。

A2 的任何改动都是**公共协议修复**，两臂同时生效，必须重跑 V 与 X（1920 条）并重出对照表，
不许把旧结果拼进新表。

## 4. B：用正确的目标重做可观测转移分析

### B1 目标与输入都要是可观测的

上一会话的错：预测"物体终态在机器人起始坐标系里的位姿"，含全局朝向，原理上不可观测。

本轮改成：

- **输入** = 技能起始时白名单里的东西：自身位姿与速度、局部片段的点集/拟合线段/法向/置信度、
  接触标志、队友的相对位姿、技能参数（α、δ/速度）。
- **目标** = 技能结束时**机器人会看到的那段局部几何**，表达在机器人自身起始坐标系里
  （例如终态片段的法向角、有符号距离、切向偏移；以及"接触是否仍在、是否换面"）。
  不要包含物体全局位姿的任何分量。
- 若终态片段不可用（换面/丢失），把它当成一个**离散结果**单独报，不要丢掉样本。

### B2 评估协议

留一 **root** 交叉验证（同一 root 的 8 个变体整组留出），位置与角度**分别**报 R²。
另外报：

- "only observable" 与 "truth features"（含物体真值初态，作为**上界参考**，不是可部署输入）的差值；
- 在共同正常完成子集上的结果（辅助）；
- 残差是否与隐藏量相关（例如用真值物体朝向给残差分层，报告残差是否随隐藏朝向系统变化）。
  这一项是回答"可观测转移对隐藏状态有多敏感"的关键。

## 5. C：楔形接触构型

### C1 在**同一运动类型内**对照

上一会话的比较无效，因为楔形 root 全是 `dual_rotate`。本轮要造同类型对照：

- 取同一个平移任务：目标物体、初态、动作角、速度都相同；
- 只改两台机器人的接触位置——**(a) 同一条边** vs **(b) 相邻两条边**（法向夹角 ≈90°）；
- 每类各 4 个 dev root + 8 个 test root，扰动变体沿用现有 8 个（同一份定义与 hash）。

### C2 测什么

- 终态跨扰动离散度（位置与角度分开）；
- B 节模型在两类上的**留一 root 残差**；楔形是否显著更小；
- 接触丢失率、有效推动完成率、判稳率（楔形是否以稳定性为代价）；
- 真值切向滑移量（楔形是否真的减少了物体姿态的不确定性）。

### C3 如果有效

报告"楔形是否值得加进 option 家族"，以及要让策略**主动偏好**它还需要什么。这里必须写清：
一个只做极大似然的动力学模型不会自己把策略推向可预测区域，不确定性要在某处**显式**进入决策
（模型集成 / 悲观规划 / 代价里的预测方差项）。不要在这一轮就去实现那套机制，只给判断和证据。
