## 0. 本轮目标与边界

检验：在机器人自身全局位姿已知、两机器人可以交换信息，但控制器不能直接读取物体全局真值位姿/速度的条件下，局部接触面反馈能否产生接触更连续、推动时长更明确、终态速度更小、对小扰动更不敏感的联合技能转移。

这是假设验证，不预设新控制一定更准、轨迹一定为圆弧。已有学习模型的预测问题不能全部归因于旧技能。

本轮完成控制器、传感接口、分阶段 option、配对物理实验、简洁结论。**不训练世界模型、不收集 512k 数据、不改旧模型结构/权重、不接入学习规划器、不实现全套 SLAM 或目标物体全局定位。** 保留旧控制与旧数据，新增版本化路径。冻结物体质量、形状、摩擦、阻尼、机器人尺寸/质量、力上限、物理步长；不能用增强摩擦或阻尼掩盖控制问题。

当前实现是平面全向力驱动圆形机器人。第一版验证平移控制，允许在机器人自身坐标系观测并将法向转到共享坐标系，不要求底盘实际转向。不得把绘图箭头/虚拟朝向当作已完成 yaw 控制。真实底盘转向和有限视场传感头是后续独立问题，不在本轮偷偷加入转矩执行器。

## 1. A：实现事实与信息边界

### 1.1 先核对当前代码，不凭报告推断

用一页表确认：旧窗口是否仍为 2 s；机器人/物体速度是否继承；旧 Push 的接触判定、接近阶段和推送阶段；方向采用世界系还是物体系；完成/制动语义；控制周期和力上限。给实际文件与函数名。若与本任务描述不同，在 errata 中修正后继续，不覆盖旧实现。

### 1.2 新控制器只能接收白名单观测

新增不可访问原始 env/BodyState 的 `LocalContactObservation`，内容限于：

- 自身机器人全局位置、朝向、线速度、角速度；队友分享的同类量及阶段状态。
- 当前可见局部表面片段：机器人坐标系下的采样点、拟合线段、距离、法向、可见性/置信度、时间戳。
- 本机器人触碰目标物体的布尔量；机器人坐标系下接触点及接触力/冲量的传感器读数。不得提供物体质心位置、角度、线速度、角速度、整个顶点集合、真实面编号或真实物体局部接触坐标。
- 静态地图、己方半径、固定技能参数。当前单物体场景允许已有目标身份；不研究多目标识别。

传感仿真层可使用物理引擎真值生成上述读数；控制器与评估器严格分层。第一版是**理想局部传感**，并非真实感知系统已经解决。

局部几何默认由以机器人为中心、0.6 m 范围内的射线测距生成：72 个均匀方位；每条射线返回最近遮挡面，静态障碍/队友也参与遮挡。目标表面至少 3 个点才拟合法向；不得把物体全形状投影给控制器。无噪声版本先通过，再测试噪声/延迟。连续片段只按观测空间距离和法向连续性关联，不用真实 face_id 跟踪。

法向 `n` 指向物体内部（从机器人指向表面），切向 `t = Rot90(n)`，两者在共享世界坐标系表达。已知机器人朝向只用于旋转局部测量，不等于已知物体位姿。法向无法可靠确定时停止推进并记录 `surface_unobserved`。

接触力用于监测/日志，v1 不做额外力 PI 环，避免新增积分状态。用真实接触对生成传感布尔量，但控制器不能通过接触对反查物体状态。

### 1.3 技能参数与可辨识性

新增 `LocalSurfacePush(alpha, speed, active_duration, force_limit)`。alpha 是相对内法向的夹角；正负号按 t 定义。默认持续时间 2 s、力上限沿用现有值。`local_patch` 是当前观测初始化的局部片段句柄，不是永久物体坐标。

它是沿当前表面方向持续推进的技能，**不承诺固定物体材料接触点**。沿面滑动、滑向角点均需要测量和报告，不能把固定夹角当成固定接触点。两机器人交换各自的 n、参考速度、接触状态和阶段，v1 只做同步握手与异常停止，不增加物体刚体运动求解器。

## 2. B：新控制律与 option 协议

### 2.1 表面坐标中的参考速度

推动阶段对机器人 i 定义：

`v_raw_i = speed_i * (cos(alpha_i) * n_i + sin(alpha_i) * t_i)`。

这表达参考速度，接触受阻时不保证实际达到。每次控制更新限制参考速度变化：`||v_ref(k)-v_ref(k-1)|| <= a_ref_max * dt`，初始 `a_ref_max = 0.5 m/s²`。局部法向用归一化向量的一阶滤波，时间常数 0.10 s，避免角度跨 ±π 的错误。连续两帧法向跳变超过 30° 时判为片段切换/角点；停止该次技能，不无声切换到新面继续计时。

平移力采用有界速度反馈：

`F_cmd_i = clip_norm(Kv * (v_ref_i - v_robot_i), F_max)`。

默认 `Kv = 40 N·s/m`；不积分位置误差，不直接覆盖速度，不设置物体运动，不用真值物体速度做前馈。若稳定性验收失败，仅允许在开发集尝试 Kv ∈ {20, 40, 80}，最多 3 套；选接触保持优先、穿透/震荡次之的合格最小增益，然后冻结。记录所有试验，测试集不能调参。若 3 套均失败，交付失败诊断，不扩展成任意控制器搜索。

此形式与沿局部方向运动的位置参考加反馈有相近意图，但避免受阻时参考位置无限走远。未来是否需要阻抗/导纳或接触力调节，由本轮饱和、滑移、振荡记录决定。

### 2.2 接近、同步、推动、制动

分阶段执行器与具体控制律解耦，旧/新控制均可接入。

1. **APPROACH**：仅针对当前可见表面片段的近距离接近；初始表面间隙 0.01–0.20 m。参考速度沿 n，未接触时大小 `min(0.08 m/s, max(0.02 m/s, 2 s^-1 * max(gap,0)))`；临近接触时保留 0.02 m/s 的缓慢接触建立速度，仍受力上限约束。无需全局物体绕行规划。未观测到可用片段则明确失败，不从物体真值生成导航目标。最多 5 s。
2. **READY**：真实传感接触连续保持 0.10 s 后报告 ready；先到者使用低速法向预接触参考 0.01 m/s，避免脱离。记录提前推动的位移与力。两机器人同时 ready 持续 0.10 s 后共同进入 PUSH。单机器人实验仅等待自身。到达时间不一致是测试内容。
3. **PUSH**：速度从当前参考值平滑升至目标。有效接触时间从 PUSH 阶段开始累计；双推只在双方均接触的控制区间累计，升速过程计入。目标为 2 s。连续失联超过 0.15 s、局部片段丢失超过 0.15 s 或面切换时中止，双方进入制动；PUSH 墙钟上限 3 s。短暂掉接触时暂停有效计时，仍记录真实施力；不能暂停整个物理仿真。报告 `active_contact_time` 与 `push_wall_time` 两种时长。
4. **BRAKE**：参考速度按同样加速度上限降为 0，随后用 `F=-Kv*v_robot` 限幅制动。物体完全依赖原有物理接触及阻尼减速。禁止瞬间清零任一速度。
5. **SETTLE**：机器人自身速度均 <0.03 m/s、角速度 <0.08 rad/s，且可见表面采样点变动所估计的局部表面速度 <0.02 m/s，持续 0.30 s，判为 `settled_observed`。BRAKE+SETTLE 最多 4 s。没有足够局部观测不能声明稳定，标 `settle_unobserved`/`settle_timeout`。

局部表面速度必须从连续局部扫描及已知机器人运动估计；至少 3 个有效匹配点，按观测匹配，不使用物体点的真值身份。单平面某些运动不可观测：**本地稳定判定不等于物体全局静止**。评估器另用真值检查物体线速度 <0.03 m/s、角速度 <0.08 rad/s，并测假稳定率。控制器不能读取这个真值判定；如果局部观测无法可靠判稳，结论就是目前观测下不能保证静止终态。

所有退出都有终态与耗时，包括接近失败、接触丢失、角点、超时等。物理越界/数值错误/严重穿透由环境安全终止并记录。任务目标达成只做评估标签，本轮控制器不通过物体真值提前终止；这是技能测试执行器，不改旧任务 runner。

### 2.3 必须测的潜在问题

- 两机器人参考速度可能不满足同一刚体运动；不要用共享坐标系假装这个问题已解决。相向对推、速度不匹配都是合法测试输入，允许失败或几乎不动。
- 先到者在 READY 阶段可能移动物体，使队友的接近条件改变，必须记录。
- 静止物体/机器人姿态初值只在 reset 指定；任何阶段切换不得重置物理速度或引擎接触缓存。
- 当前粘性阻尼模型不等于论文中的准静态库仑摩擦模型。圆弧只做拟合诊断；拟合差不能单独判控制失败。

## 3. C：配对实验，分开控制律与终止协议

### 3.1 四个实验臂

| 标记 | 推动控制 | 执行协议 |
|---|---|---|
| O | 原有控制原样 | 原有 2 s 窗口 |
| P | 原有控制力公式 | 新接近/真实接触握手/有效推动/制动稳定协议 |
| F | 新局部表面控制 | 2 s 总墙钟；近距离接近后推动，到时直接记录，不加终端稳定 |
| N | 新局部表面控制 | 完整新协议 |

P 保留旧公式需要的全局真值输入，明确标 oracle 基线；只是外部调度替换其接触阶段触发与终止。O 与 P、F 与 N 分析阶段协议；P 与 N 分析相同阶段协议下的控制变化（也有信息/动作参考系差异，不能称纯单因素）。O 与 N 是系统总对比。禁止顺便修旧公式后仍声称 O 原样。

新动作 alpha 与旧动作世界方向，在初始瞬间对齐；旧动作随后世界方向不变，新动作随表面变化。初始接触点用相同几何配置。明确不是整个时间段完全相同的动作。另做 alpha=0、小旋转子集，减小方向语义差异。

用同一 backend 快照分别运行各臂；快照必须包含物理接触历史的既有精确重放语义。严格避免各臂相互污染。

### 3.2 固定实验规模与拆分

先生成并冻结 24 个开发 root、120 个测试 root，root 包含初态及一对动作。每组 root 均覆盖以下六类，测试每类 20 个：

1. 单机器人中央正推，队友远离并制动。
2. 单机器人偏心推，观察转动与沿面滑动。
3. 双机器人同侧协同平移。
4. 双机器人偏心或不同侧的旋转协作。
5. 相向抵消、速度不匹配等不兼容输入。
6. 靠墙、接近角点、通道入口；包含应该受阻的情况。

物体全局角度分散；接触位置至少中央与两侧；alpha ∈ {−15°,0°,15°}，speed ∈ {0.08,0.16,0.26} m/s。不做全排列，按固定种子分层覆盖。每类至少包含不等接近距离的双机器人配置。生成器可用真值布置合法初态、初始化 O/P 动作及评估；N/F 初始化只读取实际局部扫描。

每个测试 root 生成 8 个变体并对四臂配对：基准；机器人位置小扰动（2 mm、10 mm 两级，各一）；初始残余速度两级（0.02、0.05 m/s；物体和机器人方向由固定种子给定）；观测噪声（距离标准差 2 mm，点噪声经拟合产生法向误差）；100 ms 观测与共享消息延迟；物体质量和摩擦各 ±10% 的固定扰动组合。位置扰动不得产生初态重叠；拒绝数及替代过程记入 manifest，不根据控制结果重采。

合计 120×8×4=3840 次技能执行，加开发实验。仿真确定性重跑只证明实现可复现，**不是鲁棒性/可预测性证据**。扰动版本共享名义 root_id；置信区间按 root 聚类 bootstrap，不能把 8 个变体当独立 root。

O/P 没有使用局部传感时，噪声变体只是负对照；需声明输入信息差异。物理参数扰动只属于压力测试，不修改名义环境默认值。

### 3.3 三个层面的指标

**执行是否清楚、物理是否合格：**

- 接近成功率、双 ready 成功率、有效接触时长、墙钟时长、接触保持率、脱离/角点/超时占比。
- 各阶段物体位移与转角，尤其 APPROACH/READY 占总变化的比例。
- 力饱和占比、最大穿透、越界率、机器人碰撞情况、相对表面的滑移距离。
- 本地判稳率、真值终态速度及动能、假稳定率；二者交叉表不能省略。

**状态转移是否更有限、更可控：**

- 使用初始物体系下物体 SE(2) 相对位移；仅评估器使用此坐标变换。机器人终态也以同一初始系记录。角度差使用 wrap。
- 同一 root 小扰动前后终态偏差的中位数/P90/P95；平移、角度分别列，不任意加权成一个主分。
- 按扰动大小分层；速度扰动与位置扰动不能用同一分母定义敏感度。物体末端变化与机器人末端变化都报。
- 终态接触模式分布、失败模式分布、达到有效 2 s 的比例；收敛后剩余速度是否更集中。
- 按成功执行的实际位移匹配区间（0–2 cm、2–10 cm、>10 cm）再看终态敏感度。全样本与共同完成子集同时报告，避免删除失败造成优势。
- 检查“变稳定只是几乎不动”：在中央推/同侧推样本中报告沿初始目标方向的有效位移，并以相同主动推动时长比较 P/N。O/N 的直接位移不能忽略耗时差异。

**是否具有低维运动近似：**

- 仅对运动明显的 PUSH 轨迹，拟合常体坐标 twist 的 SE(2) 轨迹，直线作为角速度近零的特例；报告位置/角度残差，不只报圆拟合残差。
- 前半段拟合参数，外推后半段，报告误差；不能用整条轨迹拟合后称预测准确。
- 滑移/接触切换与稳定接触分别报；小于 2 cm 且 3° 的微运动单列，不用它们冲低拟合误差。

无需训练网络即可得到上述结论，但不能把它表述为世界模型样本效率已改善。

## 4. D：判断与交付

### 4.1 预先冻结的工程门槛

下列是本轮继续投入的工程门槛，不是理论充分条件。先在开发阶段确认单位、测量含义，然后冻结，禁止看测试结果后修改：

- 信息隔离、力限幅、无状态瞬移、计时、快照隔离全部通过。
- 名义自由空间中央推/同侧推：N 达到有效推动 2 s 的比例 ≥90%；不能把受阻/不兼容组混入这个分母。
- N 宣称本地稳定的样本中，真值假稳定率 ≤5%；同时报告本地稳定覆盖率，不能靠永不判稳过关。
- 对上述可推动组，N 有效位移中位数不低于 P 的 80%；P 本身几乎不动的 root 单列，不能做无意义比例。
- N 相比 P 的小扰动终态位置 P90 至少下降 20%，角度 P90 不恶化超过 10%（接近零时同时报绝对差）；或仅终态残余速度明显降低、位置敏感度不降，判为“终止协议有收益，控制稳定性未证实”。同时给配对区间，区间宽则标证据不足。

不能为了达到门槛降低 speed、缩短实际推动时间、扩大传感可见区域、改动力学或跳过角点。若失败，仍完整交付表格与最有解释力的失败轨迹。

### 4.2 接续测试

若名义执行及信息隔离合格，从测试集中预先按 root_id 选 12 个配置，每个连续执行 3 个技能。传承真实速度，控制器阶段状态按协议重置；不吸附到标准位姿。测稳定末端能否成为下一次有效初态、累计耗时、接触可用性、三步末端误差及异常退出。达不到稳定终态的样本不得强行当作 rest-to-rest 继续；记录失败即可。

仅当控制对比及接续均有正向证据，报告下一轮可以采集小规模新 option 数据。**本轮不自动启动训练或大规模采样。** 若只有分阶段协议获益，建议保留协议，不把新控制律包装成成功。

### 4.3 必要测试

1. 控制器调用的观测对象没有物体真值字段；在固定 LocalContactObservation 下修改隐藏物体真值，输出力不变。
2. 对全场景作刚体平移/旋转，局部参数不变，控制力随旋转等变；有边界场景只选不受边界影响的变换。
3. 距离投影符合不代表接触；侧向错位不会触发 ready。
4. 双 ready 握手与有效接触计时正确；接近耗时不计入 2 s。
5. 丢接触、丢观测、延迟、角点、超时均有明确退出；双方协同中止。
6. 任意阶段变更不直接改物理位置/速度；力及参考加速度始终有界。
7. 本地判稳使用局部观测；评估真值不反向泄漏。构造平面切向运动等不可观测案例，验证会被报告为假稳定而非修改真值标签。
8. 配对快照重放、副本互不污染、旧 O 路径行为未改。

### 4.4 交付格式

新增目录建议 `src/coimagine/local_contact_option/`、`experiments/local_contact_option/`、`docs/local_contact_option_v1/`、`outputs/local_contact_option_v1/<run-id>/`。如必须修改共享基础设施，仅做向后兼容接口，列出 diff 与验证。

交付 `CONTRACT.md`（公式、参数、信息白名单、阶段退出）、`STATUS.md`、`report.md`、`errata.md`、manifest、JSONL 逐次执行、按控制周期抽样的状态/传感/力日志、汇总 CSV、8–12 个代表 GIF、源码与必要测试、可复现命令。审查 ZIP 包含完整新增源码、配置、指标脚本、核心小表；大日志在 MISSING 中列路径/hash/恢复命令。

报告正文不超过 1500 中文字，先回答四个问题：

1. 无物体全局位姿反馈的控制是否真实成立？局部传感仍假设了什么？
2. 接触后推动 2 s 与稳定终态是否实现？有多少超时/假稳定？
3. 哪项改善来自控制律，哪项来自阶段协议，是否只是移动得更少？
4. 是否值得以新 option 收集下一轮数据？给支持与反证，不用“测试通过”替代性能结论。

所有失败保留。遇到既有不相关测试失败，单列复现证据，不擅改测试期待。科学门槛未达标是实验结果；代码无法执行才是 BLOCKED。

## 5. 背景参考（不要求照搬）

Lloyd & Lepora, *Goal-Driven Robotic Pushing Using Tactile and Proprioceptive Feedback*：https://arxiv.org/abs/2012.01859 。支持研究局部接触反馈的合理性，不构成本控制律的稳定性证明。

Heins & Schoellig, *Robust Single-Point Pushing with Force Feedback*：https://arxiv.org/abs/2305.11048 。其假设包括已知全局接触点与近似物体初态；不能描述成无任何全局信息的方案。本轮已知机器人位姿，但不提供物体真值反馈。
