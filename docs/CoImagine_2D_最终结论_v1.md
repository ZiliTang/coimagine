# CoImagine 2D 最终结论（v1）

这份文档只回答两个问题，并且只写**有实验支撑**的部分。详细的按时间顺序的记录（包括所有
被推翻的中间结论及原因）在 `results.md`；未完成项在 `next_steps.md`。

**研究问题。**

1. 在一个两台机器人协作推动、物体只能靠自身雷达感知的 2D 任务里，**为了让 rollout 做对，
   预测必须保留什么？**
2. **什么时候通信才真正有价值？**

---

## 一、站得住的结论

### 1. 缺失的信息值多少

同等信息下，精确的**信念空间规划器**——在联合观测上分支、并**沿着前瞻更新信念**——在可解
回合上的成功率与全信息 oracle **完全相同**（1.000），代价只高 18%（3.47 对 2.94）。

> **不知道接触物理的代价是步数，不是成败**——前提是规划确实在信念空间里做。

一个冻结信念的价值函数做不到这一点：它无法给"信息性动作"定价，于是过度对冲。（rounds 16–17、28）

### 2. 什么必须被表示

| 发现 | 数字 | 轮次 |
|---|---|---|
| 模型**类别**装不下牵引或约束模式 → 规划器层面彻底失败 | 差距 18.00，成功率 0 | 7 |
| 装不下阻力 → 无损（稳妥方案本来就会叫上队友） | 差距 0.00 | 7 |
| 潜变量确实带上接触信息 | 物理解码 0.306 对随机 0.0625；位置 0.944 | 8 |
| **训练分布的覆盖**决定该模式回合的成败 | 约束消融 → **0/300**；重物消融 → 下降 **3–9×** | 30–31 |

**消融只在策略高于地板时才有意义**：同一个实验用"能推就推"是地板 0，用"推进+使能"（唯一
会选 `release` 的学习规则）才显出完全崩塌。

### 3. 预测什么才能服务 rollout

- **逐动作结果分不行**：无论目标是"移动""推进"还是"推进+使能"，都被精确参照远远甩开
  （一致率 0.125–0.263 对 0.688）。（rounds 9–10、20）
- **价值目标在单步决策上明显更好**（一致率 0.412，后悔同组最优），**但在回合层面没有优势**：
  修正输入后学价值只有 7% 成功率，而粗糙的结果分策略有 59%。（rounds 20、28）
- **多步可行性损失不划算**：预算对齐后从未占优，最大规模上每个深度都输；"更深的状态更难"
  这个立论前提也不成立。（round 26）
- **连续参数下**：可行集是**矩形**（角度窗口 × 力度阈值），阈值由隐藏物理决定；
  **回归力度阈值**明显优于两个固定力度基线（后悔 0.891 对 3.192 / 2.250），且对输入修正
  **稳健**。（rounds 18–19、28）

### 4. 什么时候通信有价值

- **消息的价值恰好等于它所替代的那次实验。** 在需要 `h` 次协推的回合里，消息价值稳定在
  约 1.0（= 一次浪费掉的尝试的期望代价），与 `h` 无关；只有**相对占比**按 `1/(6h)` 衰减。
  （rounds 23–24）
- **只在队友必需（而非仅仅更便宜）时才有价值。** 必需性测台里，1 比特让学到的模型从
  **随机水平（平衡准确率 0.500）达到精确最优（1.000、零后悔）**；而三个"队友只是更便宜"
  的测台里消息价值为零。（rounds 21–23）
- **冷启动下"必须尝试才能学到"**：代价最优的一步规则选择放弃，而放弃不产生证据；强制一次
  实验把成功率从 0 提到 12.5%（oracle 25%），**再多实验只增加代价**。（rounds 33–34）
- **有界的负面结果**：该规则**未能移植进 grid**，因为 grid 的动作集里有"队友单独推"，使队友
  不再必需，规则前提不被满足。（round 29）

### 5. 一个贯穿全项目的区分

> **信息的价值，与使用它的能力，是两个不同的量。**

- 前者由第 22–24 轮测出：一份私有事实的 1 比特，价值 4.440 后悔 + 55.5 个百分点的成功率，
  从随机到最优。
- 后者由第 28、33–34 轮测出：**同一份证据在手**，学到的规则在回合上停在 oracle 的一半到
  七分之一，而精确规划器能用满它。

把两者混为一谈，就会把"模型不行"误判成"信息不够"（或反过来）。

## 二、被自己推翻的结论（方法论部分）

报告里记录过、后来被自己的实验推翻的结论共 8 条，例如：

| 曾报告 | 真正原因 |
|---|---|
| 学价值一致率 94.7% | 前瞻截断值是**状态无关常数**，参照与标签一起退化成"选最便宜动作" |
| "不知道接触物理整条回合代价很大" | 参照是**冻结信念**版本，无法给信息动作定价 |
| "参照过度保守，53% 决策空转" | 用正确参照后，它 73 次等待中 62 次 oracle 也等待 |
| "模型在队友打滑时最差" | **私有反馈泄漏**；去掉后该组反而最好 |
| "消息把后悔减半" | 静默基线是**稻草人**（永远单人推）；公平基线把收益抹平 |
| 多步损失带来 +11 个点 | **数据量**效应（2364 对 870 样本） |

**共同教训：**一个结论被后续实验推翻时，原因几乎总是**对照组或输入被污染**，而不是效应本身
不存在。这个项目里**每一次**撤回都属于这一类——所以修好对照之后，结论往往以更窄、更可靠的
形式重新成立（例如"训练覆盖决定回合成败"在第 8 轮被指向、第 20 轮因泄漏被撤回、第 30–31 轮
以干净证据重新确立）。

## 三、没有确立的（不隐瞒）

- **学习模型在回合层面仍追不上精确参照**（差 2–8 倍）。这是当前最主要的开放问题，且已定位为
  **决策规则**而非信息的问题。
- **消息规则未能在 grid 里复现**；需要重构场景使队友"必需且不可替代"。
- **单一场景族**（机器人贴物体西面、向东推），泛化性未测。
- 完整通信协议（双向、联合公共提交规则、消息依赖的参照信念）未实现。
- 3D 与硬件明确超出本轮范围。
