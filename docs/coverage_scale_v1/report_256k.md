# coverage_scale_v1 — 256k 续跑结论

完整对照表见 [comparison.md](../../outputs/coverage_scale_v1/coverage-scale-256k/comparison.md)
（本文件末尾为摘要）。方法与上轮完全一致，只有数据规模、更新预算（`60×ceil(N/128)`，无 60000
上限，本档 120060 次）与评估间隔（每 3000 次，另存 `update60000`）不同；差异与更正见
[CONTRACT_256k_addendum.md](CONTRACT_256k_addendum.md) 与 [errata_256k.md](errata_256k.md)。

## 1. 256k 是否继续改善泛化 —— 是

同一新验证集（3584 窗口 / 128 根，与 128k 档逐条相同）主选点加权 P：

| 档 | 窗口 / 独立根 | 256 宽度 P | 512 宽度 P |
|---|---:|---:|---:|
| 128k | 128006 / 4591 | 0.3181 | 0.3150 |
| 256k | 256004 / 9176 | **0.3084**（−3.0%） | **0.2901**（−7.9%） |

新测试集（3497 窗口 / 128 根，清单先冻结）同向：0.3201 / 0.3158 → **0.3118 / 0.2953**
（−2.6% / −6.5%），成功召回 0.245 / 0.239 → 0.226 / **0.289**。逐 seed 看，512 宽度在 256k 上
三个种子全部优于 128k（0.2935/0.2897/0.2871 对 0.3133/0.3217/0.3099）。

**更数据还是更多更新。** 把更新数固定成 60000（128k 档的 `final` 对新档的 `update60000`，两者
更新数相同、数据差一倍）：0.3033 → 0.2976（256 宽度，−1.9%）、0.2948 → 0.2919（512 宽度，−1.0%）。
即**两倍数据本身**就已经贡献了一部分改善，剩下的来自更多更新；两者同向，不是互相抵消。

## 2. 改善来自哪些转移 —— 几乎全部来自机器人的移动/接触窗口

分组（新验证集，主选点，两宽度三种子均值；persistence 与被评估模型无关）：

| 分组 | n 窗口 | 128k 物体/机0/机1 (m) | 256k 物体/机0/机1 (m) | 128k→256k 非法率 |
|---|---:|---|---|---|
| all | 3584 | 0.1521 / 0.4014 / 0.3912 | 0.1497 / 0.3746 / 0.3687 | 69.6% → 69.2% |
| translation | 2022 | 0.2091 / 0.4642 / 0.4541 | 0.2058 / 0.4373 / 0.4279 | 74.8% → 75.1% |
| rotation | 1924 | 0.2080 / 0.4654 / 0.4537 | 0.2051 / 0.4394 / 0.4273 | 73.4% → 73.9% |
| stationary | 1495 | 0.0783 / 0.3177 / 0.3077 | 0.0769 / 0.2907 / 0.2904 | 63.2% → 61.9% |
| contact | 2446 | 0.1867 / 0.4414 / 0.4296 | 0.1835 / 0.4135 / 0.4047 | 78.0% → 78.2% |
| no_contact | 1138 | 0.0778 / 0.3155 / 0.3086 | 0.0772 / 0.2909 / 0.2913 | 51.7% → 49.8% |
| （persistence） | — | 物体 0.1344 / 机0 0.4837 / 机1 0.4721 | 同左 | — |

分组**互相重叠**：运动划分与接触划分独立，运动划分内部平移与转动也可同时成立（实测平移且转动
1857、仅平移 165、仅转动 67、静止 1495；接触且平移 1902、无接触且静止 976）。

结论：**下降几乎全部在机器人位置**（机0 −6.7%、机1 −5.8%），物体位置误差基本不动
（0.1521 → 0.1497），且**在所有分组都仍然大于物体自己的 persistence 0.1344**。机器人位置误差
则明显小于其 persistence（0.3746 对 0.4837），也就是说模型确实在预测机器人的受控运动，
而不是在预测物体的位移。

## 3. 非法率与候选选择是否终于获益 —— 都没有

- **非法率没有改善**：验证集 67.6% → 69.0%（256 宽度）、71.1% → 68.9%（512），方向不一致；
  测试集 68.4% → 69.3%、71.7% → 70.6%。分组内同样平（见上表），接触组仍是 78%。
- **候选选择没有一致获益**。固定候选（12 个新 test 根，K=64，种子 {0,1}，真值复用上轮缓存）
  的 H=1 与 H=3 分表：H=3 上 128k→256k 的配对差（仅两档都可行的共同行）为
  Δ选中真实 J = −0.0068 / +0.0175 / −0.4905（256 宽度，seed 0/1/2）与 −0.0049 / +0.0025 / +0.5260
  （512 宽度），符号不一致，且「有解→无解」在 256 宽度是 0/3/1 次、「无解→有解」1/1/2 次。
  拒绝率 0.911→0.926（256）、0.928→0.930（512），无可行方案比例 0.069→0.069 / 0.069→0.111。
  H=1 的真实收益差只有 ±0.02。**误拒损失 + 排序损失 = 执行 regret 的恒等式仍逐行成立。**
  12 个起点里只有 4 个在 H=3、K=64 内存在任何真实成功候选，H=1 一个都没有：候选层结论仍受限。

## 4. 更宽模型是否开始有稳定优势 —— 是（首次）

- 验证集（主选点加权 P）逐 seed：256k 上 512 对 256 为
  0.2935 < 0.3094、0.2897 < 0.3145、0.2871 < 0.3014，**三个种子全部更好**，均值 −5.9%；
- 128k 上同样比较只有 −1.0%，且 seed 0/1 是 512 更差、只有 seed 2 更好；
- 测试集上 512 对 256 为 0.2953 对 0.3118（−5.3%），128k 上是 0.3158 对 0.3201（−1.4%）。

代价仍是 512 的非法率略高（验证 68.9% 对 69.0% 基本持平，测试 70.6% 对 69.3%）。

## 5. 停止

按要求**只做 256k 一档**：没有扩到 512k，没有换结构/损失/几何阈值，没有新增闭环。预算未用尽
（本轮墙钟约 1.6 h，上限 4 h），停止是范围截断，不是观察到饱和。
