## 2. 场景与初态分布（A2，生成前冻结）

S0/S1 各 50%。S0 无静态障碍；S1 两个矩形构成竖墙与开口。

| 项目 | S0 | S1 |
|---|---|---|
| arena | (3.2, 2.2) | (3.0, 2.0) |
| 墙中心 x | — | U[1.40, 1.80] |
| 开口中心 y | — | U[0.80, 1.20] |
| 开口净宽 | — | U[0.60, 0.85] |
| 墙厚 | — | 半厚 0.09（原值） |
| 目标中心 | (2.35,1.10) + U[−0.15,0.15]² | x=2.25+U[−0.10,0.10]，y=开口中心+U[−0.10,0.10] |
| 目标半尺寸 | (0.65, 0.60) | (0.55, 0.55) |

物体初态三模式（各根 50/25/25）：

- `broad`：中心在 arena 包围盒内均匀，角度 U[−π, π]，严格合法性拒绝采样；
- `wall`：S0 随机取一面边界墙、S1 随机取通道墙盒的**一个面**，物体到该面的最近表面间距 ∈ [0.01, 0.20] m；
- `goal`：中心在目标中心 x/y ±0.9 m 内，角度 U[−π, π]，要求与目标区域最近距离 ≤0.30 m（含重叠）且尚未满足完整目标内条件。

机器人：每台独立 70% 近物体（均匀取物体一条边及边上位置，沿外法向使圆-面间隙 U[0.005, 0.25] m）/ 30% 广域（arena 内均匀）；朝向 U[−π, π]；不固定左右。初速为零、控制器重置、`success_counter = 0`。

合法性：统一 0.005 m 非接触裕量，拒绝采样（每根 ≤2000 次），不做穿透投影、不放宽容差。额外要求**严格**初态判据（见 §3），因为它比冻结的 `legality.scene_clearances` 更强。

## 3. 严格初态判据（相对冻结检查器的收紧）

`legality.scene_clearances` 只用物体**顶点**到障碍盒的距离判断 `object_obstacle`。当障碍盒的角点落在物体多边形内部、而物体四个顶点都在盒外时，该检查通过，但物理引擎第一步就报穿透（实测 `object_wall` 穿透 0.22 m）。本轮采样器改用与 `geometric_violation` 同一套有符号 SAT/圆-多边形判据（`coverage_scale.sampler.strict_clearances`），要求每个 pair 的**有符号**间隙 ≥0.005 m。这是收紧，不是放宽；冻结的检查器与旧场景定义未被修改。

## 4. 采集配方（B1，各规模完全一致）

每个合法根执行：

1. 随机轨迹，最长 8 窗口：首窗口从 root 技能库均匀选，其后 50% 重选 / 50% 重复上一技能；
2. 一步精确引导轨迹，最长 8 窗口：每窗口从同一 root 库确定性抽 ≤16 个不同联合技能，用精确物理各执行一个窗口后按 `J` 取最优（并列取最小稳定 `candidate_id`），再在 live 世界真实执行；全不可行则记 `planner_no_feasible_plan` 并停止该轨迹；
3. 取引导轨迹**最后两个非终止窗口起点**为锚点（只有一个则取一个）；
4. 每锚点 4 个不同首动作（引导实际动作、双方 hold、2 个 root 库均匀随机，去重后用稳定随机顺序补齐）；每分支最长 2 窗口，第二窗口 50% 重复 / 50% 随机；严格 `restore(exact=True)`，含 `success_counter` 与引擎状态。

每根最多 `8 + 8 + 2×4×2 = 32` 个真实窗口。成功或真实失败即停止该轨迹，不从吸收态继续。精确引导的试算**不**并入监督集，只记录真实执行；试算物理步/前缀重放步/耗时计入采集成本。

去重：`transition_id = SHA256(scene_content_hash, state, next_state, action, termination, success)[:24]`，只删除完全相同内容，不按浮点近似合并。

## 5. split 与血缘（B2）

根 seed 空间互不相交：train 前缀 100 000 000、val 200 000 000、test 300 000 000、dev 400 000 000（各加 SHA256 前 6 位十六进制）。每根的随机轨迹、引导、锚点、分支全部留在同一 split；scene_id = `{family}_r{seed:09d}` 全局唯一。scene_id / split / 生成 seed 只作元数据，**不进入模型输入**。

val、test 各 128 个独立根：每 family 64 根，模式 32/16/16。train 按六个 family×模式格轮流加入**完整根**，模式长期 50/25/25；规模子集严格嵌套。

## 6. 规模档与训练预算（C1/C2）

目标窗口数 8k / 16k / 32k / 64k / 128k；每档取达到目标的**最短完整根前缀**，实际条数可略超。每档 2 宽度 × 3 种子 = 6 个 run，均从新初始化开始；同 seed 的样本顺序流跨宽度/规模一致。

- 最大更新数 `Umax = min(60000, max(6000, 60·ceil(N/128)))`，无早停；
- 评估点：`{0, 100}` ∪ 每 `max(250, ceil(Umax/20/250)·250)` 次，强制含最终更新；
- 训练期监控只在固定的 `train_monitor`（按根 hash 预选、≤4096 窗口）与新 val 上做；
- 完整训练集只在**两个选定点**上各解码一次；
- 主选点 `best_new_val_total`：新 val 四项总 loss 最小（含 update 0，不得排除早期、不得按 test/候选收益/非法率重选）；
- 固定预算末点 `final`：最后一次更新。

汇总权重：先在根内对窗口取均值，再在 family×模式格内对根取均值，最后按 family 权重（各 0.5）×模式权重（broad 0.5 / wall 0.25 / goal 0.25）汇总。

## 7. 停止规则（C3，工程规则，非统计显著性）

宽度在某档“有收益”需同时满足：至少 2/3 种子达到

1. 平均 P 相对下降 ≥5% 且非法率恶化 ≤2 个百分点；或
2. 非法率绝对下降 ≥3 个百分点且平均 P 恶化 ≤5%；

且没有任一 family 的 P 恶化 >10% 或非法率恶化 >5 个百分点（否则记混合趋势）。

8k 后至少再试 16k、32k；之后任一宽度有收益即可继续；连续两次规模增加两宽度均无收益则停止。若只有 `final` 显著改善而主选点无改善，允许再执行下一档一次验证该趋势（最多一次）。

## 8. 最终评估（D）

- D1 等数量窄覆盖对照：从旧六个固定训练初态出发，用**同一** B1 配方采到与广覆盖 16k 相同数量的窗口，条数误差 ≤32，按完整采集根保留；独立初态仍只有 6 个，必须报告。
- D2 冻结 run 清单后，对所有完成档位的主选点、final 及窄覆盖对照在新 test 上统一评估一次。旧 test 只作第一档/最终档主选点的历史回归。
- D3 固定候选：test 生成后按根 hash 每 family 选 6 个根（共 12），起点固定为合法根初态；先冻结 H={1,3}、K=64、candidate seeds={0,1}，精确真实收益只算一次并缓存；未筛选/执行筛选两套协议分开报告，误拒损失+排序损失=执行 regret；共同 `(start_id, candidate_seed)` 配对，无可行候选记 `null` 并计数。
