## 1. 实际运行多久、做到哪一档、规模多大、为什么停止

墙钟自 02:30 起算，采集 02:44–03:55，训练与评估 03:05–04:10，交付 04:10–04:35，合计约 **2.1 h**，
远未触及 8 h 硬上限。**五个档位全部完成**：8k / 16k / 32k / 64k / **128k**，去重后实际
8023 / 16017 / 32002 / 64007 / **128006** 个真实窗口，独立初态 289 / 570 / 1146 / 2291 / **4591**
个；新 val 3584 窗口 / 128 根，新 test 3497 窗口 / 128 根，等量窄覆盖对照 16019 窗口 / 626 个采集
回合（独立初态仍只有 6 个）。共 **36 次训练**（每档 2 宽度 × 3 种子，加窄覆盖 6 次），每次
6000–60000 更新、每档约 60 遍数据；72 次新 test 留出评估（每档 2 选择点 × 2 宽度 × 3 种子，加窄覆盖 12 次）、24 个逻辑模型做固定候选验证。

**停止原因是到达冻结的最高档 128k，不是规则要求停止**：8k→16k 有收益（512）、16k→32k 主选点
无收益而 `final` 有、32k→64k 两宽度有收益、64k→128k 有收益（256）。因此写「**预算/范围截断，
尚未判断饱和**」，不写「scale-up 已不再有效」。

## 2. 采样范围真正覆盖了什么

六格接受率（train 实测，每次提议的接受概率）：S0/broad 15.98%、S0/wall 1.31%、S0/goal 18.45%、
S1/broad 4.71%、S1/wall 2.99%、S1/goal 3.96%，**全部 ≥1%，无 BLOCKED 格**；val/test 同量级。
128k 档 128006 个窗口里 100% 的根出现过机器人-物体接触，**1604 / 4591** 个根至少出现一次真实
成功；窗口级运动：平移 75964、转动 72312、静止 49836（阈值 0.01 m / 0.02 rad），成功窗 2275。
**物理失败窗为 0**：修好初态合法性（E1）后，冻结配方在全部 139465 个采集窗口中（含 128k 档
使用的 128006 个）没有一次穿透/越界终止，`physical_failure` 在本数据上无正样本，其召回率不可估。新 val / test 各有 42 / 40 个成功根
（每族均 ≥5），成功类证据可用。

## 3. 扩数据是否改善同一验证/测试集；512 相对 256 的优势是否变化

**是，且单调。** 新 val 的 P（三刚体位置误差均值，米）：宽度 256 为 0.3791 → 0.3644 → 0.3591 →
0.3356 → **0.3181**，宽度 512 为 0.3796 → 0.3606 → 0.3552 → 0.3377 → **0.3150**；新 test 同向
（0.3775/0.3794 → 0.3201/0.3158）。物体位置误差 0.180 → 0.149 m，成功召回 0.089 → 0.208。
train 全量与 val 的总 loss 差距随规模收窄，128k 上 train 全量 P 0.3193 已与 val 0.3181 持平。
**512 相对 256 没有稳定优势**：所有档位两者的 P 相差不超过 1.1%，128k 上 512 的 P 略低但非法率更高
（71.1% vs 67.6%）、物体误差更大，优势没有随数据增加而扩大。**必须并列的负面事实**：模型物体
位置误差在所有档位都仍大于「预测不动」基线 0.1368 m（val）/ 0.1396 m（test）；非法率始终
68%–71%，不随数据下降。

## 4. 等量窄/广覆盖，以及非法率、误拒与候选真实收益

16019（窄）对 16017（广）窗口：广覆盖在新 val 上 P 低 4.4%，**六个（宽度, 种子）单元全部同向**；
新 test 上窄覆盖 P 0.3784/0.3799 对广覆盖 0.3594/0.3640。代价是广覆盖非法率反而高 1.9 个百分点。
固定候选（12 个新 test 根、H∈{1,3}、K=64、种子 {0,1}，真实收益只算一次并缓存）显示**扩数据没有
传递到候选选择**：未筛选选中真实收益 8k −0.282 → 128k −0.301，执行筛选后 −0.273 → −0.293，
执行 regret 1.346 → 1.491，拒绝率 0.710 → 0.780，方向均为变差；误拒/排序分解显示 128k 是
误拒变差（0.778 → 1.146）而集合内排序变好（0.568 → 0.345）。等量对照上窄覆盖略好（拒绝率
0.695 vs 0.725、误拒 0.597 vs 0.622、执行 regret 1.351 vs 1.400），但配对差只有 ±0.03 量级，
且 12 个起点中只有 4 个在 H=3、K=64 内存在任何真实成功候选（H=1 一个都没有），结论只能限制在
「差候选之间的排序」。**误拒损失 + 排序损失 = 执行 regret 的恒等式在每一行成立**（最大残差
1.8e-15）。等量窄/广覆盖对候选误拒的改善不成立：差异被 1–2 行主导，符号不一致。

## 5. 下一步只推荐一个动作

**保持本轮全部冻结条件不变，把 128k 上限提高到 256k 再跑一档六 run，用同一个新 val/test 决策。**
理由是 P 在 128k 仍在下降、C3 规则未触发停止。该档预设两个观察点：非法率是否首次下降、
候选选择是否首次改善。**当前是预算截断，「scale-up 已不再有效」不成立。**
