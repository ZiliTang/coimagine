## 2. A1 判稳分类审计

账户分开算（test，每臂 960 条）。**有效推动完成** V 850 / X 772；**局部判稳** V 647（0.674）/
X 592（0.617）；退出原因里 V 有 `contact_lost` 78、`patch_lost` 32、`settle_timeout` 190、
`settle_unobserved` 13，X 另有 `patch_support_lost` 12。判稳率的分母混着中止：若只看"判据决定
结局"的集合，判稳率是 **0.761 / 0.768**。

**退出瞬间真值低速**：V 313/313、X 368/368。**完整 0.30 s 保持窗真值低速**：同样 313/313、
368/368。也就是**每个未判稳退出，在被拒的那一刻和整个窗口里真值都是静止的**；反向的
"判稳了但真值仍在动"是 **0**。真值参考按 `v_obj + ω_obj × r` 含旋转项，退出时真值表面法向速度
p50=0、p90≤0.0093、max≤0.0105 m/s。

**中止后判稳**：记录的 `settled_after_abort` 结构性恒为 False（死代码），部署门槛下重算也是 0/0。

**估计量坐标系**：`world_points(patch, robot_pose)` 先把两帧都映射到**世界系**再匹配，机器人自身
运动已抵消。数值核对：物体静止 + 机器人移动 → 0.0000 m/s；物体真实平移 0.004 m/0.05 s →
0.0800 m/s。

**卡在哪**：真值确实静止时估计量中位读到 **0.029–0.030 m/s**，门槛 0.02——虚警地板骑在门槛上。
但**必须分变体**：六个无噪变体中位只有 0.0032–0.0036、判稳率 V 0.892–0.908 / X 0.808–0.842；
`noise`（σ=0.002 m）中位 **0.033–0.037**、判稳率 **0/120**；`delay`（100 ms）中位 ~0、
判稳率 **0/120**。
`noise` 的原因是可分辨性：相邻帧差商把 σ 放大成 `σ√2/0.05 ≈ 0.057 m/s`，而统计量取逐点速度
**绝对值的中位数**，抗错配但不降噪。`delay` 的原因是 `repeated_timestamp` 让估计量置 None，
把整段保持清零。诊断工具（窗口化估计量，**默认关闭、不采纳**）在 dev 的 noise+delay 子集上把
0/48 提到 V 44/48、X 39/48，证明瓶颈在测量而非门槛。

## 4. B 可观测终态转移（初步）

目标改为机器人终态**自己会看到**的局部几何（有符号距离 / 切向偏移 / 法向角，表达在起始坐标系），
**不含物体全局位姿**（有断言测试）；不可观测样本保留为离散结果。留一 root。臂 V（n=958，
中位绝对误差）：白名单特征得到有符号距离 **7.2 mm**、切向偏移 **12.2 mm**、法向角 **4.6°**；
再加物体真值初态（不可部署参考）后位置两项**几乎不再改善**（7.1 mm / 12.3 mm），法向角改善到
**2.7°**（R² 0.415→0.754）。残差按**隐藏**物体朝向四分层，Spearman ρ≈0.07（无强单调依赖），
但法向角的层间极差 3.5° 与其误差同量级——**位置类目标基本可观测可预测，姿态类仍残留隐藏依赖**。
臂 X 同向。这只是离线诊断预测器，未接规划器，也不构成"策略可以偏好可预测构型"的证据。
