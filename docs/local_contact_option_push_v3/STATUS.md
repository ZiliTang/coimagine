# STATUS — local_contact_option_push_v3

起因：人工观察认为局部参考尺度太保守（推动慢、易卡住）。本轮先诊断再调参，
dev 选型、test 单次验证。396 项测试通过。

## 诊断（只读日志，不重跑轨迹）

- 实际/命令速度只有 **0.49–0.53**；PUSH 期平均力 **1.5 N / 15 N**，**从不饱和**。
- 主因是 **Kv=20 对 ~20 N·s/m 物体阻力的稳态速度误差**（`v/v_ref=Kv/(Kv+c)`，模型与实测吻合）。
- 次因是 **APPROACH 上限 0.08 m/s**：中位 **1.70 s** 花在接近，占总时长 6.30 s 的 27%，是"卡住"的观感来源。
- `a_ref_max=0.5` 只贡献约 3%（2 s 推动里斜坡仅 0.3–0.5 s）。

## 两阶段调参（dev only）

| 阶段 | 设置 | 结果 |
|---|---|---|
| 激进 | Kv120 + a3.0 + 接近 0.30 | 位移 +49%，但力饱和 68%、有效推动 0.812、接触丢失 9 次 → 不可交付 |
| 退回 | **Kv25 + a3.0 + 接近 0.30** | 满足预先写好的四条安全规则，选定 |

选型规则（事先固定，在 72 个 dev root、24 个主要 root、4 变体上评估）：取同时满足
有效推动 ≥0.95、力饱和 =0、最大穿透 ≤ 基线 1.3 倍、判稳 ≥ 基线 的**最大** Kv。
Kv=25 通过，Kv=30/35/40 均在有效推动上失败（0.938）。

## 测试分片结果（同 root 同扰动）

每有效推动秒位移 0.113 → **0.134（+19%）**；位移中位 0.225 → **0.257**；
墙钟 6.30 → **4.15 s（−34%）**；判稳 0.651 → 0.632；假稳定仍为 0；
最大穿透 0.00132 → **0.00258（×2，负结果）**；G4 0.532 → **0.610**（仍未过 0.80）；
G5 位置 0.602 → 0.339（仍过），角度 0.122 → 0.324（更差）。

## 结论

推动确实变快、卡住主要来自接近段；但**剩余瓶颈是控制结构而不是尺度** ——
大 Kv 的代价来自阶段切换瞬间的力尖峰被 15 N 限幅，而不是稳态过载。
下一轮建议做一处结构性改动（参考软启动 / 受限积分 / 按可达速度重标定档位），不要再调尺度。
