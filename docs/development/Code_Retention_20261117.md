# 代码与测试保留规则

当前入口为随机房间CAP库、扁平语义监督、输入消融、检索对照及迁移实验。源码与数据分开管理。

- experiments/planar_tasks中运行库、版本化作者协议、实验复现入口及静态测台需要提交。部分旧入口仍为当前模块的依赖，不能仅按日期删除。
- tests中的协议、控制器、观测隔离、特征、监督、检索和接口回归测试保留。部分历史端到端检查可能依赖已清理的产物；不把缺少历史数据伪装成全套测试通过。
- 一次性宿主、日志、模型、数组、轨迹及迁移包留在outputs，不提交；Python缓存、虚拟环境及外部参考论文不提交。
- 当前平面源码约2.4 MB（274文件，208个Python模块）；全部测试源码约1.1 MB（180文件）。文件数与实验输出的几十万个文件不是同一量级。
- 正在运行的实验按源码快照校验。源码目录重构应在运行结束后另做依赖审计，当前提交保持其运行字节不变。

当前必要验收集中于GD/覆盖、随机房间、特征和监督、检索基线。历史源码的存在不代表继续该研究路线；当前目标只以研究计划v5和CURRENT为准。
