## 修复规则与范围

- 仅移动违规机器人的位姿：沿违规约束内法向迭代投影，直到全部非接触对满足裕量；步长与迭代在 `continuous2d/legality.py:minimal_robot_fix` 中固定，与成功率无关。
- S0_dev / S0_v4 只需 x 方向；S0_v2 的第二台机器人仅靠 x 会触犯物体裕量，因此同时做了最小 y 位移（记录在上表位移列）。
- 物体、目标、障碍、质量、摩擦、阻尼、时间步、力限幅、成功阈值、控制器与候选模板均未改动。
- 三个被修改场景标记 `scene_version=closeout_v2`；其余七个几何未变，保留 `v1` 与旧结果引用。
