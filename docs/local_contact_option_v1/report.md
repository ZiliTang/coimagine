## 1. 无物体全局位姿反馈的控制是否真实成立？局部传感仍假设了什么？

成立的是**信息隔离**这一条：控制器只拿到 `LocalContactObservation`（自身与队友运动学、
机器人坐标系下的局部片段/接触读数、静态地图、技能参数），没有任何物体位姿/速度/顶点/面编号
字段，把隐藏物体真值移动后同一观测下的控制力逐位不变（测试 1）。四臂对比的另一半 O/P 仍读
物体真值，本轮明确标为 oracle 基线。局部传感**仍然是理想化的**：（a）0.6 m/72 线理想测距，
无标定误差，只在噪声变体加 σ=2 mm；（b）单物体场景，目标本体身份已知；（c）机器人自身全局
位姿已知，法向/切向在共享世界系表达，但底盘 yaw 没有被执行器驱动，本报告不主张已完成 yaw 控制；
（d）局部稳定性只能观测**法向**分量，纯切向滑动不可观测——该情形被构造成测试并确认为
`settled_observed` 而真值未静止，说明**本地判稳不等于物体全局静止**。

## 2. 推动 2 s 与稳定终态是否实现？多少超时/假稳定？

| 臂 | 有效推动 2 s（可推动组基准） | 终止分布 | 本地判稳 | 真值假稳定 |
|---|---:|---|---:|---:|
| O 旧窗口 | 0%（无该语义，固定 2 s 总时长） | 960×wall_clock_end | — | — |
| P 旧公式＋新协议 | 92.5% | 869 settled / 89 contact_lost / 2 unobserved | 90.5% | **3.5%**（30/869） |
| F 新律＋等墙钟 | 0%（2 s 含接近，547/960 几乎不动） | 960×wall_clock_end | — | — |
| N 新律＋完整协议 | **92.5%** | **897 settled / 60 contact_lost / 3 face_switch** | 93.4% | **0.0%**（0/897） |

判稳交叉表（不可省略）：N 为 897 观测到且真静止、0 假稳定、63 未观测（已中止）、0 未观测却在动；
P 为 839 / 30 / 66 / 25。P 的假稳定全部来自「旧公式把物体推到还在滑行的状态并停手」；N 的 897 次
完成中，PUSH 期间接触占比**每一次都是 1.00**，间断接触的样本恰好就是 63 次 `contact_lost` 中止，
没有一次被算作成功。

## 3. 哪项改善来自控制律，哪项来自阶段协议，是否只是移动得更少？

- **阶段协议**（P 对 O）：把终态速度中位数从 0.159 降到 0.017 m/s，并首次给出终态。O 从不停机。
- **控制律**（N 对 P，同一协议）：假稳定 3.5% → **0%**；10 mm 位置扰动的终态 P90
  0.0126 → **0.0056 m**（−56%）；0.05 m/s 残余速度扰动 0.0710 → **0.0239 m**（−66%）；P90 配对
  区间见 tables。这一层是控制律的贡献，且不是靠「判稳更保守」换来的（判稳率反而更高）。
- **但确实移动得更少，这是本轮最重要的负结果**：N/P 位移中位数 0.182/0.416 = **0.44**，未过
  0.80 门槛；按命令速度分层为 0.08/0.16/0.26 m/s → 0.23/0.43/0.66，即使命令速度与旧公式的巡航
  0.26 m/s 相同也只有 0.66。每有效接触秒的位移 N 0.099 m/s 对 P 0.244 m/s（2.5 倍差距）。
- **F 说明协议不可或缺**：同样的新控制律放进 2 s 总墙钟（含接近）后，547/960 次几乎不动
  （中央/同侧中位位移 0.011 m，N 为 0.222 m）。新律本身推力不足以在旧窗口形状里产生位移。
- **低维近似**：只对完成 PUSH 的轨迹拟合常体坐标 twist。N 882 条、拟合位置残差中位 0.0069 m、
  后半段外推 0.0231 m、直线占比 0.757；P 771 条、0.0050 / 0.0273 m、直线占比 0.462。
  即新律没有带来更丰富的可拟合结构，反而更直、更慢。这些是几何诊断，不是世界模型收益。

## 4. 是否值得以新 option 收集下一轮数据？

**支持**：N 给出 92.5% 有效 2 s 推动、93.4% 本地判稳、**0 假稳定**、扰动终态 P90 比 oracle 基线
低一半以上，并且 12 个 root×3 技能的接续里，凡判稳的末端 100% 都能作为下一次技能的可用初态
（20/21 次转移；两臂都完成 10/12 条链）。这正是「rest-to-rest option」需要的前提。

**反证**：位移效率未过门槛（0.44，匹配速度也只有 0.66），6.3% 以 `contact_lost` 中止，
twist 拟合没有更好，切向运动不可观测意味着终态静止声明在小扰动下仍可能被真值推翻（本轮 0 次，
但这是结构性风险而非已证安全）。

**结论（一个动作）**：值得保留并继续使用**分阶段协议**；但**暂不**为大规模 option 数据启动新一轮
采集——先把参考速度/力的量级与位移效率对齐（用它把 G4 拉回 ≥0.80），再采一小规模 option 数据。
不支持把本轮写成「新控制律已成功后开始采数据」。
