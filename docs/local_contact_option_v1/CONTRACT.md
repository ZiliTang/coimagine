# local_contact_option_v1 冻结契约

任务书：`docs/tasks/20261013_1256_CoImagine_局部接触控制与Option终态验证任务书.md`
实现审计：[A_implementation_audit.md](A_implementation_audit.md)（A.1 逐条核对，未发现与任务描述不一致之处，旧实现未改动）

## 1. 控制律

推动阶段对机器人 i：

```
v_raw_i = speed_i * (cos(alpha_i) * n_i + sin(alpha_i) * t_i)
||v_ref(k) - v_ref(k-1)|| <= a_ref_max * dt          (a_ref_max = 0.5 m/s^2)
F_cmd_i = clip_norm(Kv * (v_ref_i - v_robot_i), F_max)   (Kv = 20 N s/m, F_max = 15 N)
```

`n` 为滤波后局部法向（从机器人指向表面），`t = Rot90(n)`，均在共享世界系；`dt = 0.05 s`
（20 Hz）。法向用单位向量一阶滤波，时间常数 0.10 s；连续两帧夹角 > 30° 判为片段切换/角点，
该次技能中止。无位置积分、不直接覆盖速度、无物体速度前馈。alpha 正负号按 `t` 定义。

**Kv 选择（开发阶段，事先冻结规则）**：候选 {20, 40, 80}，取**满足全部验收的最小增益**，
优先级为接触保持 → 穿透 → 振荡。验收：可推动组有效 2 s 比例 ≥0.90；无执行超过 0.05 m 穿透；
超速（>1.5× 命令速度）周期占比 >20% 的执行不超过 10%。实测三者 retention 均为 0.9375、
无穿透、无振荡 → **Kv = 20 冻结**，测试集不参与调参。

## 2. 信息白名单：`LocalContactObservation`

允许：自身与队友的全局位置/朝向/线速度/角速度、队友阶段与就绪/接触标志、技能参数；机器人
坐标系下的局部片段（采样点、拟合线段、距离、法向/切向、可见性置信度、时间戳）；本机器人是否
触碰目标、机器人坐标系下的接触点、接触力/冲量读数；静态地图、己方半径、力上限。

**禁止**：物体质心位置、角度、线速度、角速度、顶点集合、真实面编号、真实物体局部接触坐标，
以及 env/BodyState/后端对象。`tests/test_local_contact_option.py` 检查字段集合并验证「固定观测
下改写隐藏物体真值，输出力逐位不变」。

传感层可用真值生成读数（这是传感器仿真），但控制器与评估器严格分层。局部几何由以机器人为中心、
**0.6 m / 72 条均匀射线**生成，静态障碍、边界与队友都参与遮挡；目标表面至少 **3 点**才拟合法向；
连续片段只按角向相邻与距离连续性分组，**不用真实 face_id 关联**。同一根的所有臂共享同一快照，
每臂 `restore_exact`，互不污染。

## 3. 阶段与退出

| 阶段 | 进入条件 | 参考速度 | 退出 |
|---|---|---|---|
| APPROACH | 技能开始 | 沿 n，`min(0.08, max(0.02, 2·gap))`；接触后 0.02 m/s | 接触→READY；5 s 超时→`approach_timeout`；>0.15 s 无可用片段→`surface_unobserved` |
| READY | 双/单机器人均连续接触 0.10 s | 法向 0.01 m/s 预接触 | 双 ready 保持 0.10 s→PUSH（单机器人只等自身） |
| PUSH | 握手完成 | 控制律 | 有效接触累计 2.0 s→BRAKE；墙钟 3 s→`push_wall_timeout`；连续失联 >0.15 s→`contact_lost`；片段丢失 >0.15 s→`patch_lost`；法向跳变 >30°→`face_switch`（双方进入 BRAKE，队友记 `teammate_abort`） |
| BRAKE | PUSH 结束或中止 | 以 0.5 m/s² 降到 0，随后 `F = -Kv·v` | 参考速度归零→SETTLE |
| SETTLE | BRAKE 完成 | `F = -Kv·v` | 机器人 `|v|<0.03`、`|ω|<0.08`，且**局部表面法向速度估计** <0.02 m/s，保持 0.30 s→`settled_observed`；BRAKE+SETTLE >4 s→`settle_timeout`/`settle_unobserved` |

单推只在自身接触期累计；双推只在**双方都接触**的控制区间累计，升速过程计入。短暂掉接触暂停
有效计时但不禁停物理仿真。中止后的终止标签**保留中止原因**，此后若又判稳只记
`settled_after_abort` 标志，不覆盖原因。任务目标达成只是评估标签，控制器不据此提前终止。

局部表面速度：把连续两次扫描点用自身已知位姿映射到世界系后最近邻关联（容差 0.05 m，至少 3 点），
取沿当前**法向**的平均位移。单平面切向运动不可观测，因此本地判稳与真值判稳分开报告。

## 5. 实验规模与变体

24 开发 root（每类 4）+ 120 测试 root（每类 20），六类：单机器人中央正推、单机器人偏心推、
双机器人同侧、双机器人旋转协作、不兼容输入、受限（墙/角/通道）。alpha ∈ {−15°, 0°, +15°}、
speed ∈ {0.08, 0.16, 0.26}、初始表面间隙 ∈ {0.02, 0.06, 0.12, 0.18} m，按固定种子分层，不做全排列；
每类都含不等接近距离的双机器人配置。

每个 root 8 个变体：基准；位置扰动 2 mm / 10 mm；残余速度 0.02 / 0.05 m/s；测距噪声 σ=2 mm；
100 ms 观测与共享消息延迟；物体质量 ×1.10 且摩擦 ×0.90。位置扰动的合法化拒绝次数记入 manifest，
不按控制结果重采。物理参数扰动只用于压力测试，名义默认值未改。

## 6. 门槛（测试前冻结）

- G1 信息隔离/力限幅/无瞬移/计时/快照隔离：由测试覆盖。
- G2 名义自由空间可推动组 N 有效推动 2 s 比例 ≥0.90（受阻/不兼容组不进入分母）。
- G3 N 宣称本地稳定的样本中真值假稳定率 ≤5%，同时报告判稳覆盖率。
- G4 可推动组 N 有效位移中位数 ≥ P 的 80%（P 几乎不动的 root 单列）。
- G5 N 对 P 的 10 mm 位置扰动终态 P90 至少下降 20%。

阈值未根据测试结果修改。
