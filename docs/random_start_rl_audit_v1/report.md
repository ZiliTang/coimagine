## 1. 已复现并修复

实现：`experiments/random_start_reposition_v1/rl.py`。
回归测试：`tests/test_random_start_rl.py`。

| 问题 | 修复前证据 | 最小修复 |
|---|---|---|
| critic 状态时刻不对 | rollout 读取决策前 `V(h)`；update 在消费当前技能内部观测后才算 `V`，却拟合决策前 target | actor 与 critic 都读取同一决策前隐藏状态 |
| TBPTT 只在文字中存在 | 后一决策的损失可反传至前一决策输入，梯度测试失败 | 每次读完决策头后 detach，再消费该技能内部帧；下一决策仍可训练这些中间帧 |
| 局部 RNG 未生效 | `sample(generator=...)` 内调用不接受该 generator 的 `Categorical.sample()`；消耗全局 RNG，同局部 seed 的序列不复现 | 用 `torch.multinomial(..., generator=generator)` 采样，logp 仍由同一 Categorical 计算 |

修复前新增测试首轮结果：**4 failed / 1 passed**，分别覆盖上述三问题（RNG 两个测试）及正确的半马尔可夫 target。
修复不改变 GRU 数值状态的连续性；只改变梯度跨越范围。跨技能记忆没有清零。

RNG 修复意味着旧实验所称的逐 episode 行为 seed 实际上未被局部使用。
旧实验仍可能在固定全局执行顺序下复现，但不能将该结果解释为严格隔离的逐 episode 行为种子对照。

## 2. 真实轨迹固定数据对照

入口：`experiments/random_start_reposition_v1/run_rl_audit.py`。
正式结果：`outputs/random_start_rl_audit_v1/final/audit.json`，含源文件 SHA256、版本、种子、逐 epoch 曲线。

- 从已有诊断子集取固定前两个实例 `L0_train_0005/0010`，未按本次结果选择。
- 初始化 seed=0；rollout 局部 seed=100/101；同一初始化网络，原环境全部预算。
- 两条轨迹均预算失败，各 30 个决策，分别 470/464 控制周期，共 60 个决策。
- 对完全相同的观测、标签和初值，各做 20 个 critic-only 更新，AdamW 3e-4、梯度裁剪 5。
- 新路径：正确决策前价值 + 一技能梯度截断。旧路径：旧价值时刻 + 原无截断图。
- 两者均在**部署实际使用的决策前状态**上评价。无 actor/熵损失，无训练轨迹替换。

| 指标 | 初始化 | 修复路径，20 次后 | 旧路径，20 次后 |
|---|---:|---:|---:|
| MSE | 0.883017 | 0.048948 | 0.046012 |
| MAE | 0.836242 | 0.209162 | 0.200200 |
| 解释方差 | -0.093775 | 0.888772 | 0.876159 |

未更新参数时，修复路径与 rollout 的价值重算最大差为 **0**；旧路径为 **0.061811**，
平均差仅 **0.003013**。这证实时间索引错误，同时提示其在本次样本上的数值影响不大。
同两条真实轨迹经过正常 PPO `update()`、学习率为零时，ratio mean/max 均为 1，参数不变。

**不能外推的部分：** 这只是同数据拟合，不是验证集预测、在线 PPO 稳定性或成功率提升。
数据仅有两条失败轨迹，且新旧差异同时包含价值时刻与截断，不是两因素独立因果消融。
旧路径甚至取得稍低 MSE，故不支持“修复已带来明确拟合优势”的说法。

## 3. 回报诊断：比单纯折扣衰减更重要的区别

检查现有累计前缀奖励与 `flatten()`：

`target_i = sum(reward_global_i:) / discount_prefix_i`

与半马尔可夫 Monte-Carlo 回报一致，手算测试通过。未发现这里重复施加折扣。

但完整终止轨迹采用 `Phi_terminal=0`，势函数塑形项望远镜相消：

`sum_t gamma^t * (gamma * Phi_(t+1) - Phi_t) = -Phi_0`。

因此，在初态、总时长、终止事件相同的两条失败轨迹中，无论中途接近目标还是远离目标，
**从初始决策计算的完整 MC 回报相同**。新增测试用不同中间距离、相同分段时间直接调用冻结奖励函数，验证相等至 1e-12。

这不是奖励实现 bug；势函数塑形本来就不应改变原任务的策略排序。
但当前使用完整 MC 而非带 bootstrap 的短程 TD 时，不能把它当成保留在整轨迹 target 中的稠密进度奖励。
成功稀少时，实际的初始决策回报区分主要依赖成功事件与持续时间，而不是失败前走了多近。

`gamma=0.997/周期` 的半衰期约 11.5 s，1700 周期末尾事件系数约 0.006。
但本次两条轨迹仅 464/470 周期，不能将 1700 周期作为所有 rollout 的代表。
晚期决策仍能获得终局信号；失败轨迹平均优势接近零也不是梯度无信息的充分证据。
**折扣是待检验因素，不是已隔离的失败主因。本轮未改变它。**

## 4. 仍待处理的输入与验收缺口

- `env.py:observation_vector()` 的 324 维向量不含已执行动作/参数或技能阶段。
  这些量存在于外部日志，却未拼入 actor/critic 的 GRU 输入。合法观测不等于充分历史。
  改动需版本化输入 schema、检查点和采集加载器；本轮没有静默破坏兼容性。
- 当前 bandit 原检查没有调用完整 PPO `update()`。本轮另加真实 `update()` 的可手算方向/排序测试。
  该测试学习率 0.03，只验证更新方向，不验证真实任务的 3e-4 是否足够。
- 主训练 `pass_signal` 仅检查最终成功率，未落实任务书要求的连续三个评价点；
  本轮未运行主训练，因此没有错误授予通过门槛，但以后重跑前应修正。
- 上轮只有 5 个诊断实例，未达到任务书 8–16 个要求。这不是已经证明的失败原因。
- 相邻 S5 采集代码还存在每边界重置策略 hidden、混合行为概率/权重哈希等待审计问题。
  它们不在上轮 S4 的训练路径中，不能拿来解释 S4 失败；本轮未扩展修复 S5。
