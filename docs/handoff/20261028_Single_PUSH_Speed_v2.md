# 单机器人 PUSH 提速与 approach 限速诊断 v2

仅沿用上一轮单例：单机器人向北 PUSH 0.3 m，初始切向偏置0.18 m，同伴远处等待。分两步测15组配置，没有扩展随机场景或启动RL。最终原型回放：[review/index.html](../../outputs/option_testbench_v1/single_push_speed_v2/review/index.html)。

## 当前建议

保持物理参数，采用名义 PUSH 上限 **0.32 m/s**、approach 切向/法向上限 **0.30 m/s**，配合切向纠偏和基于自身剩余法向行程的末端渐减速。该场景总时间 **6.25→4.35 s（减少30.4%）**；物体侧偏 **1.37→0.70 cm**，转角绝对值 **1.90→1.34°**；机器人法向行程 **0.3119→0.3009 m**。物体前移约0.3129 m，机器人行程与物体位移仍是不同量。

参数/原型包装器保存在 `experiments/option_testbench/single_push_speed_v2_eval.py` 和 `single_push_speed_v2_refine.py`；候选标识为 `prepare_matched_0.30`。生产控制器、v11默认配置和旧RL接口没有修改。这里给出可复现候选，不将单例通过视为协同可靠性。

## 推动速度不是越大越快

下表前5行保持同一准备参数；非基线组同步增强切向纠偏、采用末端渐减速，不能将差异全部归因于推动速度。

| 方案 | 总时间 s | approach s | 物体侧偏 cm | 转角 ° |
|---|---:|---:|---:|---:|
| 当前基线 PUSH 0.12 | 6.25 | 1.75 | −1.37 | −1.90 |
| PUSH上限0.24 + 协调纠偏/减速 | 5.10 | 1.75 | +0.05 | −0.40 |
| PUSH上限0.32 + 协调纠偏/减速 | 4.70 | 1.75 | −0.10 | −0.50 |
| PUSH上限0.40 + 协调纠偏/减速 | 4.85 | 1.75 | −0.40 | −0.77 |
| PUSH上限0.50 + 协调纠偏/减速 | 4.85 | 1.75 | −0.52 | −0.91 |
| 推荐：0.32 + 准备参数重配 | **4.35** | **1.75** | **−0.70** | **−1.34** |
| 更激进间隙伺服 | 4.10 | 1.55 | +1.93 | −0.21 |

推荐组配置：接触切向增益4.8、切向上限约0.213 m/s、接触点变化上限0.16 m/s、切向速度阻尼0.7；准备位置增益4.5、速度阻尼1.2、制动包络参数0.7。末端法向参考上限为 `max(0.025, sqrt(2*0.25*remaining_own_normal_travel))`，仍经过原0.5 m/s²参考加速度限制和原力反馈。总参考速度额外限制不超过0.5 m/s。

0.5上限组未出现严重侧偏，但也没有更快。这个0.3 m短动作在加速度/制动包络下，参考速度峰值约0.37 m/s，机器人实际峰值约0.24 m/s（统计包含准备阶段），**并未测试持续实际0.5 m/s接触推动**。0.32是当前单例的效率选择，不是理论或已证实的稳定性极限。

更激进间隙伺服虽在预先规定的2 cm侧偏门槛内，但已接近边界，因此保留为对照，未选为推荐。取消近面低速切换的3组试验分别出现侧偏2.32 cm或转角约2.99°，未通过门槛；不能把解除clip直接当作正确优化。

## approach 增益为什么会无效

代码链路在 `effect_push.py::_approach_lateral`、`EffectPushSkill.step` 和 `local_contact_option/control.py::ReferenceVelocity`（由skills引用）中：

1. 位置误差乘增益后减去速度阻尼。
2. 按准备切向速度上限截断；**物面间隙小于4 cm时切换到接触切向低速上限**。
3. 还受 `sqrt(2 * approach_brake_accel * |error|)` 的剩余距离制动包络限制。
4. 切向和法向合成后受**总参考加速度0.5 m/s²**限制；实际速度还要通过有力上限的反馈驱动和环境阻力。
5. 进入PUSH前还要求切向误差≤2.5 cm、切向速度≤4 cm/s、物面间隙≤3.5 cm以及朝向对齐。法向使用距准备线3 cm的间隙伺服，未到速度上限时增加上限无效。

本例初始切向误差约19.3 cm，目标在拟合物面中心附近，不是目标太近以至于没有可移动距离。基线35个approach控制周期中有20个周期参考速度尚未达到原始命令；切向控制函数36次调用中有15次达到其限幅（含转阶段调用）。近面低速限制只发生在最后4次调用，不是整个准备阶段唯一瓶颈。

只提高准备速度上限/位置增益的对照，approach反而1.75→1.85 s；前一轮激进配置曾达到2.45 s。增益可使系统更早饱和或更晚停稳，不能越过上述限制。放宽近面限速、同时改变间隙伺服可到1.60 s，但所测配置质量退化；推荐组合的approach仍1.75 s，主要收益在后续接触建立和推动。另一组1.55 s的代价是侧偏接近门槛。

## 是否调整物体质量和摩擦

当前是无重力俯视近似：地面阻力为对动态物体施加的黏性力 `−linear_damping*v`（系数8），`friction=0.6`用于碰撞接触摩擦；不是库仑地面摩擦 `μmg`。因此“质量减半、摩擦系数翻倍保持地面摩擦力”不对应当前实现，额外提高friction还会改变机器人—物体切向接触作用。

单独测了物体质量3→1.5 kg，其他参数不变：同一PUSH0.40控制器4.85→4.35 s，前向位移更接近0.3 m。不过制动开始后物体位移约2.00→2.77 mm，该例不能单凭总时间证明滑移减少。自由滑动物体的线性衰减时间常数由 `m/8` 得0.375→0.1875 s只是模型推导，不能代替接触阶段测量。

原3 kg物体通过控制优化已经达到4.35 s，因此**本轮保留质量、摩擦、阻尼原值**。后续如需改物理，应作为有独立版本和标定依据的环境变更。

## 验证、局限与复现

预先记录的单例门槛：正常完成、机器人法向行程0.30–0.31 m、物体侧偏≤2 cm、转角≤2°、穿透≤2 mm、无安全触发。基线因0.3119 m行程不通过这个更严格的门槛，也完整保留；不能宣称基线失败或把门槛通过当作全任务成功。

15组均达到原完成条件，10组通过上述局部门槛（含减半质量的独立对照）。推荐组峰值穿透约1.35 mm，基线约0.46 mm；尽管在2 mm门槛内，接触动态不是完全相同。两轮结果重复运行后物理结果一致；原始位姿独立重算行程通过。没有运行全仓库测试或协同回归。
