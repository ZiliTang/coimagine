# Run12 阻塞诊断与 Run13 执行逻辑修复

2026-10-29。目标是区分本地物理/感知条件不满足与执行器状态问题，不能将“长时间没有运动”全部视为 bug，也不能靠无条件重启隐藏失败。

本轮在 `experiments/option_rl_v13/` 保存独立版本；run12 冻结源码指纹复核一致。46 项动作、822 维输入、5 Hz 决策、20 Hz 控制、120 Hz 物理、质量/摩擦/力限、任务 reward 均保持原设定。没有开始新的长训练。

## 有证据的分类

| 类别 | 观察证据 | 处理 |
|---|---|---|
| 当前方向确实不满足安全通路要求 | validation root8 的扫掠静态回波间隙约 2.08 cm，小于原 4 cm 裕度；相同路线重新启动仍停止 | 保留 `blocked_static_route`；不能推断整个场景全局无解 |
| 局部接触恢复没有在预算内完成 | root19 原命令出现 `joint_recovery_timeout`；重试或让一方换位未能让另一方恢复，且可能再出现 `patch_lost` | 保留失败；尚未证明物理上绝对不可恢复 |
| 同伴失败错误传播为本机永久失败 | root1/root18：本机尚未失败、进度守卫尚可，下一周期被写成 `peer_mode_failed`；之后另一方换位仍不能继续 | 改为健康方制动等待，自身真实失败不清除 |
| 新绕行意图被旧失败状态遮蔽 | root8：CCW 失败后改为 CW，旧代码只改动作字段，控制器仍 `done`；先 BRAKE 再 CW 可实际退回约 0.77 m | 显式改变方向允许制动后的全新检查，不保证通过 |
| 失效控制器的过时参考值污染下一次切换 | root1_escape：原版单周期参考速度跳变约 0.1012 m/s，超过 0.025 m/s 斜坡限值 | 从当前制动器继承参考值，修复后约 0.025 m/s |
| 单帧拟合失效被立即锁存 | root18/root23 早期物体未动、机器人仅移动毫米级；有效拟合随射线落点变化，某帧无有效关联即永久 `effect_face_lost` | 已跟踪面丢失时制动，等待至多 0.25 s；持续无关联仍失败 |

其中“通路阻塞”是当前局部路径与既定安全裕度的判断，`translation_stalled` 等是局部进度判据。它们均不能直接等同于“任何动作序列都无法完成任务”。另一方面，几何 mask 允许某方向也不是物理可执行性证明。

早期逐帧拟合数据保存在 `outputs/option_rl_v12/recovery_diagnosis_20261029/early_face_loss.json`。root18 的原轨迹中 t=0.15 s 没有有效面，t=0.20 s 又出现有效拟合。修复后的制动会改变后续扫描轨迹，仍可能持续不可观测并最终失败；不能据原轨迹断言修复轨迹一定在下一帧恢复。

## 新版本的恢复契约

本机失败后，原意图重复或仅改变速度仍锁存。健康控制器的同族参数更新仍保持端点跟踪和参考速度；本机已失败且策略显式改变 PUSH 方向或 REPOSITION 方向时，新意图通过真实制动进入新控制器，再运行原感知、障碍、接触和进度检查。没有“忽略失败继续推”的路径，也没有把物理可行性标签传给策略。

健康 PUSH 因同伴失败进入 `peer_wait`。自身安全扫描仍检查；等待不记成一次又一次独立本机失败，也不累计主动尝试进度的超时。对方换为 REPOSITION/其他模式后，健康方可以继续本机控制；对方正在切换至新的 PUSH 时则等待提交与接触握手。

配对身份改变时，旧的 release、ready、contact_ready、joint_active 与恢复计时不能直接继承。FOLLOW 等待对方实际成为 PUSH，避免把对方旧 REPOSITION 的失败或切换制动阶段误当成新 PUSH 失败。这些交接回归由针对性状态测试覆盖。

感知等待只针对已有面关联的短时丢失，期限为 `min(endpoint_max_age, 0.25 s)`，不沿用旧面继续推进；双 PUSH 同时制动。超过期限仍记真实感知失败。暂停后的表面/角速率估计采用实际观测间隔，避免把数个控制周期的变化除以一个 dt。

保持偏置在本机明确失败时关闭，减少对失效模式的额外偏好。其余状态下仍为原来的可学习参数，初始 2.5；本轮没有调整熵系数、任务 reward 或 advantage 算法。

## 短轨迹对照

最终测台：[round_004/index.html](../../outputs/option_testbench_v1/continuous_recovery_v2/round_004/index.html)。原版/修复版切换、机器人 0/1 切换、单步与滑条可查看失败前后。选取 root1、8、18、19 的原始 890 轮验证命令前缀；原版前缀退出原因和时间全部复现。每个场景从同一初态完整重放，不使用未实现的控制器 branch 快照。

| 算例/后续命令 | 原版 | 修复版 |
|---|---|---|
| root1：一方真实停滞后维持原命令 | 另一方也永久 `peer_mode_failed` | 真实失败方仍失败，健康方制动等待；两版物理位置一致 |
| root1：等待后让失败方 RP_CCW | 健康方被锁死；物体末端 Δxy 约 (0.403,0.143) m | 健康方恢复运动，随后自身也出现 `translation_stalled`；末端 Δxy 约 (0.520,0.170) m，未宣称任务成功 |
| root8：失败 RP_CCW 改为 RP_CW | 绕行机器人仅移动约 1.2 mm，仍旧失败 | 从失败边界起移动约 0.775 m，两个控制器均未失败 |
| root18：失败侧换为 RP_CCW | 另一方仍锁死，物体不动 | 另一方继续推动，物体 Δxy 约 (−0.014,0.137) m；仅证明局部恢复 |
| root19：维持原命令 | 两方恢复超时，保持失败 | 结果保持；没有无条件解除真实失败 |
| 窄静态通路负例 | `blocked_static_route`，物体不动 | 结果保持，穿透为 0 |
| 健康单推/同向双推 | 正常推进与制动 | 两个参考的逐周期物理状态和力与旧版完全一致 |

共 11 案例 × 2 版本 = 22 分支。修复版最大穿透约 0.408 mm，最大单周期参考变化 0.025 m/s，力限未超出。所有分支由原始物理日志独立重算 reward，最大误差约 5.6e−17。此测台不构成所有组合、障碍布局或感知条件的覆盖证明。

## 固定旧权重反事实：没有任务收益证明

使用 run12 最终 895 轮权重与原归一化统计，选取 validation roots 0、1、8、18、19、23、34、62，比较四个版本，每个完整运行 90 s 任务预算。root34 是 890 轮时曾成功的场景，在最终权重上已不再成功。

| 变体 | 成功 | 本机失败记录占比均值 | 失败或等待记录占比均值 | progress 均值 |
|---|---:|---:|---:|---:|
| 原执行器、原偏置 | 0/8 | 86.0% | 86.0% | −0.259 |
| 仅生命周期修复 | 0/8 | 40.1% | 68.2% | −0.346 |
| 仅关闭失败状态的保持偏置 | 0/8 | 76.4% | 76.4% | −0.305 |

四个版本物理异常均为 0。失败记录减少部分来自健康方被正确归为等待，不能仅用该数字宣称恢复改善。旧策略仍不能稳定选择解除约束的动作，progress 没有改善。这是挑选失败场景的局部诊断，不是完整验证、测试集或重训练结果。

## 探索持续性诊断

在四个根的 64 个合法重放状态上固定最终策略网络，仅改变保持偏置，计算熵项对该参数的梯度。初值 2.5 时，`dH/dbias≈−0.4024`，原系数下 `d(−0.02H)/dbias≈+0.00805`；梯度下降会推动保持偏置减小。在最终偏置 0.277 时也观察到同方向作用。

这证实熵项存在削弱保持倾向的梯度，但没有测量整段训练的 actor 梯度，不能将全部偏置漂移归因于熵。它是探索设置与长程信用的调参问题，尚未发现 PPO 联合概率计算错误。下一次学习对照应在冻结执行修复后，单独改变熵或保持偏置设置；不应同时改任务 reward 来混合解释。

[熵项梯度数据](../../outputs/option_rl_v13/entropy_diagnosis_001.json)。完整回报 Monte Carlo advantage 仍保持；GAE、历史编码器与世界模型本轮未加入。
