# 单机器人 PUSH 速度与制动小对照

仅测单机器人向北推动 0.3 m，初始切向偏置 0.18 m，同伴在远处等待；没有扩展场景集或启动 RL。

本例不支持“推动速度增加必然大幅降低精度”：将速度从 0.12 提至 0.24 m/s，总耗时从 6.25 降到 4.70 s。同步增加切向速度上限、纠偏增益和接触点更新速率后，物体侧偏约 0.3 mm，转角约 −0.47°，均优于本例基线。但机器人法向行程从 0.312 增至 0.338 m，说明主要的新问题是末端过冲，而不只是切向控制不足。

在实验包装器中加入基于自身剩余法向行程的渐减速后，5.10 s 完成，机器人行程 0.3007 m，物体侧偏约 0.5 mm、转角约 −0.40°；相比基线节省约18.4%时间。进一步调整准备阶段速度阻尼可降到 4.55 s，但侧偏增至1.78 cm、峰值穿透增至1.29 mm，不能称为质量完全无损。

单纯大幅增加准备位置增益反而使 approach 从1.75 s拉长至2.45 s；速度阻尼调整后恢复1.75 s。当前 approach 仍有近面限速和速度收敛门槛，不能把位置增益与制动能力等同。最后制动时间从双倍速度时的0.65 s降到渐减速组的0.15–0.20 s，但尚未证明 approach 本身缩短。

物理/控制/扫描频率、力和加速度限制、完成阈值保持不变。渐减速只使用自身观测累计行程，不用物体真值；生产控制器和 v11 默认配置均未修改。所有6组完成，独立位姿行程审计通过；没有运行大范围回归，也不推断协同场景的稳定性。
