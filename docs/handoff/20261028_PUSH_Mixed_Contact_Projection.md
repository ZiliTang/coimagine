# PUSH 混合组合：避开同伴占据的接触区域

2026-10-28。针对用户指出的 `push_follow` 卡住问题，完成一个小步改进及对照。没有改奖励、请求尺度、超时和物理模型，没有启动 RL。

## 原因与改动

用户观察正确。原控制中 PUSH 一直处于 approach、物体不动：接触点分配只在 cooperative 双 PUSH 路径启用。PUSH+FOLLOW 没有分配保留区，PUSH 朝原偏好接触点移动，同伴排斥却阻止它接近，最终停在约 6 cm 物体间隙且因切向误差无法进入正常接触。

新增显式配置 `mixed_contact_allocation=True`（需已有 `same_face_allocation=True`）：

1. 根据本侧雷达识别的同伴位置，在当前拟合面上排除同伴占据的区域；不读取其私有扫描、控制目标或物体真值。
2. 保留初始切向相对顺序，不穿过同伴争抢另一侧。在自身这一侧的可见剩余区间里，将原偏好接触点投影到最近的位置。原方向/纠偏控制仍提供偏好点。
3. 单 PUSH 对独立同伴只排除其占据区，不强制平分接触面；原双 PUSH 的对称分配保持不变。端点/遮挡可见边界继续约束目标，不补造被挡住的面。
4. 可见剩余区间为空时，明确退出 `same_face_lane_unavailable`；同伴证据短时丢失只使用原 0.25 s 有界预测，超时退出。确认同伴离开该面后释放保留区。
5. 稳定分配后沿用已有同面工作间距：目标切向中心分离 0.41 m（半径之和 0.36 + 4 cm 间隙 + 1 cm padding），原 12 cm 排斥裕度可按既有规则降到 4 cm；首帧、陈旧观测和快速接近保留更大缓冲。**2 cm 安全退出、静态避障、力/参考加速度上限均不放宽。**

这是局部目标可行性处理，不是全局路径可达性证明。旋转 PUSH 没有在本轮扩展。

## 实际结果

[打开新测台](../../outputs/option_testbench_v1/mixed_contact_projection_v1/round_001/index.html)（默认 `push_follow`，可切换原接触点/可行区域投影、机器人 0/1）。粉色点是实际目标，空心点是原偏好点。

![修复后相同 7.5 s 时刻的推动](../../outputs/option_testbench_v1/mixed_contact_projection_v1/round_001/projected.png)

8 场景 × 2 配置 = **16 分支，全部完成记录**。两组均使用前轮同伴避让与 2 cm FOLLOW，仅改变混合接触点分配；每分支墙钟 8 s、批次 60 s 上限，实际 23.29 s。

| 场景 | 原控制 | 新控制 |
|---|---|---|
| PUSH_N[0.3]+FOLLOW[6s] | 14 s 超时，未接触，物体位移 0 | 5.00 s 首次接触，8.95 s 结束；PUSH 法向行程 0.312 m；物体向上 0.326 m，侧偏 0.0116 m，转角约 1.11° |
| 初始 PUSH 位置 x±1 cm | 均无接触、超时 | 两侧扰动均完成 0.3 m 请求；向上位移约 0.326 m |
| 交换机器人身份 | PUSH 仍超时 | 相同物理轨迹，PUSH 完成 |
| PUSH+WAIT | 无接触、超时 | 完成，物体向上约 0.300 m；侧偏约 0.113 m、转角约 −11.77° |
| 同伴远离该接触面 | 正常完成 | 逐周期物理轨迹/施力完全相同 |
| 窄面已占据 | 后续安全退出 | 明确 lane_unavailable，不通过放宽间距硬挤 |
| 原训练 0026602 WAIT+PUSH | 再次安全退出 | PUSH 完成 0.4 m 请求，但物体转角约 −41.74°；不能视为高质量平移 |

主场景初始接触目标从约 x=2.494 m 投影至 x=2.390 m，排除右侧同伴占据区；随后随观测与同伴位置更新。本轮 4 个 PUSH+FOLLOW 主场景及局部变化全部完成，但这不是独立随机评测成功率。

主场景物体最大穿透约 **0.514 mm**；全部 16 分支最大约 **0.749 mm**，均未触发原异常阈值。保留接触重叠实数，不称为严格零穿透。主场景最小双机实际边缘间隙约 5.92 cm。

PUSH 的完成依据仍是本体实际法向行程，物体位移/旋转另行报告。偏离理想接触点可能产生力矩，特别是同伴 WAIT 不移动时；解除阻塞没有保证任意组合的目标效果对齐。

FOLLOW 依旧是相对表面维护而非接触支撑。主场景 FOLLOW 记录完成计时，但随着物体推动及 FOLLOW 退出后的保持阶段，最终真实物体间隙约 0.155 m，不能由 `follow_complete` 推断全程保持 2 cm 或产生支撑力。这仍是后续独立质量问题。

## 验证与复现

- 原主场景 baseline 的物理轨迹/施力与前轮归档完全一致，自由同伴对照也逐周期一致。
- 16 分支均由前一周期观测法向与原始本体位置独立复算法向行程，最大误差 2.78e-17 m；接触点对可行区间的最近点投影误差 ≤4.44e-16 m。成本仍按原日志独立复算。
- 61 项混合接触点/同面分配/法向计程/FOLLOW/RL 接口测试通过，未跑全套。浏览器检查 96 个视图，无脚本错误，手机宽度无横向溢出。
- 新字段关闭时保留旧 RL 描述/哈希；新候选配置显式区别，当前训练适配器未启用，旧 best/checkpoint 不被覆盖。
- `pilot/` 保留最初两段对照，最终以 `round_001/` 的冻结 manifest、原始 logs、metrics、contract_audit 为准。
