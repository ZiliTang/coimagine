# Run13 短训结果：与 Run12 前220轮对比

2026-10-29。Run13 已正常达到30分钟预算，220轮、1760个训练episode，训练器用时约1814.7秒；supervisor退出码0，没有故障停止，也没有自动续训。

**结论：执行层的错误锁死减少，但尚未带来任务学习收益；不建议原参数直接延长到数小时。** 验证成功峰值与run12相同，平均progress更差。保留有独立轨迹证据的执行修复，下一步适合单独检查探索持续性。

## 对比口径

- 主对比为两轮各前220轮、每轮8个完整episode，即相同1760个训练episode。
- 两轮的seed、训练场景生成器、64根固定validation、64根预留test、任务reward配置相同，源码指纹均匹配各自冻结manifest。
- 都有23次完整验证（第1轮及每10轮）。3根初始已在目标内，目标外成功分母为61；固定验证的重复观测不当作独立统计重复。
- 两轮约75.1万transition、约15.0万模拟秒，墙钟约30分钟。严格按run13训练器最终时间截取run12的完整history记录，可纳入219轮；只差一轮，未改变以下判断。
- run13包含已归档的生命周期修复和失败状态保持偏置关闭。不是单个控制器补丁的逐项训练消融，也只有一个训练seed，不能据此作显著性或普遍优劣声明。

run13第120轮达到5/64，其中3个属于初始已在目标内，真正从目标外推入的是2个。全部验证中，目标外成功记录共14次，run12为13次；这一个记录的差距不能作为可靠提升。run13最高保留频次为同一根成功5/23次，没有目标外根达到一半评估稳定成功。

训练侧平均progress略有改善（−0.095→−0.088），但目标外训练成功率均值基本相同（约2.61%→2.54%），没有对应的验证进步。

## 行为指标：修复有效，但策略仍未学好

以下为后5次完整验证，先逐次计算所有机器人的决策记录占比，再取均值。PUSH阶段不等于独立测得的物理接触时长。

| 状态占比 | Run12 | Run13 |
|---|---:|---:|
| 本机已失败 | 67.0% | 22.6% |
| 失败或等待同伴/感知的并集 | 67.0% | 34.0% |
| BRAKE阶段 | 17.4% | 33.9% |
| PUSH阶段 | 9.3% | 18.1% |
| REPOSITION move阶段 | 0.8% | 3.4% |

所以不能把改进仅解释成将失败改名为等待：连同等待计算，阻塞记录仍减少了。但BRAKE占比同时上升，更多执行也没有转化为稳定朝目标的运动。后5次验证，目标外场景真实距离改善均值由约−0.310 m变成−0.384 m，与归一化progress变差的方向一致。

随机训练的后50轮，模式切换/重试提交率约33.5%→35.0%（每机器人每次决策为分母；run13还包含少量明确改意图后的重试）。run13约每0.57秒提交一次切换/重试，探索仍然很碎。熵均值约4.73→4.74，未明显降低；run13保持偏置从初始2.5下降至1.512。

这与此前熵项削弱保持偏置的梯度诊断一致，但仍不能将所有失败归因于熵。当前仍采用完整回报Monte Carlo advantage与共享MLP；本轮没有对信用分配或历史表征作单变量验证。

## 后续建议

保留执行逻辑修复，不按当前配置直接延长长训。下一个对照可只把熵系数从0.02降到0.005，从头做同样预算的短训，其余reward、网络、控制器、场景与验证根固定。检验目标是切换频率是否下降、持续执行是否增加，以及目标外progress是否随之改善。

若持续性改善而任务progress仍不改善，再单独测试advantage估计或历史编码。当前数据不足以支持同时调整reward、引入GRU与世界模型后归因于某一项。本次分析没有启动下一项实验，也没有修改冻结训练源码。
