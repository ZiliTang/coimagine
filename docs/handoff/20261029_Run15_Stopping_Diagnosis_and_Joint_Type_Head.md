# 到达后制动诊断与V15联合类型头短对照

2026-10-29。本轮在V14小测台上继续，完成冻结策略诊断、一个联合类型评分头改动及两组配对短训。未改变任务reward、成功判据、物理或底层控制器。全部训练与诊断进程已经结束，未自动续为长训。

## 先确认失败属于哪一环

使用V14第30轮冻结策略，在预先声明的8个开发训练场景上生成8条贪心轨迹和64条新的随机策略轨迹（每场景8条）。贪心成功1/8，随机成功43/64；后者不是64个独立场景，也不是正式validation泛化。

在205个距离小于0.35m且仍向目标运动的随机策略决策中，双方BRAKE共13次，策略给该组合的平均概率约5.14%。其中13条决策都位于最终成功的episode内；在目标半径内仍运动的92条决策中，双方BRAKE共5次。观察到的相关性不等于这些动作单独导致成功。

GAE并非完全不给制动正反馈：按每8条episode重算归一化后，前一组13个双方BRAKE决策中12个优势为正、均值约+1.66；目标内仍运动的5个决策全部为正、均值约+2.71。这是冻结策略新采样批次的诊断，不是恢复了原训练迭代的实际梯度，也不能由此排除value估计误差。

随后从完整命令前缀重放到相同物理状态，在离线选中的边界改为双方BRAKE。3个原失败场景可转为成功：

## 本轮唯一训练改动

新增独立版本[option_rl_v15](../../experiments/option_rl_v15/README.md)。沿用V14分离actor/critic、944维合法输入、两层256 flat网络、GAE10秒迹、gamma=1、0.8秒保持、熵0.02、相同优化参数与任务成本。

将actor隐藏特征映射为14×14联合类型残差评分，加入原合法联合动作logits；速度条件分布保留。联合偏好由任务数据学习，未手工规定双方必须同向、必须BRAKE或必须等待。

残差头全零初始化，构造时保存/恢复随机数状态。单元测试确认两组初始动作概率和value逐项一致；正式训练首批回报、成功率、progress及641条actor transition也完全相同。36项聚焦测试通过，未运行完整仓库测试。[测试XML](../../outputs/option_rl_v15/focused_tests.xml)

## 改善机制需要收窄解释

不能把以上提升直接称作“学会协同BRAKE”。在V14原贪心轨迹选出的相同27个近目标合法观测上，两模型的双方BRAKE平均概率仅约4.60%与4.85%，贪心都没有选双方BRAKE。[相同观测比较](../../outputs/option_rl_v15/common_stopping_states_001/result.json)

联合头成功轨迹中，主动侧常在靠近目标后切换ROTATE，利用模式交接的减速过程满足停止条件；独立头成功轨迹常切换REPOSITION。它们均实际满足原低速、低角速度和持续0.5秒成功判据，是合法任务成功，但还不是明确、可持续保持的BRAKE策略。不能仅凭这个结果宣称改善来自联合制动或已学会双机合作。

随机策略的结果也未同步提升：固定最终权重、每场景4个相同预声明seed的32条新随机轨迹，独立头22/32成功、平均回报+3.885；联合头20/32成功、平均回报+3.106。轨迹随动作分歧，不把相同seed称作相同观测过程。小样本不足以认定联合头的随机策略更差，但本轮没有证明其随机策略期望收益更好。

本对照只改变一个架构组件，但增加的评分头也增加了容量和参数更新通路。更好的贪心结果可能来自联合表示、额外的状态依赖评分或优化变化；尚未分离这些原因，尤其当前改善主要集中在单机任务。后续若要证明联合交互本身有价值，应增加相同容量的独立评分或只保留交互分量的对照，再在双推/换面任务上验证。

## 当前判断

新联合类型头值得保留为候选：同预算开发小集合的贪心成功与progress已有可复核提升。当前仍未通过全8任务稳定成功门槛，双推/换面未解决，且存在成功遗忘与随机策略/贪心策略差距。尚不足以据此启动12小时全随机训练或宣称模型架构已经解决协作问题。

本轮按短预算完成后停止。下一步应继续固定小集合上的成功保留与交互对照；无需立刻更换物理、增加奖励或引入世界模型来解释本轮结果。
