## 0. 这份报告的范围与形式（与以往不同之处）

以往每份 `docs/<round>/report.md` 都是**针对单一任务书**的验收报告，按该任务书点名的问题逐条回答。
**本报告不是**。本会话横跨了 3 个任务书，另外还包含 1 轮自主调参和 1 轮自主诊断——后两项不针对任何
任务书，是发现缺口后自行发起的。因此本报告按"任务书 → 结论 → 证据位置"组织，并把非任务书工作
单列一节（第 3 节），同时**必须**把会话中对自身早先结论的撤回单列（第 4 节）：那些结论曾经出现在
本会话的中间汇报里，如果被写进新任务书的假设前提会直接带偏方向。

每一轮的完整报告、契约修订、errata 与数据表仍在各轮自己的目录下，本文只做汇总与取舍建议。

## 2. 逐轮结论与门槛判定

**2.1 `local_contact_option_v1`（四臂 O/P/F/N）**
信息隔离成立（改写隐藏物体真值、同一观测下输出力逐位不变）。G2 通过（有效推动 0.925）、
G3 通过（假稳定 0/897）、G4 **不通过**（N/P 位移中位比 0.437）、G5 通过（位置 P90 −55.6%）。
当时报告"判稳覆盖率 92.8%"——**这个数字在下一轮被证明不可信**（见第 4 节）。

**2.2 `local_contact_option_repair_v2`（同批 root 复核）**
G2 通过（主分母 0.925 / 次 0.9375）、G3 通过（假稳定 0/625）、G4 **不通过**（0.532）、
G5 **不通过**（位置 −60.2% 通过，**角度 +12.2% 不通过**）。修好单位后判稳覆盖率降到 0.651。
两个共用传感缺陷是真 bug：射线分组用"本次 run 第一条射线"而非相邻射线作连续性基准；
360° 扫描按线性而非环形分组，跨 0/2π 的片段被拆开。

**2.3 `local_position_push_v1`（V 速度式 vs X 位置式，1920 条）**
零间隙等价性精确通过。实测差异全部指向 X 更差：有效推动主分母 0.900 → **0.800**、
接触丢失 0.081 → **0.153**、位移中位 0.265 → **0.209**、接续三步正常完成 9/12 → **7/12**；
假稳定两者都是 0；扰动敏感度无实质变化（配对中位差 ≤4e-4）。**结论：控制律这条轴已经关闭。**

## 3. 不属于任何任务书的自发工作

**3.1 推动尺度诊断与两阶段调参 → `local_contact_option_push_v3`**
用户观察"推动慢、容易卡住"，先诊断：PUSH 期实际速度只有命令的 0.49–0.53，力均值 1.5 N / 15 N，
**从不饱和**；APPROACH 占 1.70 s / 总 6.30 s。主因是纯比例律对约 20 N·s/m 物体阻力的稳态误差
（`v/v_ref = Kv/(Kv+c)`，模型与实测吻合）。先激进（Kv 120 等）确认效果做得出来（位移 +60% 但力饱和
68%、接触丢失 9 次），再按**事先写好的规则**退回稳定：Kv 25、接近上限 0.08→0.30、`a_ref_max` 0.5→3.0。
test 上位移 +14%、每推动秒 +19%、**墙钟 −34%**，代价是穿透 1.3 mm→2.6 mm、G5 角度更差。
**结论：剩余瓶颈是结构（阶段切换的力尖峰被限幅）而非增益。**

**3.2 判稳严格性真值审计**（`experiments/local_position_push/analyse_settle.py`）
用 1920 条日志做两件事：未判稳退出的**真值审计**（313/313、368/368 在退出瞬间物体与两台机器人都
确实静止，0 例"判稳了但真值仍在动"）；以及在另一门槛下的**精确反事实**（BRAKE/SETTLE 的力与判据
无关，故可精确重算）。反事实：0.02→0.674/0.617；**0.03→0.745/0.744，且新增判稳里 190 例只有
1 例真值不达标**；0.06→0.869/0.870 但新增里 138/430 真值不达标；≥0.08 饱和在 0.87。
即：**门槛放宽到 0.03 是唯一接近免费的改动，再往上是用误报换数字。**

**3.3 可观测转移分析（目标设错，见第 4 节）**
留一 root 交叉验证：真值初态 → 总体 R² 0.885；仅白名单特征 → 0.025。**该数字无效**，原因见 4.3。

**3.4 表面速度估计量的鲁棒化与验证**
把聚合从逐点速度的 RMS 改成**逐点绝对速度的中位数**（保留"对称运动不被抵消"的性质，去掉对少数
错配点的敏感性），并在受控反例上验证（5 点中 1 点错配：中位数 0.000、RMS 0.125；对称 ±0.20：
两者都 0.20）。**但真实数据上中位数与 RMS 数值相同（差 ≤1e-5），重跑 1920 条的退出分布逐位相同**。
即这是买保险，不是修病。已提交并加测试。

## 4. 撤回与更正（任务书编写方必须知道）

**4.1 撤回"真值静止时估计量读数 0.040 m/s、是门槛两倍、判据无信息量"。**
那是我自己的静止窗口差了一个控制周期（估计量比较**两次扫描**，故窗口前一个周期也必须静止）。
修正后该 0.040 的噪声地板不存在。

**4.2 更正"判据太严"的说法。** 把估计量与正确的真值参考 `(v_object − v_robot)·n` 对齐后，估计
0.0180 对真值 0.0157、0.0137 对 0.0123、0.0011 对 0.0009——**估计量是准的**。未判稳的真正机制是：
SETTLE 期间物体**真的在残余滑行** 0.010–0.022 m/s，正好骑在 0.02 门槛上缓慢衰减
（物体阻尼时间常数 3.0/8.0 ≈ 0.38 s）。判据拒绝把确实还在动 0.02 m/s 的状态叫静止，**这是对的**。
所以既不是"判据太严"也不是"控制器停不下来"，而是**停机尾迹与门槛同量级**。

**4.3 撤回 3.3 的可预测性结论。** 我预测的是"物体终态在机器人起始坐标系里的位姿"，其中包含
**原理上不可观测**的全局朝向，然后把低 R² 当成"option 难学"。特权数据是做**标签**的，不是做**输入**的；
且按设计，每一步只需要可观测的局部构型。该分析必须用可观测目标重做。

**4.4 澄清一个容易被误引的数字。** 早先的"同 root 八变体离散度 0.011 m vs 跨 root 0.192 m
（R²=0.997）"回答的是"能不能区分不同初始条件"，**不是**"能不能跨 root 预测"。两者不矛盾，
但引用时必须写清问的是哪一个。

## 6. 给下一份任务书的建议（附证据强度）

已写为 `docs/tasks/20261013_1900_...`，此处给取舍理由：

1. **判稳可用率（第一优先，证据强）**。目标：≥0.90 且**真值窗**误报率 ≤5%。候选按推荐顺序：
   门槛 0.02→0.03（实测 +7 个百分点、190 例中 1 例不达标，是唯一接近免费的）；
   主动制动（让机器人贴住物体把它也按住，缩短 0.38 s 的滑行尾迹，属公共协议改动）；
   延长预算（作对照）。**这一项成功与否决定整条路线能否继续**，建议任务书写成硬门槛。
2. **用可观测目标重做转移分析（第二优先，方法已明确）**。目标改为"任务结束时会看到的局部几何"，
   输入只用白名单，留一 root 交叉验证，并**专门报告残差是否随隐藏朝向系统变化**——这一项才回答
   "可观测转移对隐藏状态有多敏感"，是楔形假设的前提。
3. **楔形构型（探索性，需先说清判据）**。必须在**同一运动类型内**造对照（同一条边 vs 相邻两条边），
   否则会重复上一次的混淆。
4. **需要任务书编写方裁决的三件事**（我不宜自行决定）：
   - 判稳的语义边界："镇定"是要求**物体真值静止**，还是只要求**可观测局部构型静止**？两者的
     门槛与验收完全不同。
   - 是否接受 0.03 这一档；若接受，等于承认"低于 0.03 m/s 的残余滑行"在语义上算静止。
   - 若后续要让策略主动偏好可预测构型，不确定性必须在某处**显式**进入决策（集成/悲观规划/代价里
     的方差项）。一个只做极大似然的动力学模型不会自己把策略推向可预测区域。要不要在本轮就写进去？
