# 历史编码器与世界模型同步训练：讨论方案存档

日期：2026-10-28。状态：**设计讨论，未实现，未接入正在运行的run11**。本文件保存本次讨论的用途、架构、边界和候选实验；不将建议参数写成已验证结论。

## 动机与当前基线

RL同时承担任务基线和世界模型数据采样器两种用途。一次真实环境交互可同时用于PPO和预测学习，世界模型的历史表示随后也可能改善策略输入。

当前run11在联合option边界读取760维观测，由两层256宽MLP产生actor/critic输出；没有循环策略、帧堆叠或完整option内部历史。输入含两机器人当前扫描、位姿/速度/接触、当前面几何、公开目标/时钟和末控制周期的少量技能进度。控制器内部的端点跟踪和反馈记忆没有整体交给策略。

历史可能帮助速度/角速度估计、遮挡端点持续跟踪、接触稳定性判断和记录先前失败尝试，但当前平台尚未隔离证明缺少历史是主要学习瓶颈。固定物理参数、集中共享双侧扫描和边界制动也可能降低历史依赖。

## 讨论中的首选接法

**共享交互数据，先独立优化，再分阶段接回策略。** PPO继续采样；预测模型从序列缓冲区训练，不直接用其loss更新当前actor/critic。验证预测有效后，将固定版本编码器接回新版本PPO，最后再考虑联合微调或想象规划。

同步训练不要求同步共享梯度。世界模型若仅旁路读取数据，不影响决策或PPO参数，则不改变原PPO优化问题，但仍会占用计算、存储和采样带宽。

候选结构：

```text
合法扫描/自身运动/接触 + 已执行命令 + Δt
                    ↓
          循环历史状态编码器 h_t
                    ├── 当前帧直接通路 + 公开任务 → option边界actor/critic
                    ├── 固定时间步转移/观测预测
                    └── 联合option转移/结束观测/耗时/退出与成本预测
```

历史状态初始可试10Hz更新，保留20Hz控制/扫描和120Hz物理；频率是待验证候选，不是已证最佳值。状态跨option保留、episode结束清零。不能只堆叠相隔十几秒的option边界来估计即时滑动速度。

## 区分滤波与预测，避免未来观测泄漏

看到当前观测后更新历史状态：

`b_t = F(b_(t-1), u_(t-1), o_t, Δt)`

尚未看到下一观测时的动作条件预测：

`b^-_(t+1) = T(b_t, u_t, Δt)`

`o_hat_(t+1) = D(b^-_(t+1))`

真实下一观测到来后才作校正。先输入o_(t+1)再解码o_(t+1)，只能证明重构能力，不能替代未来预测。没有概率语义和校准的GRU状态先称“历史表示”，不直接宣称精确Bayes belief。

低层固定步预测可用自身实际执行命令；option级规划的未来低层反馈命令尚未知，需要显式建模其闭环执行，或另学以两个名义option为条件的宏转移。**实际option耗时、未来退出原因应是输出，不能提前当作规划输入。**

## 保留原策略的能力

用户指出：历史表示与原观测同时输入，网络理论上可以忽略新增历史信息。该判断在函数表示能力层面成立，不保证有限数据和计算预算下更容易优化。

候选残差接入：

`actor_logits = actor_base(o) + W_h f(h)`

`V = V_base(o) + W_v g(h)`

复制已有actor/critic权重，W_h/W_v初始化为零；原760维观测、原归一化路径和原动作mask完全保留，使接入初始的动作概率与价值预测逐项一致。新增分支仍能在后续更新中学习。这只保证初始函数一致，不保证后续回报不退化。

初期将世界模型预测loss与原策略支路隔离；历史特征可独立归一化，避免跨全部维度的归一化改变原输入。随后比较冻结编码器与小学习率联合微调。若纯循环PPO作为对照，actor/critic循环状态宜分开测试；共享结构可能受预测、actor和critic梯度干扰，不能预先宣称联合训练更好。

## 预测目标与评价

- 分别预测雷达距离、命中/物体/静态/同伴类别，以及接触、可见边界/端点和运动趋势；合理处理缺失观测与置信度。
- option级预测结束观测、实际耗时、退出类别及固定任务成本/reward。辅助loss不是增加任务奖励。
- 包含多步自由展开；不能只报告真实观测每步校正后的单步误差。
- 对比复制当前观测、无历史、无动作条件等简单基线；分开报告物体相关、运动/接触变化和整体误差，防止复制大量静态/无返回射线取得低loss。
- 必要的仿真真值可作离线监督/诊断标签，不能输入部署编码器或用于候选动作mask。
- 先按完整episode/场景做训练验证分离，再采序列；避免随机拆相邻帧导致泄漏。另检查早期/后期策略的数据分布差异与不同option/尺度/组合覆盖。
- RL偏好的动作不一定覆盖所有候选动作；需报告覆盖分母与未验证区域。成功、失败、遮挡和受阻轨迹均保留，不能只学成功演示后声称普适动力学。

## 数据和训练工程

当前record=False快路径不持久保存完整option内部观测，collect_raw主要用于边界观测归一化；现有摘要不能直接训练连续时间循环模型。下一版需轻量序列缓存，记录合法观测、执行命令、阶段、时钟、边界和终止标记，不恢复昂贵全量调试日志。已有冻结run11的初态/动作序列可重放补数据，但应先验证轨迹一致性。

世界模型可从带版本的历史数据缓冲区反复训练，PPO仍按其on-policy规则更新，不能将旧数据任意混入PPO。训练资源需明确配额，分别报告采样与模型更新成本。

若联合训练循环编码器，PPO必须存连续序列，在更新中重算隐藏状态；不能只保存detach后的旧belief再宣称编码器获得RL梯度。保持采样旧logp、用新参数历史重放求新logp，正确处理burn-in、截断反传、padding和episode reset。辅助预测loss可在密集时间步应用，策略loss仍只在option决策边界应用。

## 候选实验顺序

1. 不改reward和option，旁路训练世界模型，先证明动作条件和历史对预测有用。
2. 对照当前MLP、短窗口MLP、冻结预测式GRU表示＋原观测MLP；保持信息边界、场景分割、策略预算并报告额外计算。
3. 若历史确有价值，再比较冻结与联合微调；如需纯循环PPO，单独列为方案。
4. 预测和校准足够后再考虑option级想象规划，不将“重构准确”直接等同于“能公平比较未执行动作”。

本轮不同时修改reward、控制器和记忆架构，也不在活动run11中热切换输入。研究贡献仍需通过表示/预测/规划的受控比较建立；actor＋world model＋critic的拼接本身不是已验证创新。
