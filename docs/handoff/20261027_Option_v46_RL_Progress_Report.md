# 交接报告：Option v4.6 与 RL 训练进度（给规划侧）

日期：2026-10-27。本文只写**已发生并可核对**的事实，标注推断与未验证项。

## 0. 一句话

单一环境模型 v4.6（协同 staging + 软短面）上的 option 已能稳定执行短/中距推与协同推；RL 侧
尝试了三种动作编码，结论是**平坦 28 路学不动、6 固定尺度只学会近/中距、因子化 type+scale 头
是恢复全部尺度后最合理的探索方式**，当前正在 uniform 全随机分布上训练（结论未出）。

## 1. 环境/option 的当前状态（v4.6）

- 动作空间：7 类型 × 4 尺度 = **28/机器人，784 联合**；`index = type*4 + scale`。
  - PUSH：3 个速度；尺度 = 请求距离 `{0.10, 0.25, 0.50, 1.00} m`；
  - REPOSITION：CCW/CW；尺度 = 转移距离 `{0.10, 0.25, 0.50, 1.00} m`；
  - WAIT/FOLLOW：尺度 = `{2,6,12,24} s`。
- 观测：760 维（2×18 非雷达 + 2×2 进度 + 2×72×5 雷达），无特权量。
- 协同推：staging（各到约 3 cm、10° 对齐）→ 双方 ready 后同周期 release；同侧 pair 实测
  after-engagement contact **100%**，接触前物体位移 <2 cm。
- 短面：软内缩（最小 0.1R），`L1_train_0002` 的 0.22 m 短面已能中心接触并推（0.5 m 档
  `push_complete`，1.0 m 档 `option_budget`）。
- 已知不稳定：相邻侧协同（垂直法向）仍会出现 `safety_abort`/`contact_lost`。

测台（68 分支/120 option）条件口径 62.0%（57/92）；未过滤 49.2%（59/120）。

## 3. RL 训练的三种动作编码（这是本轮最重要的经验）

训练器：`experiments/option_rl_v45/train.py`；场景：4.0×3.0 空场、无静态障碍、一物体两机器人、
随机初始与随机目标（离墙余量）；评估固定 16 test roots、确定性贪心、**不放松口径**。

| 编码 | 探索 | 结果（全目标 val_success） | 结论 |
|---|---|---|---|
| 平坦 28 路 softmax | 28 路 | 0（515+ iters） | 探索太贵，学不动 |
| 6 固定动作（推 .25/.50、绕行 .25、等待/跟随 6 s） | 6 路 | 峰值 **0.1875（3/16）**；最终 0.0625 | 能学会近/中距；尺度维度丢失，长推不可用 |
| **因子化 type(7)+scale(4)**（当前 run9） | 7+4 | 训练中（2026-10-27 启动，6 h） | 恢复 28 动作 + 可探索；结论待出 |

关键点：
- “6 动作能学、28 平坦不能学”**不是尺度没用**，是平坦 28 路的探索太贵；因子化头正是为了解决这
  个矛盾（用户原始设计就是 type one-hot + scale one-hot）。
- 训练分布：本轮明确**不做短→长退火**，训练与评估都用 uniform 全随机（短/长等概率），这样每步
  改动才可比。此前 run7/run8 的退火数据（峰值 0.1875、退火到远距后回落 0）应视为“退火课程”的
  产物，不是因子化头的基线。

## 4. 已确认的局限与推断（严格区分）

已确认（有数据）：
- 近/中距目标可学会（6 动作下峰值 3/16；val progress 多次为正，最高 +0.146）；
- 远目标（object→goal >约 1.2 m）在 6 动作下基本 0；
- 合法启发式（`fixed_policies._goal_action`）本身在 16 test roots 上 0 成功，因此 BC 只提供
  “推的形态”，不提供成功先验；
- 平坦 28 路 + 高熵/无 BC 时策略不会推；6 动作 + BC + 课程时会推（贪心 PUSH 41 / REPOSITION
  29 / WAIT 10）。

推断（未验证，需规划侧决定是否验证）：
- 远距失败与“多段换面→再推”的长程链式规划有关；但**尚未对远距 episode 逐段记录技能序列与物体
  位移**，所以不能断言是“没换面/换错面/推了但打转”。
- 奖励里 `distance_cost/time_cost/failure_penalty` 是否压过 `progress/success_bonus` 未做消融；
  固定策略对照（交接文档 v4.6）显示成功局 return 约 +7.4、失败约 −7，说明成功路径存在。

## 5. 给规划侧的问题清单（按优先级）

1. **远距规划**：多段换面应作为 option 内在能力（分层 option）、还是 RL 的课程/示范、还是交给
   世界模型？需要先验证远距失败的具体形态（逐段轨迹）。
2. **因子化头之后**：若 run9 仍只覆盖近/中距，是否引入“面向目标的选面”监督（仍用合法观测，不用
   真值选动作），还是把选面做成 option 的显式子技能？
3. **奖励/信用分配**：是否需要对长程成功做更强的信用分配（不改权重的前提下，例如分段 success、
   或只用现成的 progress 奖励做课程），需要规划侧定原则。
4. **评测口径**：当前 16 roots 的分布（0.38–2.38 m）是否代表目标分布？是否需要分层报告
   （近/中/远）而不是单一均值？
5. **协同**：同侧对称已可用、相邻侧不稳定；是否把相邻侧列为下一阶段目标，还是先只保证同侧？
6. **世界模型**：稳定性/接触模式此前判断应由世界模型学；option 侧是否需要为此保留哪些接口
   （例如 contact mode / 面身份）？
