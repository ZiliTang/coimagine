# B. 小规模真实终态预测训练

数据单元 = **一次真实联合 option**（执行前信息 → 退出时信息与标签），时长可变；不是"固定 2 s 后
的状态"。臂 V、`VariantSpec("baseline")`（无附加噪声/延迟）、round-3 冻结判稳协议
`settle_window=0.20`。采集与字段表见 `phase_b/{roots_b.py,collect_b.py,FIELDS.md,verify_b.py}`，
训练/评价见 `phase_b/{dataset_b.py,model.py,evaluate_b.py,train_b.py}`。

## 1. 数据总账

| 档 | train root | val | test | 执行数 | 丢弃 | 采样失败 | 墙钟 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 32-root 管道检查 | 32 | 64 | 64 | 256 (+1024) | 0 | 0 | 3.8 s |
| **第一档** | 256 | 64 | 64 | **3072** | 0 | 0 | 35.3 s |
| **第二档** | 512 | 64 | 64 | **5120** | 0 | 0 | 60.7 s |

- 每个 root 恰好 8 条执行、8 个**不同**命令；同一 root 的 8 条共用同一个快照
  （`snapshot_sha256` 相同），完整快照/精确重放路径已验证（`verification.json` 的
  `exact_replay.all_ok = true`：同一命令两次运行的终态、退出类别、时长逐位相同）。
- 六类构型全覆盖；α ∈ {−15°, 0°, +15°}、speed ∈ {0.08, 0.16, 0.26}，全部在冻结集合内。
- **失败样本全部保留**：2887 `settled_observed`、132 `contact_lost`、47 `patch_lost`、
  6 `settle_unobserved`；`settled_after_abort = 170`（round-3 记账路径可达）。
- **泄漏防护**：新盐使种子家族互斥，采样时硬拒绝跨 split 距离 < 0.02 m 的 root。
  独立复核（`verify_b.py`）最小跨 split 距离 train↔val **0.0412 m**、train↔test 0.1176 m、
  val↔test 0.1796 m；root-id/种子零重叠；把阈值抬到 0.30 m 时 16/16 被拒（守卫是活的）。
- 两档的 **val/test 逐位相同**（sha256 一致），所以档间比较干净。

## 2. 模型与冻结配置

2×256 MLP + ReLU，Adam lr 1e-3，batch 128，≤200 epochs，验证 patience 20，种子 0/1/2；
六组目标权重全部 1.0；连续目标按 train 统计量标准化 + 带 mask 的 MSE，观测有效性
用二值交叉熵，退出类别用交叉熵；checkpoint 只按 val 综合损失选。**参数量 97,573，输入维 86**
（deployable 的特权槽置零，privileged 填入物体真值初态；两者同结构、同参数量、同预算）。
三个种子实际都用到第 191–197 epoch（早停前）。

## 5. 动作是否产生不同终态

同 root 8 个命令的真实终态 spread（test，有符号距离）中位 **0.0556 m**；模型预测的 spread
中位 **0.0607–0.0670 m（一档）/ 0.0720–0.0817 m（二档）**。也就是说动作确实改变终态
（384 个 root 全部有非零 spread，中位物体位移 0.228 m），而模型输出**随动作变化**。

### 5.1 修正：spread 不能证明"动作对应关系正确"（评审意见）

把同一 root 的八个命令标签**打乱**，spread **完全不变**，但决策可能全错。所以必须换成
**动作差值误差**与**排序一致性**。新增脚本
`experiments/option_prediction_mechanism_v1/phase_b/action_sensitivity.py`，
结果 `phase_b_tier2/action_sensitivity.json`，二档 deployable 三个种子在 test 上：

| 终态几何列 | 动作差值中位误差 p50 | p90 | Spearman ρ 均值 | **置换对照 ρ** | ρ 可定义 root / 参与 root |
|---|---:|---:|---:|---:|---:|
| r0 有符号距离 | **0.0045 m** | 0.0091 | 0.511 | 0.002 | 64 / 64 |
| r0 切向偏移 | 0.0212 m | 0.0402 | 0.464 | 0.014 | 64 / 64 |
| r0 法向 sin | 0.0445 | 0.0962 | 0.708 | 0.004 | 64 / 64 |
| r0 法向 cos | 0.0188 | 0.0409 | 0.116 | −0.016 | 64 / 64 |
| r1 有符号距离 | 0.0193 m | 0.0668 | 0.378 | −0.009 | 51 / 64 |
| r1 切向偏移 | 0.0367 m | 0.0711 | 0.488 | −0.005 | 51 / 64 |
| r1 法向 sin | 0.0525 | 0.1085 | 0.622 | 0.004 | 51 / 64 |
| r1 法向 cos | 0.0355 | 0.0646 | 0.086 | −0.013 | 51 / 64 |

**并列处理修正（评审意见）。** 原来用 `argsort(argsort(x))` 得到的是**序数排名**，并列值按数组
顺序强行分先后，会凭空造出相关性。现在用**平均排名**；若真实值或预测值全相同则 ρ **无定义**，
报 `nan` 且不参与汇总，同时报告可定义的 root 数（上表最后一列：r1 的 13 个 root 因有效命令
不足 3 个而**未参与**；本轮没有因"全相同"而无定义的 root）。
样例（`tests/test_option_prediction_mechanism_b.py`）：常量 → `nan`、并列 → 0.949、
正序 → 1.0、逆序 → −1.0；对 `[1,1,2,2,3,3]` 旧序数法给 1.0、平均排名法给 0.956。

读法（**ρ 是秩相关系数，不是排序正确率**，ρ=0.5 不表示一半动作比较是对的）：
- **动作差值**（同一 root 内任意两个命令的预测变化量减去真实变化量）中位约 **4.5 mm**（r0 距离）；
- **秩序相关**：r0 距离 0.51、法向 sin 0.71，属**中等**；r1 距离 0.38 偏弱，
  cos 分量 ≈0.1（法向接近竖直，cos 几乎没有变化，秩序本身病态）；
- **置换对照把 ρ 打到 ≈0** 而 spread 不变——证明这两个指标确实在测"对应关系"，
  也证明第 5 节那个 spread 数字**不构成**动作对应关系的证据。

结论：模型**部分**学到了"哪个动作会把终态推向哪边"，但**远不足以**据此说它具备规划价值。

## 7. 训练目标审计：报告声称 vs 实际字段（评审意见，本轮只改文档）

审计脚本 `phase_b/audit_targets.py`，结果 `phase_b/target_audit.json`（2048 条记录）。

| 报告声称的目标 | 实际训练字段 | 字段计算来源 | 能否从允许观测直接得到 |
|---|---|---|---|
| "机器人终态会看到的局部几何：有符号距离" | `label.robot{i}.terminal_signed_distance` | `collect_b.segment_geometry(terminal_object, face, terminal_pose)`：用**真实终态物体位姿**与**真实面线**算出的距离 | **近似可以**——与观测片段距离的中位差 **0.37 mm**、p90 9.5 mm，但有 0.63 m 的尾部 |
| "……切向偏移" | `label.robot{i}.terminal_tangential_offset` | 同一个调用：沿**真实面线**、从**真实面中心**量起的坐标 | **不可以**。观测侧最近的对应量（片段质心在机器人起始系的 x）原点与切向都不同，两者**按构造就不是同一个量**，不存在可比误差 |
| "……法向方向" | `label.robot{i}.terminal_normal_own_start_frame` / `terminal_normal_sin_cos` | `collect_b.face_frame(terminal_object, face)`：**真实面**的外法向 | **近似可以**——与观测片段法向夹角中位 **0.019°**、p90 0.074°，但有 **90°** 的尾部（换面） |
| 观测有效性 mask | `mask_terminal_geometry` | `mask_terminal_patch_valid` **且** `point_box_distance(terminal_pose, terminal_object) ≤ SCAN_RANGE` | 第一项可观测，**第二项用真实终态物体位姿** |

其中 `face` 由 `reference_face(initial_object, pose_start)` 决定，**也用了真实初始物体位姿**。

mask 交叉表（2048 条 × 2 机器人）：两者都有效 3618、都无效 478，
**不一致 0 例**——所以 mask 实际上由可观测的片段有效性主导。

**不能支撑的结论（必须写清的限制）**：
1. 这三个标签里有**真实的物体参考面信息**（面编号、面中心、面线），
   不是"实际扫描片段"。因此本轮"deployable"臂预测的是一个**部分不可观测**的量，
   它的小误差**不能**读成"机器人能预测自己将观测到什么"。
2. 现有标签**无法支持"未来观测预测"**：记录里其实采集了可观测的对应字段
   （`obs_terminal_patch_distance`、`obs_terminal_patch_normal_own_start_frame`、
   `obs_terminal_patch_centroid_own_start_frame`、`mask_terminal_patch_valid`），
   但**本轮的训练目标不是它们**。要预测"机器人将观测到什么"，必须改用这些字段重做标签，
   并重训——**这不在本轮范围内**。
3. `terminal_tangential_offset` 与观测片段质心不是同一个量，之前把两者并列讨论是错的。

## 8. 这个模型是什么、不是什么

它是**局部观测与执行结果的终态预测基线**，输入是双方可共享的起始局部观测、自身运动学、
静态场景与联合技能命令，输出是双方可观测终态几何、机器人终态位姿变化与残余速度、时长、
观测有效性与退出类别。它**不是**可递归调用的完整信念世界模型，本轮也**没有**接入规划器；
使用融合输入**不代表**已经实现分布式模型。
