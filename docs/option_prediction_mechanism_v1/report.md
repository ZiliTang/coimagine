## 1. A 修了什么，哪些误判被消除，哪些限制仍在

修了两件事，都没动门槛、力或阶段结构：

- **记账**：`primary_exit_reason` / `locally_settled` / `settled_observed` / `settled_after_abort`
  分开；旧实现里 `settled_after_abort = settled and abort_exit` 结构性恒为 False（死代码），
  现在两条路径都可达，真实轨迹测试验证。中止后判稳定为**中止**，不计正常完成。
- **时间戳与估计量**：`now` 改用当前控制周期时间（旧代码让 `now − sample_time ≡ 0`，
  新鲜度检查形同虚设）；同一帧只算一份证据，重复帧**冻结**保持窗而非清空；过旧 / 丢观测 /
  匹配不足 / 采样间隔 > 0.15 s 一律标记不可用；窗口化估计量只在合同中冻结的 0.20 s 与 0.30 s
  之间选型，先做**有时间符号**的逐点法向速度、再做空间聚合（不靠取绝对值平均降噪）。

效果（test，V）：正常完成 **0.674 → 0.884**（647→849/960），局部判稳 **0.762 → 0.998**
（958/960），超时 **190 → 0**，`noise`/`delay` 两个压力变体从 0/120 恢复。
配对：202 条 `unsettled→normal`、109 条 `abort→after_abort`、1 条仍未判稳。
估计器误判 0.025→**0.017**，陈旧数据误判 **0**。

仍存在的**可观测性限制**（不是账目问题）：① 本地法向扫描**原理上看不见纯切向运动**，
test 上 9 例"局部确实低速、物体整体仍在转"（有断言测试）；② 仍有 **16/958** 例估计器误判，
确认窗内 patch 级真值表面速度 0.0202–0.0428 m/s，集中在减速进入静止的起始段。

## 3. B 是否真的训练了模型，哪些目标有收益

真的训练了（PyTorch 自动微分，2×256 MLP，97,573 参数，3 种子，checkpoint 按 val 选）。
test 中位绝对误差，持久化 → 第二档 deployable：有符号距离 **175 mm → 4.4–7.1 mm**、
切向偏移 248 mm → 30–41 mm、法向角 **18.7° → 2.7–3.6°**、时长 **2.06 s → 0.09–0.11 s**、
退出类别准确率 0.922 → **0.969–0.971**，其中稀有类 `contact_lost` 召回 0.08 → **0.80**。
按 root 聚合（64 root）一致。同 root 8 命令的真实终态 spread 中位 55.6 mm，模型预测 72–82 mm，
说明它**捕捉到了动作造成的差异**而不是只会输出均值。
特权参考（物体真值初态）只带来很小增益（切向 −3.9 mm、法向角 −0.5°），**不能**据此说状态完全可观测。

## 4. 两档趋势与停止条件

第一档在验证集上四个任务相关目标全部比持久化好 20% 以上（比值 0.04–0.20），触发合同 §2.4 的
扩充条件，故执行第二档。第二档把 test 有符号距离中位从 7.9–9.5 mm 降到 **4.4–7.1 mm**、

切向偏移基本饱和（30–41 mm 未改善）。两档用同一配置、同一种子、同一 val/test（哈希相同）。
按合同**到此停止，不启动第三档**。

## 5. C 是否找到"信息相近但选择不同"的案例

找到了：64 对候选中 **18 对正例**。最强一对 `T1-12-symmetric`：双方全部允许共享输入
（自身位姿/速度、72 条原始射线的距离与命中/有效/目标位、局部片段点集/线段/距离/跨度/法向/
切向/置信度/遮挡、接触读数、静态地图、命令历史）**逐量最大绝对差 0.0**；
近优集合 A\*={`along_pos_2`} 与 B\*={`spin_pos`} **无交集**，互相 regret **0.256 > δ=0.02**；
50/50 全知 0.116 vs 共同动作 0.072，差 0.044。世界 B 用两个技能可以完成、世界 A 一个都完不成。
我用独立脚本从参数重建两个世界、重跑全部技能，复核了 5 个正例，全部数值**逐位一致**。
64 对中 0 对非法、6 对因观测已可区分被拒、39 对因近优集合相交被拒、1 对无有效共同动作。

## 6. "信息乐观"的差距是否只是全知上界

不全是。在同一个有限候选集上：T1-03 全知 0.256 / 共同动作 0.145 / **合法观测条件化**
（只有第一技能后观测真的可区分才分支，否则必须用同一规则）**0.194**；
T1-12 三者 0.666 / 0.553 / **0.666**——合法分支能把差距全部拿回来。
但必须同时说清：18 个正例 × 8 个首技能 = **144/144** 次检验中，执行完第一个技能后两个世界
**都变得可区分**，所以"第二技能必须同一规则"这条约束本轮从未生效，这个歧义是**一次性**的，
只影响第一个决策。另外两处**声明性**收窄必须连同结论一起引用：传感由 360° 环改为前向 ±60° 锥
（否则机器人看到身后场地即可区分）、技能窗由冻结的 2 s 改为 6 s（否则既有 success 规则几乎
不可能成立）；物理、力上限、成功判据、评分未改。
