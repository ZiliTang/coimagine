### 1.3 估计量与时间戳（冻结）

- 证据时间一律用**传感器采样时间** `sample_time`；`now` 用**当前控制周期时间**（不是帧自带时间）。
- 同一帧只算一份证据：`sample_time` 与上一份相同 → **冻结**保持窗（不增不减）；不因重复而清空。
- 真正不可用（过旧、无片段、匹配不足、帧间隔过大）→ 标记不可用并**清零**保持窗。
- 冻结常数：最大新鲜度 `SURFACE_FRESHNESS` = **0.20 s**；允许最大采样间隔
  `SURFACE_MAX_SAMPLE_GAP` = **0.15 s**；窗口最小基线 = **0.10 s**。
- **候选窗口只有两个：0.20 s 与 0.30 s**，不做其他参数搜索。
- 估计顺序：**先时间、后空间**。先在窗口基线上对每个匹配点求**有符号**法向速度 `v_i`，
  再做空间聚合。主统计量 `median_i |v_i|`（不抵消 ±，能看见旋转）；同时报告有符号均值与
  IQR 作为诊断。噪声靠**加长基线**压低，不靠"先取绝对值再平均"。
- 保持窗累积：在"有新的有效采样帧且当前判据通过"的周期 `+dt`；重复帧冻结；判据不通过或
  不可用则清零。确认时必须报告**证据覆盖的采样时段**与**相对当前时刻的滞后**。
- 明确声明：切向运动是本地传感盲区，本修复**不保证**物体全状态静止。

### 1.4 A 选型与复核（冻结）

1. 候选只在 **dev**（24 root × 8 变体 = 192 条，V 臂）上比较；
2. 顺序：**先**看运动误判（真值仍在动却被确认静止）与陈旧数据误判（证据不覆盖保持窗却确认），
   **再**比较静止确认率与确认延迟；不得只按判稳率选型；
3. 采用后重跑 V 的 **test 960**，与旧 V 日志按 `(root_id, variant)` 配对；**X 不重跑**；
   旧 test 称为**既有回归集**，不是全新泛化验证；
4. 逐变体输出：正常完成 / 中止后判稳 / 超时 / 不可观测 / 错误确认 / 确认延迟；比率注明分母；
5. 关键安全检查不通过 → 不启用候选，保留旧协议并记录失败，不发明第三个估计器。

## 2. 冻结：B 小规模终态预测

### 2.1 数据单元与规模

- 单元 = **一次真实联合 option**（执行前信息 → 退出时信息与标签），时长可变。
- 规模：train **256** root / val **64** / test **64**；每 root **最多 8** 个固定生成的联合技能命令；
  第一档执行上限 **3072**；第二档 train 增至 512 root，总上限 **5120**。
- 命令集合必须包含**真正不同**的合法控制选择；命令选择只允许用允许观测，不得按真值挑。
- 不删失败/中止/传感缺失/未判稳结果；失败单独计入数据总账。
- 传感条件：主训练**无附加噪声与延迟**；A 的噪声/延迟测试单列。
- 拆分按**底层初态家族**分组；同 root 命令、几何近重复、扰动版本、同轨迹派生状态不得跨 split。
- 先采 **32 个 train root** 做管道与小样本拟合检查，通过后才扩至规定规模。

### 2.2 输入 / 输出 / 模型（字段表另附 `FIELDS.md`）

- 主模型输入：双方可共享的起始局部观测、自身运动学、静态场景信息、联合技能命令；
  保留观测有效性 mask。本轮不新增历史编码网络。
- 主输出：双方可观测终态几何（有符号距离、切向偏移、法向 sin/cos，各自起始坐标系）；
  机器人终态位姿变化与残余速度；option 实际时长；观测有效性与退出类别。
- 切向偏移按**片段质心/对应点变化**计算，报告名称为"片段切向偏移"，**不得**称为物体材料点位移。
- 缺失几何用 mask，保留离散结果；**不得填零后参与几何损失**；未观测类别样本仍计入分类评价。

### 2.3 训练配置（冻结）

2×256 MLP、ReLU、Adam、lr **1e-3**、batch **128**、最多 **200** epochs、验证 patience **20**、
种子 **0/1/2**。连续目标按 train 统计量标准化 + **带 mask 的均方误差**；离散目标交叉熵。
**各目标组损失权重全部 = 1.0（六组等权，冻结，不按 test 调整）**：
`terminal_geometry`、`robot_pose_delta`、`robot_residual_velocity`、`duration`、
`observation_validity`、`exit_class`。checkpoint 只按 val 综合损失选。
不做宽度/学习率搜索，不混入精确模型行平均。

三档对照（同一输入槽、同参数量、同训练预算）：

1. **persistence 基线**：终态几何/机器人状态 = 起始值；时长与类别用 train 统计量（时长=中位数，
   类别=多数类）。
2. **deployable**：只喂白名单输入；特权槽**恒为零**。
3. **privileged 参考**：同一网络，特权槽填物体真值初态（位姿+速度）；仅评估信息增益。

### 2.4 扩充与评价（冻结）

- 第二档前提：第一档**实际训练完成、无数据/标签故障**，且验证集上**至少一项任务相关指标**
  超过 persistence 基线。仅按验证集决定；两档配置冻结后再汇总 test。
- 评价：逐目标 MAE / 角误差的**中位数与 p90**；分类混淆、各类数量与召回；按构型、
  真实发生运动/近静止、正常结束/中止/未判稳分组。
- 单列"动作是否产生不同终态"：同 root 不同命令的真实输出 spread，以及模型是否捕捉其变化。
- 结果按 root 聚合，三种子完整列出；test 只用于最终报告。

## 3. 冻结：C 信息歧义机制实验

### 3.1 命题

存在两个合法世界 sA、sB：双方**所有允许共享的当前输入**相同（数值容差内）或在声明的传感噪声下
难以区分；可执行技能命令集合相同；而真实后续结果中，A 的近优动作集合与 B 的**无交集**。

"物体状态不同"本身不是正例；必须比较双方完整允许观测与可用历史。

### 3.2 搜索范围（冻结）

- 只两个模板，每个最多 **32 对**候选，共 ≤64 对：
  - T1：双机器人接触同一长直边，物体沿边**切向位置不同**；
  - T2：相同合法局部接触观测下，与**已知通道/障碍**有关的后续动作选择不同。
- 先用已有物体与传感配置；若端点始终可见而无歧义，可另建**明确版本**的长矩形机制场景，
  同一对内形状/尺寸/质量/地图完全一致，并检查初态合法；新场景与旧基准分开。
- 每对比较：双方位姿与速度、原始扫描、有效性与遮挡、局部片段、接触读数、已知地图、
  命令、已有历史。冷启动/无历史场景必须明确标记。

### 3.3 评分与正例判据（冻结）

技能集合：每对使用同一组**至多 8 个可部署联合技能**；先单技能，必要时枚举至多**两技能**序列。

标量收益（先固定，不得事后改）：

```
completion  = 1 if 对象满足既有 success 规则（在 goal 内且低速保持 0.5 s）else 0
progress    = min(1, (d_start - d_end) / max(d_start, 1e-6))，d = 到 goal 的最大角点距离
time_cost   = 技能序列的总墙钟秒数
action_cost = 总指令冲量的归一化 (Σ|F|·dt / (F_max · T_total))
Q_h(a) = completion + 0.5*progress - 0.05*time_cost - 0.10*action_cost
```

- 近优集合 `A*_h(δ) = {a : R_h(a) ≤ δ}`，`R_h(a) = max_b Q_h(b) - Q_h(a)`。
- **δ = 0.02（事前容差）**；仿真是确定性的，重复仿真误差按 0 记（用重复运行核验）。
- 正例要求：`A*_A(δ) ∩ A*_B(δ) = ∅`，且两个世界的最优动作互相的 regret **> δ**。
- 全知参考 `0.5 max_a Q_A + 0.5 max_a Q_B`；共同动作 `max_a [0.5 Q_A + 0.5 Q_B]`；两者之差
  即隐藏状态信息的潜在价值。**本身不证明任何现有规划器犯了信息乐观错误。**
- 两技能序列：第一技能后的观测若仍不可区分，第二步必须采用**同一**决策规则；已可区分才允许
  分支。至少给出一个遵守该约束的有限候选信念规划参照（可枚举，不开发通用 POMDP 求解器）。
- 无正例：记录是观测已足够区分、动作排序无实质差别、还是技能集合不足；停止 C。

   **第一版的 18 个正例与 C4 数值不再作为证据。**
2. **C 重做沿用本节 3.2 的场景许可，但协议全部冻结**：局部 V 控制器、360°/0.6 m/72 射线传感、
   2 s 有效接触与既有阶段协议、既有物理。只允许改物体**长度**（为了让两端落在扫描之外）。
   事前声明案例，交付正例或负结果，**不做参数搜索**。
3. **B 的评价补充冻结口径**：除 spread 外必须报告**同 root 动作差值误差**与**排序一致性**，
   并给出**置换对照**；spread 本身不构成动作对应关系的证据。
4. **A 的口径冻结**：正常完成、中止后判稳、局部判稳三个口径必须分别报告，
   跨轮比较只能用同口径数字。
