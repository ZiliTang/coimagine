# PLAN — night_sequence_v1

任务书 §2 的时间预算与优先级。**实际开始时间与截止时间记录在 `STATUS.md`。**

## 优先级（严格执行）

1. 序列采集与加载接口（数据正确性优先于模型数量）。
2. 一档新增独立 root（D1）与固定的新 val/test。
3. **至少一组成对 MLP-history / Transformer-history 训练与同目标评价。**
4. 导师汇报素材包（§9，**必交**，优先于 D2 追加采集与 D2 训练）。
5. D2 采集与 D2 成对训练（只有在主对照按时完成且 D2 完整时才做）。

## 本轮采用的顺序

| 步骤 | 内容 | 回退方案 |
|---|---|---|
| 1 | 写序列采集器、九项正确性门槛、吞吐标定 | 若某门槛不过，先修或隔离，不用规模掩盖错误 |
| 2 | 恢复 D0（原 train root 精确重放全过程） | 若重放不一致，逐条定位，不用新轨迹替换 |
| 3 | **先固定新 test 512 / val 256 root**，再扩 train | 若 root 空间因去重标准停滞，交付较小完整档并报告 |
| 4 | 扩 D1（3584 新 root） | 同上 |
| 5 | 建 token 数组与窗口采样，标定 200 步耗时 | 若两历史模型 200 步过慢，统一降预算并在 CONTRACT 标记 |
| 6 | 跑主矩阵（D0/D1 成对 + 种子 + 单帧消融） | 时间不足时先保证 D1 三个模型各一次完整 run |
| 7 | 统一评价（P0/P1 + 模型，t=0 与执行中分开） | — |
| 8 | 渲染 F01–F08 与素材包 | **最后 60 分钟只做评价、渲染、交付** |
| 9 | 若仍有充裕余量：D2 采集 + D2 成对训练 | 直接跳过，如实登记 |

## 明确不做

新场景搜索、主动辨识、显式随机 latent、先验/后验网络、VAE、对比学习、集成、自由 latent
rollout；不改底层控制器与物理，不扩技能词表，不新增噪声/摩擦/质量/障碍物任务；
不实现完整规划器；不新建两步分支库；不加入第三类序列网络；不为跑满时长做重复实验。
