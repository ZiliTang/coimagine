## 2. 数据（§3）

- 一条真实 option 执行 = 一条序列。主间隔 Δt=0.05 s，记录**真实时间戳**。
- **O0** = 动作开始前、同一初态下真实可获得的观测（执行器先感知、后施力，所以
  `trajectory[0]` 就是它，不是"跑了一个周期后的第一条日志"）。
- **T** = option 实际退出时刻。阶段机在 append 日志行之前 break，因此最后一条日志比 T 早一个
  周期；本轮的终态观测是**退出后不推进物理、不施加控制**的一次真实传感调用。
- 首次采集即同时保存全过程与 T（不先丢过程再全量重放）；加入记录不改变物理步与控制输出。
- 三类 mask 严格区分：`token_valid`（是否存在）、`patch_valid`/`geometry_mask`（存在但片段不可见）、
  `target_available`（指定未来时刻的样本是否存在）。不可见时刻**不是** padding，不删除；
  短序列/中止轨迹不整条删除。
- 档位：D0 = 512 root/4096 序列（原 train root 精确重放）；D1 = 4096 root/32768 序列；
  新 val 256/2048；新 test 512/4096。**先固定新评估 root 再扩 train**，用原近重复标准
  （`MIN_ROOT_DISTANCE=0.02 m`）隔离所有互斥 split。D2 未采集（时间不足，如实登记）。
- 分片存储、原子写入、带配置/来源/哈希、支持续采。

## 3. 共同任务（§4）

- 历史窗口：O0 锚点 + 截至当前时刻的**最近 32 个真实网格时刻**，≤33 token；不足左侧 padding。
  锚点若已在窗口内不重复。**改变未来轨迹不改变当前输入**（因果）。
- 两组预测头（所有模型完全相同）：
  - **A 固定 Δt 过程头**：下一网格时刻的片段几何(8)、自身相对起始位姿(6)、速度(6)、可见/接触(4)，
    以及"本 option 是否在未来 Δt 内退出"(1)。标签时刻跨度恰为 Δt；末尾非整步不进入固定步长标签。
  - **B option 终态头**：实际 T 的片段几何(8)、位姿(6)、残余速度(6)、可见/接触(4)、
    剩余时长 T−t(1)、退出类别(15 类)。
  - 权重：两组任务各 **0.5**；组内各子组等权平均。连续标签**按组**用 train **有效值**拟合
    **单标量** mean/std（沿用原方案，**不是逐列**）；过程与终态各自统计；二值/multiclass 不标准化。
- 采样：先均匀选 train root，再选其 8 个命令之一，再选预测起点——**25% 取 t=0**，其余在该序列
  未终止时刻中均匀取样。各模型同 seed 使用**相同**的 example 序列。
- 主评价分开：**执行前 t=0**（只有 O0 与候选命令）与**执行中**（真实观测前缀，按预先固定的
  0.25 s elapsed 区间报告）。

## 4. 模型与训练（§5）

| 模型 | 输入 | 结构 | 参数量 |
|---|---|---|---:|
| MLP-current | 锚点 + 最新 token | 2 层宽 512 | 686,913 |
| MLP-history | 同一 ≤33 token 窗口，固定顺序展平 + mask | 2 层宽 512 | 1,608,513 |
| Transformer-history | 完全相同窗口 | 4 层、d_model 128、4 头、FFN 512、dropout 0.1 | 895,937 |

两个历史模型参数比 **1.80×**（目标 ≤2×，均在 0.5–2M 量级）；单帧模型参数更少，**单独列出**，
不与历史模型混作架构结论。

训练：AdamW(lr 3e-4, weight_decay 1e-4)，梯度范数裁剪 1.0，有效 batch 128，
5% 线性 warmup 后 cosine 到 3e-5，每 200 次更新验证，按**共同验证合成损失**选 checkpoint。

**更新预算（标定后统一冻结）**：D0/batch128 实测 200 次更新 MLP 5.2 s、Transformer 35.1 s；
6400 次会使整个矩阵约需 2h20m，无法与必交交付和素材包并存。按 §5.2 允许，**全体主 run 统一使用
3200 次更新**，无任何 run 使用不同预算；未使用 1600。结构在正式训练前写入本文件，**不依据 test 调参**。

矩阵（§5.1）：
1. D0 的 MLP-history 与 Transformer-history，seed0 配对；
2. D1 的同上，seed0 配对；
3. 上述 4 个组合补 seed1/2（共 12 次主训练）；
4. D1 的 MLP-current seed0/1/2；
5. D2 未采集，故 D2 成对训练未执行。

## 5. 基线与评价（§6）

- **P0**：固定步长保持当前可见几何/自身状态；终态保持当前状态，剩余时长取同 elapsed 组的 train
  中位数，退出取该组 train 多数类。起始/当前不可见的连续几何回退**只用 train 原始单位统计**并
  单列 fallback 率。
- **P1**：按（公开联合命令签名，elapsed 0.25 s 组）计算 train **原始单位**统计；连续量中位数、
  法向单位向量均值、二值/类别频率；组内样本 <20 依次回退到 命令+时间 → 命令 → 全局。
  统计遵守监督 mask，**不按真实 T 或未来退出分组**；查表保存备查。
- **P1 频率直接是概率，不经过 sigmoid；只有网络二值头是 logits。** 归一化/反归一化只发生在
  明确接口，基线不会再被反标准化一次。
- 必报指标见 `report.md`；**每模型逐样本预测**保存，键为 (root, record, end, target_kind)；
  所有连续指标在**原始单位、真实标签 mask** 上计算，不用模型自己预测的可见子集美化误差。
