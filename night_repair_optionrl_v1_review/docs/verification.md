数值复现**不等于**语义正确，所以第三层之前必须先过第一层。

## 2. 为什么数值复现不够

上一轮的打包验证器复用了同一套错误读出，因此"数值一致"完全不能说明实现对。
本轮因此把**语义不变量**单独抽出来，并且都在**真实模型调用路径**上检查：

- 读出位置：对 `DirectMultiStep.encoder → last_real` 的实际张量，逐长度断言摘要等于真实末位；
- `t=0`：只有初始观测时摘要范数为 7.999955，**不是零**；
- 消融：修复后的时间索引让首步就不同（在**旧**实现下首步差为 0.000e+00，被同一检查捕获）；
- 梯度：`transition[0].weight.grad` 的范数 0.028 > 0，说明损失确实经过递推；
- 采样：两个 epoch 抽到的 (序列,前缀) 集合不同，重叠率 0.24%；
- 信息边界：保持合法观测向量不变、替换隐藏真值后，actor 输出**逐位相同**；
- 半马尔可夫：变时长回报与手算一致（2.62 = 1.0 + 0.9² × 2.0）。
