# CHECKPOINT_INTERFACE — 哪些字段能预测、哪些来自命令/时钟、哪些仍缺失

本轮只做**接口清点**，不使用任何真实未来字段去补全"自主 rollout"。

## 1. 模型可预测（当前输入已包含全部所需信息）

| 输出 | 到达时刻 | 本轮状态 |
|---|---|---|
| 下一步两机器人中点（`R_i0`） | t + 0.05 s | 可用，残差参数化 |
| 下一步法向方向 | t + 0.05 s | 可用，原参数化 |
| 下一步位姿角 / 速度 / 有效性 | t + 0.05 s | 可用，原参数化 |
| 终态两机器人中点 | T | 可用，残差参数化 |
| 终态法向、位姿、速度、有效性 | T | 可用 |
| 距终态剩余时间 `terminal_remaining` | T | 可用 |
| 退出类别 `terminal_exit_class`（15 类） | T | 可用 |

模型输入只含：`O0` 锚点、最近窗口内的**真实**观测 token、token 有效性、以及**候选命令**
（两机器人的 alpha、速度、active 标志）。命令来自候选集合，不是未来观测。

## 2. 来自命令或时钟，不需要预测

| 字段 | 来源 |
|---|---|
| 候选命令（alpha/速度/active） | 规划器或采样器给出的候选，公开信息 |
| 已执行时间、时间 bin | 时钟 |
| 下一个控制周期 Δt = 0.05 s | 冻结协议 |
| 窗口长度 33、历史 32 | 冻结协议 |

## 3. 本轮**仍缺失**、不得假装拥有的字段

| 缺失项 | 后果 |
|---|---|
| **未来自身的真实观测** | 不能做多步自主 rollout；本轮全部评价都是"给定真实前缀的条件预测" |
| **自适应窗口长度** | 窗口固定 33，短历史靠左补齐，长度不随任务调整 |
| **递推时的不确定性传播** | 没有 latent 递推体系；多步展开会累积误差且无法度量 |
| **队友未来行为模型** | 队友的未来观测与动作不在输入中，本轮不预测联合轨迹 |
| **接触/约束模式的显式状态** | 只在终态类别里间接出现，没有可递推的模式变量 |
| **跨 option 的坐标系重置** | 每个 option 用自己的 `R_i0`，跨 option 需重新锚定，本轮未实现 |

## 4. 使用限制

- "终态预测"是**直接预测本次 option 结束时刻**，不是把下一步预测递推 T/Δt 次。
  两者不可混称；后者需要第 3 节缺失的字段。
- 报告中的"执行中"一律指**已有真实观测前缀**的条件预测，**不是**自由 rollout。
- 检查点内记录 `panels` 哈希与 `spec` 描述；载入时必须校验变换哈希，避免用错参考值规则。
- 任何把真实未来观测喂给递推、再声称是"自主预测"的做法都违反本文件。
