如何阅读本页 / How to read this page

1. 三个层次分开记录 / Three separate metric layers

① 控制器声称完成（层 1）：只读技能自己给出的 push_complete / reposition_complete 等退出字符串。
① Controller claim (layer 1): the skill's own exit string, e.g. push_complete / reposition_complete.
② 独立契约兑现（层 2）：从原始逐周期日志重算完成条件，不直接相信退出字符串。 如果声称完成但重算条件不成立，记为 violated（假兑现）。
② Independent contract (layer 2): the completion condition is recomputed from the raw per-period log. A completion claim whose condition fails is a violated (false claim).
③ 任务效果（层 3）：物体真实位移/转角与目标方向进展，只用离线真值评价，绝不作为 控制器输入。
③ Task effect (layer 3): real object displacement/rotation and goal-direction progress, evaluated offline from truth only and never fed back.

2. 契约 / Contracts

PUSH：在 8 s 窗口内累计真实物体接触 ≥ 0.50 s 视为兑现；旧 PUSH 的承诺是“接触推动”， 不是世界方向物体平移。REPOSITION：沿自身估计切向的累计位移 ≥ 0.80×请求距离。
PUSH: at least 0.50 s of accumulated real object contact inside the 8 s window. The promise is contact pushing, not world-direction translation. REPOSITION: accumulated tangential displacement ≥ 0.80× requested distance.

3. 覆盖率口径 / Coverage definitions

request_coverage = 接受请求 / 全部预登记请求； state_coverage = 至少一个请求被接受的 snapshot 数 / 面板 snapshot 数； 条件兑现率 = fulfilled / accepted；保守区间 = [fulfilled/accepted, (fulfilled+unresolved)/accepted]，accepted=0 记 N/A； 有效兑现覆盖 = fulfilled / 全部预登记请求，防止靠拒绝困难情况抬高兑现率。安全/受阻退出 单列，不算兑现。
request_coverage = accepted / all pre-registered requests; state_coverage = snapshots with ≥1 accepted / panel snapshots; conditional fulfilment = fulfilled / accepted; conservative interval = [fulfilled/accepted, (fulfilled+unresolved)/accepted], N/A when accepted=0; effective fulfilment coverage = fulfilled / all requests, so rejecting hard cases cannot inflate the rate. Safety and blocked exits are listed separately and are not counted as fulfilment.

5. 时间与真值 / Time and truth

时间轴按真实物理周期（0.05 s/周期），不是插值动画；执行较早结束的一侧停在终态。 雷达、拟合片段、法向/切向、参考速度、力都是控制器的合法输入；物体轮廓/中心与 true_goal_distance 是诊断真值，仅用于离线层。
The timeline is real physical periods (0.05 s each), not an interpolated animation; a side that ends earlier stops at its terminal state. Lidar, fitted patches, normal/tangent, reference velocity and force are legal controller inputs; the object outline/centre and true_goal_distance are diagnostic truth for offline layers only. Lidar rays with no hit inside the 1.20 m range are drawn at the range length in dark grey; the dashed circle is the 1.20 m sensing limit.
