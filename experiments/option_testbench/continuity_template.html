如何阅读本页 / How to read this page

1. 两条问题 / Two questions

① 连续性：PUSH 进入 push 阶段后，真实物体接触是否连续；时间条绿色=接触、红色=丢失， 黄色竖线=face switch，橙色竖线=corner_rejected。
① Continuity: after the PUSH enters its push stage, is real object contact continuous? Timeline blue=ready, green=contact, red=lost, yellow=face switch, orange=corner_rejected.
② 角点接触点：绿线是当前可见片段，白点是可见片段中点，绿圈是切向修正 目标（可见片段中点内缩 R 后的位置），青点为首次/当前接触点。注意：只看到部分面时， 可见片段中点本身会偏向角点，不等于真实物体面的中心；橙色十字是真值层的完整面中心， 用于对照。 若机器人从角点附近起步，观察投影是否向白点移动、首次接触点是否落在角点。
② Corner contact point: the green line is the visible segment, the white dot the visible-segment midpoint, the green ring the tangential target (that midpoint inset by R), the cyan dot the contact point. With a partially visible face the visible midpoint itself is biased towards the corner and is not the true object-face centre; the orange cross marks the true full-face centre (truth) for comparison. Starting near a corner, watch the projection move towards the white dot and whether the first contact sits on the corner.

2. 图层 / Layers

片段点（红点）、可见线段/面中心/目标（绿）、接触点（青）、当前轨迹（细线）、 物体轮廓（橙，真值）。
Patch samples (red), visible segment / face centre / target (green), contact point (cyan), current trajectory (thin), object outline (orange, truth).

3. 指标 / Metrics

contact fraction = push 阶段真实接触周期 / push 阶段周期； longest loss = push 阶段最长连续丢失；first offset = 首次接触时机器人投影相对面中心的偏移；projection shift = 首次接触投影 − approach 起始投影；min corner margin < 0 表示投影 在可见面内缩区之外（角点侧）。
contact fraction = contacting push periods / push periods; longest loss = longest consecutive loss in the push stage; first offset = robot projection minus face centre at first contact; projection shift = first-contact projection minus approach-start projection; min corner margin < 0 means the projection is outside the inset segment (corner side).
