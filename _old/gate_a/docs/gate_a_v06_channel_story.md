# Gate A v0.6: Multi-blocker channel story

The v0.6 main figure embeds the CST/IET mechanism in a four-blocker horizontal
channel-clearing scene. The side walls contain visible passage openings; dashed
upper/lower channel boundaries and outward arrows indicate the two valid clearing
directions.

Five exact, feasible option boundaries are selected for readability. Both rows
first clear the same current-observation-supported blocker. IET then repositions,
creates a second heavy-contact option, forms a two-robot Push hyperedge, and removes
the heavy gate. CST instead clears a currently supported light blocker and reaches
the heavy gate with only one grounded contact. The topology strips group robot-owned
options by navigation/entity factor and highlight newly created option vertices.

The figure is a representative mechanism visualization. Quantitative CST/IET,
privileged-oracle, H=2/H=3, and optimism-surprise results remain generated by the
receding-horizon planner and are not replaced by the selected storyboard.
